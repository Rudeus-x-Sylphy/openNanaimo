# 运行依赖

开发构建／回归使用Python、仓库TinyCC及.NET SDK；发布运行包自包含.NET运行时。**启动器和游戏运行不调用Python，不要求安装.NET SDK。** 原生数据库层需要系统`winsqlite3.dll`，缺失时拒绝启动而不退回DAT。客户端仍由使用者合法提供。

| 类别 | 路径或组件 | 用途 |
|---|---|---|
| 客户端 | `game.exe` | 使用者合法取得的 PE32 客户端；启动器只检查文件存在，不限制脱壳实现、大小或哈希 |
| 客户端 DLL 与资源 | 客户端配套 DLL、数据文件、场景、图像、音频等 | 原生加载与渲染 |
| 村庄地图 | `Village_map_image/Village_map_image.pack` | 原始村庄资源；兼容工具保留地宫7道路，恢复补制美术前入口并撤回已识别的补制场景对象，启动前逐项校验 |
| Boss 场景 | `flying/hd0_ep22_dg00_st01.sstg`、`flying/hd0_ep22_dg01_st01.sstg` | 原始场景及兼容名称别名；启动前执行逐字节校验 |
| 地宫7迁移模块 | `Nanaimo.Adapter.exe --tools compatibility` | 修正小地图EXE门控；精确识别、备份并迁移登记的补制入口、标题与房间背景，保留用户现有资源 |
| 资源配方 | `gui_launcher/resource_patches/*.json` | 记录派生关系和适用范围 |
| 宠物与装备目录 | `gui_launcher/data/pets.json`、`equipment.json`、`pet_attack_modes.json` | 启动器选项和属性查询 |
| 库存目录 | `gui_launcher/data/inventory_{cards,clothing,furniture,game_items,pets,pet_gems}.json` | 库存管理 |
| 预览数据 | `gui_launcher/data/previews/` | 宠物／装扮图集及索引；家具使用 `furniture_icons.png/json` 本地目录卡片图集 |
| 家具预览生成器 | `gui_launcher/generate_furniture_previews.py` | 从 `inventory_furniture.json` 生成 catalog-card；不依赖原客户端家具图像 |
| 完整 adapter | `adapter_runtime/Nanaimo.Adapter.exe`、`nanaimo_gameplay_bridge.exe`、`adapter_manifest.json` | 本地模式和社交模式使用的完整运行组件 |
| 开发用 Python | 开发者的解释器 | 用于开发检查、配方生成、回归与可选离线资源安装 |
| TinyCC | 自行准备的 `tools/tcc/` 或 `-TccPath` 指定位置 | 原生 adapter 和地宫桥接构建 |
| .NET 8 SDK | `-DotnetPath` 指定或 PATH 中的 `dotnet` | 构建 managed 源码并发布自包含运行包 |
| adapter 数据 | `-ResourceDataRoot` 指定的 `资源/数据` 目录 | 商城、任务、卡片、地宫目录等运行数据；不随源码仓库分发 |

客户端本体、客户端 DLL 与游戏原始资源由使用者自行准备；但 `gui_launcher/data/` 的目录数据与预览图集、以及 `gui_launcher/resource_patches/` 已随仓库提供，无需另行获取。运行包提供`Nanaimo.Adapter.exe --tools compatibility`，用于从使用者自己的原始文件派生人物创建、家具修复、原生状态迁移、结算手动确认与临时经验显示修正、礼物预览、空地购房、屋外外观系统、房屋推荐、地宫7道路、小地图门控、补制图像撤回及名称别名。屋外及结算经验的精确字节配方已编译进C#工具，保留实时分数，仅将客户端临时经验输入归零。对应Python模块只保留作开发期配方来源和对照。

GUI 使用配套目录数据与预览素材。“装饰家具查表”的781条预览由仓库目录字段生成本地 catalog-card，摘要明确记录原客户端资源不可用；这些卡片不属于原客户端资源提取。启动前兼容工具校验派生文件的结构、精确站点及内容一致性；发布校验器核对项目运行文件与资源模块的大小和SHA-256。

## Python 与 TinyCC 的准备方式

- **源码检查和导出脚本**：使用 PATH 中的 `python`，例如先执行 `python --version` 确认解释器可用；不要求仓库内有 Python。
- **GUI 人物／库存后端**：调用完整运行包中的`Nanaimo.Adapter.exe --tools inventory`，启动器检查`adapter_manifest.json`中的`launcher_tools=1`能力标记，由自包含运行包执行。
- **原生 adapter 构建**：默认查找 `tools/tcc/tcc.exe`，也可用 `scripts/build_adapter.ps1 -TccPath <实际路径>`。
- **完整 adapter 构建**：`scripts/build_complete_adapter.ps1` 同时接受 `-TccPath`、`-DotnetPath` 和 `-ResourceDataRoot`；缺少任一必需输入即拒绝构建。
- **本地原生协议测试**：`scripts/test_native_ui_protocol.py` 只查找 `tools/tcc/tcc.exe`，不支持构建脚本的 `-TccPath`。未准备该位置的工具会报错，不是跳过。
- **完整校验包装脚本**：`scripts/verify_package.ps1` 固定使用 `tools/python/python.exe`，仅属开发校验，不参与GUI启动。运行前须自行在该位置准备完整 Python 环境；单独的 `verify_package.py` 和 `verify_client_baseline.py` 可以使用系统 Python；后者仅检查 PE32 结构，哈希只作诊断输出。

`tools/python/`、`tools/tcc/` 是可选的本地安装位置；.NET SDK 可安装在仓库外，已加入 Git 忽略规则，并不表示仓库附带这些文件。准备本地工具时应保留配套标准库、DLL、头文件、库和发行包许可材料，不要只复制单个 EXE。`-TccPath` 不会改变其他入口的工具配置。

## 运行生成的数据

`nanaimo_launcher_profile.ini`、`nanaimo_launcher_profile.json` 保存启动器设置；`adapter_ip.txt` 保存社交模式最近使用的局域网 IPv4；`StateOption/gamestartoption.ini` 由 Network 模板生成。本地模式固定写入 `127.0.0.1`，社交模式写入检测或输入的特定局域网 IPv4。完整 adapter 的状态、日志和 SQLite 数据位于 `adapter_data/`。角色、库存和进度存储格式见 [角色资料与背包](../knowledge/authority/03-角色资料与背包.md)。

## 资源兼容性研究

SSTG／SMMO 选择、PON 别名及道路数据的分析见知识库 [05](../knowledge/authority/05-房间与多人同步.md)、[06](../knowledge/authority/06-目标掉落与首领.md) 和 [08](../knowledge/authority/08-静态地址与调用链.md)。同家族资源回退是兼容性处理，不等于找回缺失的原始资源。社交模式还要求主机防火墙允许所选局域网 IPv4 上的客户端入口；adapter 只绑定用户确认的具体 IPv4，不要求开放到所有网卡。

## 韩服差集宠物试用资源

仓库目录990条；英雄龙869条基线上增量追加121条。GUI直接指定不提高角色等级，新增条目仅开放实际存在的三阶；普通背包比较门控保留，其消费的4条超限需求按110→96、120→99下放。追加名称统一中文译名，原韩文名及源等级保留在元数据。6张有差异的熊猫共用图像及246个解码等价PON保留CN版本；追踪尾字段未解析边界见知识库04。

`scripts/prepare_korean_pets.py`需要使用者自备的匹配韩服资源、PyCryptodome和已安装英雄龙的精确基线；补入526个文件，保留旧PET行、成长表、共享BOO及客户端EXE。准备／安装与运行清单、990条GUI和adapter必须配套，不要仅复制PET表。

```powershell
python -B scripts/prepare_korean_pets.py --source-root '<韩服资源目录>' --client-root '<停止运行的客户端目录>' --output-root '<独立准备目录>'
# 完成配套runtime/GUI准备后才使用 --apply
python -B scripts/prepare_korean_pets.py --source-root '<韩服资源目录>' --client-root '<停止运行的客户端目录>' --output-root '<独立准备目录>' --apply
.\adapter_runtime\Nanaimo.Adapter.exe --tools verify-resources --kind korean --root '<项目目录>' --client-root '<客户端目录>'
```

启动校验使用C#工具，选择未完整安装的新增宠物会拒绝启动。英雄龙单宠安装器仍保留，批量安装同时更新其凭据。社交槽位在锁内刷新表，复制式资源版本不一致时拒绝启动并要求重建，保留账号档案和L7/L8可选模块。发布及外部使用目录的安装／验收范围统一见知识库09。游戏可见表现仍须实机确认。
