# 地宫与背包更新说明

## 战斗与连续挑战

- 普通怪物与 Boss 的接触伤害按当前关卡、难度、阶段和目标资源结算，并统一应用角色防御与战斗保护状态；kind60 场景碰撞只有在静态type4关联能精确闭合到同资源正HP父目标时才扣血，其他kind60和kind80继续无伤害回声。
- 肉弹技能结束后按既定保护时限恢复接触受伤；Boss 接触反馈保持对应部位标识。
- 关卡4超级 Boss 的部位独立记录生命和击杀状态，分体退场与后续形态衔接保持一致。
- 下一地宫恢复完整准备房状态；新战斗开始后继续处理伤害、拾取和技能消耗，续关保留 HP、MP 与火力。
- 超级 Boss 的结算成绩与排行榜使用独立关卡记录，实际阶段与显示阶段分别处理。

## 称号

- 登录、村庄、准备房、个人资料和结算界面统一读取角色持久化称号。
- 角色等级、宠物等级、通关评级和称号分别维护。
- 普通stage0通关保留当前称号；stage1超级Boss在任一难度通关后，1～4村16张地图依次授予P1～P16，5村7张地图依次授予R1～R7，重复通关与较高称号保持稳定。
- 启动器的称号文本与图标使用各自的资源编号；下拉框已同步grade0～24原生中文文本，grade25～42明确标记原生文本为空。

## 复活与背包

- 复活遵守原客户端选择：CF83 mode0使用所选Hans价格，mode1使用1次已激活复活彩蛋；两条路径不互相回退。
- 金币和彩蛋路径均恢复含装备、宠物、宝石加成的地宫effective满HP／MP。金币已提交而worker确认暂时失败时保持连接和死亡锁，后续重试只补做F104/F105同步，不重复扣款。
- 丢弃扩展券、戒指及其他特殊道具后立即更新所属物品列表；连续丢弃、同类物品身份和重新打开背包的结果保持一致。
- 道具使用与扩展操作同步更新消耗数量、快捷栏和已生效的扩展状态。

## 验证范围

完整构建、集成自检、地宫转换、复活计费、Boss 部位生命周期、称号状态和背包即时刷新回归检查通过。此版本供客户端实机验收。
