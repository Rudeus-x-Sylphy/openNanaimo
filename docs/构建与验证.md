# 构建与验证

以下命令均从仓库根目录执行。仓库不附带 Python、TinyCC、.NET SDK、Nanaimo 客户端或完整 adapter 数据。

## 1. 工具

| 工具 | 用途 |
|---|---|
| Python 3.11 或兼容版本 | 清单、导出、单元测试和 GUI 库存后端 |
| TinyCC 0.9.27 i386 Windows | 原生 adapter 与地宫桥接构建 |
| .NET 8 SDK | managed 源码构建与 publish |
| Windows PowerShell / WinForms | GUI 与发布脚本 |

构建脚本不会下载工具。完整 adapter 构建可通过 `-TccPath` 和 `-DotnetPath` 指定仓库外工具。

## 2. source-only 检查

```powershell
python -B scripts/verify_package.py --source-only
```

当前检查 `manifest/source_closure.json` 中174个原生 include 和 managed 构建输入，核对大小、SHA-256、递归 include、路径和公开文本。该入口在 source-only 环境中独立运行。

完整 Python 回归：

```powershell
python -m unittest discover -s scripts -p 'test_*.py' -v
```

Current result: 111 tests; 106 pass and 5 skip because external client or symlink capabilities are unavailable.

## 3. 构建完整 adapter

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_complete_adapter.ps1 `
  -TccPath '<TCC目录>/tcc.exe' `
  -DotnetPath '<.NET 8 SDK目录>/dotnet.exe' `
  -ResourceDataRoot '<已准备的adapter数据目录>' `
  -SelfTest
```

输出目录默认是 `adapter_runtime/`：

```text
Nanaimo.Adapter.exe
nanaimo_gameplay_bridge.exe
adapter_manifest.json
资源/数据/...
```

构建步骤：

1. TCC 编译 `adapter/nanaimo_gameplay_bridge.c`；
2. .NET 8 SDK publish managed 宿主为 `net6.0/win-x64/self-contained`；
3. 复制使用者准备的数据目录；
4. 生成二进制大小／SHA-256 manifest；
5. `-SelfTest` 使用隔离 profile、状态库和端口运行完整检查。

self-test 覆盖：

- 状态交换和角色资料注册；
- 登录、世界入口、背包、任务、拍卖和愿望清单；
- 队伍隔离地宫桥接；
- 角色经验和地宫通关差量；
- 宠物阶段、等级、经验、CF72／CF88／C44C／C379 一致性；
- 商城货币、数据库重开和地宫中未提交货币；
- GM 离线编辑和在线拒绝边界。

`.NET 6` 自包含目标会产生 SDK 生命周期警告，构建结果仍为成功。运行目标调整需要重新验证受支持的 Windows 环境与客户端依赖。

## 7. 完整运行目录校验

准备好客户端、GUI 数据和 `adapter_runtime` 后；P03 村庄 pack 与 SSTG/PON 别名可按兼容派生脚本从使用者自己的游戏文件生成：

```powershell
python -B scripts/verify_client_baseline.py  # 仅结构诊断，不是哈希门禁
python -B scripts/verify_package.py
start_nanaimo_launcher.bat -ValidateOnly
```

`verify_client_baseline.py` 只做 PE32 结构检查，输出大小和 SHA-256 仅供诊断，不作为支持列表。`-ValidateOnly` 不检查 `game.exe` 的大小／哈希，也不检查 P03 pack、SSTG/PON 别名或其他本地派生产物；它校验：

- `adapter_manifest.json` 中完整 self-contained runtime 文件闭包（EXE、DLL 与资源数据）；
- GUI 目录、预览、库存后端和固定 Network 配置。

## 9. 验证语言

- **静态／源码链闭合**：函数、字段、状态和响应路径一致。
- **adapter 构造验证通过**：自动检查确认字节、顺序、事务和持久化。
- **原客户端运行观察**：真实客户端在特定输入下产生可归因结果。
- **端到端验收**：从 GUI 一键启动到可见玩法、重进和重登均完成。

当前发布达到前两层；宠物升级显示、整容动画、复活控制恢复、家具选择、C355 `0/0` 安全启动后的村庄可见出生与拉米诺斯村地宫7完整试玩仍需要原客户端运行观察。
