# 构建与验证

以下命令均从仓库根目录执行。仓库不附带 Python、TinyCC、.NET SDK 或 Nanaimo 客户端；工具可通过脚本参数指定为仓库外路径。

## 1. Source closure 与 package

```powershell
python -B scripts/refresh_source_manifest.py
python -B scripts/verify_package.py --source-only
python -B scripts/verify_package.py
```

当前源码闭包为189个文件。`adapter_manifest.json` 登记256个 runtime 文件，目录另含清单自身；`open_release_manifest.json` 登记267个 critical files。验证器核对大小、SHA-256、递归 include、活动 runtime 清单和公开文本。

完整 package 需要使用者自备的 `game.exe` 只作存在性检查，不对客户端大小或哈希设门禁。

## 5. 完整 adapter 构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_complete_adapter.ps1 `
  -OutputRoot '<全新候选目录>' `
  -TccPath '<TCC目录>/tcc.exe' `
  -DotnetPath '<.NET 8 SDK目录>/dotnet.exe' `
  -ResourceDataRoot '<adapter数据目录>' `
  -SelfTest
```

输出为 `net6.0/win-x64/self-contained`，包含 `Nanaimo.Adapter.exe`、managed DLL、`nanaimo_gameplay_bridge.exe`、资源数据及 `adapter_manifest.json`。必须使用不存在的新目录，避免旧 DLL 混入清单。

```powershell

  --source-root '<客户端根目录>' `
  --output-root '<全新派生目录>' `
  --furniture --revival-display --dungeon-state --dungeon7 --overwrite
```
