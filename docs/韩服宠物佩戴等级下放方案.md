# 韩服宠物佩戴等级与中文名调整

> 当前122条追加宠物采用项目中文译名及81／90／95级佩戴策略；990条目录、运行包与社交槽位资源保持一致。本文维护完整映射和字段约束，验证范围由知识库09维护。

## 1. 生效策略

GUI从英雄龙开始的122条追加定义全部使用中文名，不带“韩服”前缀或内部家族编号占位符。103条名称更新，19条保留；原CN868条不变。

翻译依据为源韩文、资源形象及已有CN同家族名称。北极狐狸、绿蝶公主、机械鱼头马等沿用已有中文；海洋潘、皇家庞、飞鹰潘、艾尔潘、翠绿潘保留原专名区别；泰迪男／女采用泰迪先生／泰迪女士。中文译名采用项目命名。

## 2. 实现边界

- 客户端PET为 `pi._D7`，AES-128-CBC／零IV／PKCS7，GBK文本，4头字段、每条35字段、35条成长尾表。零基field1是角色佩戴需求，field2为名字，field16为描述。
- 更新5个field1、103个field2及121个field16（有效等级说明），其他字段和原868条逐字段保留；攻击、Power、年龄、MP、成长、宝石、期限、价格及美术／PON／BOO保持原值。新增宠物仍固定3阶。
- 变更限于PET资源及配套目录；人物上限、人物存档和背包等级比较保持现有契约。GUI直接指定采用本地低等级例外。
- 名称按GBK有效字节≤15校验，说明≤63，预留NUL，以编码后的字节长度为准。
- CN字段加载链为 `0x9EB1B0 → 0x41CF80 → 0x9F4260`，写定义+0x3EC。KR比较链 `0x577350 → 0x8B0890 / 0x930690` 属KR样本，与CN字段加载链分别维护。81／90／95门槛仍须原客户端上下界确认，细节见authority08。

```text
sha256=514580CC90959B9194A53317870D5D5A7EA0814EAD9CA67C379491D5A000598E
```

## 3. 迁移与发布契约

安装配方分别维护源要求和有效要求：英雄龙源120、目标95；批量安装器通过`preserved_pets`同步英雄龙。支持旧869、旧990、36行名称修正版及已登记中间目录的精确迁移，保留表顺序与成长尾表。首次安装顺序为868→英雄龙869→追加121条至990；已有990目录由批量迁移器更新。单宠与批量安装器统一凭据序列化，重复及交替执行保持字节幂等。

Python与C#校验器、GUI宠物／库存目录、攻击名称、运行包PET、两份安装凭据和社交槽位按同一合同更新。部署以源文件／运行文件白名单为边界，要求目标进程退出，执行全部目标预检、逐文件摘要校验、备份及事务恢复。回滚以安装后摘要保护后续编辑；账号与角色进度保持独立。社交槽位在准备阶段持有槽位锁并同步PET与两份凭据。

## 4. 验证范围

客户端验收按三条龙89／90级、英雄龙94／95级、直升机5号80／81级和普通81级条目的背包佩戴边界独立记录；GUI直接指定属于本地配置。普通、蓄力、自动与追踪攻击的资源依赖采用知识库04的独立契约。
