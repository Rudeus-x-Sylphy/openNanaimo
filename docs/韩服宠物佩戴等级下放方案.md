> 当前122条追加宠物全部使用韩服原始角色等级需求，本服人物上限为200。文件路径保留以兼容既有工具引用；旧的等级下放方案已经撤回。发布与安装验收由知识库09维护。

## 1. 等级与命名原则

三种龙（15003358／15003359／15003360）恢复110级、英雄龙15003361恢复120级、直升机5号15003366恢复99级；其余117条保持原值。需求为0的条目仍为0，同名不同ID的等级／期限变体分别保留。GUI直接指定不改变人物等级，既有低等级管理例外不等于普通背包免门槛。

122条中文名逐项核对源韩文与既有CN家族。熊猫男孩／女孩、泰迪先生／女士、直升机、娜娜跑车、舞狮、骑士和龙等已有名称保留；复用旧家族的北极狐狸、绿蝶公主、机械鱼头马等沿用已有中文。

## 2. 字段与不变项

- `pi._D7`为AES-128-CBC／零IV／PKCS7、GBK文本；4头字段、每行35字段、35条成长尾表。零基field1是角色佩戴需求，field2为名称，field16为说明。
- 相对上次发布只改5个field1、15个field2、4个field16；原CN868条、表顺序和成长尾表逐字节／逐字段保留。英雄龙field16仍为成长说明。
- 122条移植行采用韩服原字段、本地化field2/16/17/18及英雄龙寿命field9，其中field1保持原佩戴需求。英雄龙寿命上限由20调整为50，field18说明同步，采用项目耐久政策。攻击、Power、年龄、MP、成长、宝石、期限、价格及美术／PON／BOO保持原值；追加宠物固定3阶。
- 名称GBK有效字节≤15，说明≤63，均预留NUL；容量按编码字节而非字符数校验。
- CN加载链`0x9EB1B0 → 0x41CF80 → 0x9F4260`写定义+0x3EC。KR背包比较链`0x577350 → 0x8B0890 / 0x930690`只代表KR样本；两者不混同。地址和静态边界归authority08。

## 3. 安装与发布契约

目标PET：`count=990; size=550496; sha256=0388592AD03CAE6025409410578D58F3276983E409A350033AE2B2613E6C906A`。

首次安装868→英雄龙869（需求120）→追加121条至990；现有目录支持12个已登记的精确迁移输入，按逐行before／after摘要及允许字段差异更新。覆盖旧869／旧990／36行名称修正版、旧英雄龙等级中间目录、下放目录、寿命说明目录及单宠寿命50目录；输入资格由登记的精确大小、SHA-256及字段差异限定。各迁移的说明字段和目标摘要统一闭合到当前目标。单宠与批量安装器维持双凭据规范化及重复／交替执行幂等，英雄龙凭据包含寿命上限校验。

Python／C#校验器、GUI宠物与库存目录、攻击名称、运行包PET和资源包配方遵循同一合同。部署要求目标进程退出、全量预检、逐文件备份及事务恢复；回滚以安装后摘要保护后续编辑。社交槽位在准备阶段持锁同步PET和双凭据。账号、人物经验和背包存档不在变更范围。

## 4. 验证与未验收边界

静态资源与主机验证覆盖122条原始等级、原868条和35条成长尾表保留、中文容量、12种精确迁移、输入字段边界、重复／交替安装、异常恢复、GUI目录及资源包一致性。迁移输入按已登记大小及SHA-256维护精确身份，验证范围为资源合同与安装事务。

原客户端仍需按三条龙109／110级、英雄龙119／120级、直升机5号98／99级验证普通背包佩戴上下界，并检查中文显示；普通、蓄力、自动与追踪攻击继续采用知识库04的独立验收边界。运行中的外部安装不热覆盖，新表需按停服部署流程安装后重开GUI。
