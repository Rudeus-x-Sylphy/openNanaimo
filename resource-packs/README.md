# 客户端移植资源包

## 地宫过场

地宫战前／战后对白资源见`nanaimo-dungeon-cinematics-kit.zip`及其`.zip.sha256`，包含160个演出、720张中文台词图、44项共用图像及2项关卡演出引用修正，共926项。L1～L8全部战前／战后对白中文化，ep08～ep15恢复64个完整时间轴。安装前摘要、完整资源清单、程序配套与事务恢复见[地宫过场中文资源安装](../knowledge/指南/客户端二进制补丁/地宫过场中文资源安装.md)。

## 章节与四村挑战

- `nanaimo-story-resource-kit.zip`：37项章节立绘、37项四村场景／立绘／界面和1,154项挑战资源，共1,228项实物；包内 `kit-manifest.json` 登记三份配方及逐文件身份。
- `nanaimo-story-resource-kit.zip.sha256`：章节ZIP整体摘要。资源包由 `scripts/package_story_resource_kit.py` 按当前配方构建及核验。
- 完整仓库提供自包含适配器、QT／QS和自动部署入口 `scripts/deploy_story_release.py`。首次部署同时使用下述L7/L8资源包；已有附加资源层按收据核验。

安装、显式章节启用、奖励审核和统一回滚见[章节自动部署](../knowledge/指南/客户端二进制补丁/章节表与对白安装.md#自动部署)。两个ZIP均随Git直接交付，使用者提供完整CN客户端。

## L7/L8与宠物

- `nanaimo-korean-resource-kit.zip`：2350项去重韩服白名单输入、1328项L7/L8安装输出及保留校验项，以及安装工具和配方；数量和文件身份以包内清单为准。
- `nanaimo-korean-resource-kit.zip.sha256`：ZIP的SHA-256。包内`kit-manifest.json`逐文件登记大小与摘要。
- 支持英雄龙24项、其他121条追加宠物526项安装资源，以及L7外观／BGM补齐和L8资源；共享基础CN资源由用户自备客户端提供。

下载后按[安装说明](../knowledge/指南/韩服L7-L8与宠物资源说明.md#df-17-006)校验、解压到独立目录并执行安装器。不要直接覆盖客户端。这里只包含移植白名单子集，不包含客户端EXE／DLL、完整安装包、用户账号、存档或日志。

已发布ZIP及其SHA-256保持发布时的内容与目录，包内原有文档属于当时版本。当前安装说明从知识库入口阅读；以后生成的新包保留指南的知识库路径，并包含其本地Markdown链接依赖，根目录README提供安装导航。

本ZIP是Git直接跟踪的实际文件，不依赖Git LFS或外部网盘。包内素材权利归原权利人；代码许可不自动适用于游戏素材。验证范围为资源、转换、安装／回滚与宿主程序检查，不代表全部原客户端玩法已验收。
