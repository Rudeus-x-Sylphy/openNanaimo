## 作用与范围

维护 `nanaimo_projectile.ini` 的字段、缺省值、读取时机与生效边界。适用于已安装子弹 DIY 补丁的客户端目录；二进制站点与资源派生见[位点与安装](位点与安装.md)。

## 功能与配置

- V键连续发射采用90ms间隔，松开后停止；跨地图或战斗对象重建后，以一次松键重新取得发射资格。
- `nanaimo_projectile.ini`保存启用状态、资源选择及反向开关；客户端第一次预载时读取，配置更新及旧资源升级均在客户端退出后、下一次启动生效。
- 配置独立于角色数据库，人物数值、背包及适配器伤害规则保持各自管理。适配器与客户端配置采用独立生命周期。
- 默认关闭此功能；启用时由启动器调用可选安装器，使用 PowerShell 与内置 .NET 完成派生。

## 配置字段与读取边界

配置位于目标 `game.exe` 同目录的 `nanaimo_projectile.ini`，节名为 `[Flamethrower]`；这是兼容接口名称，界面名称统一为“子弹 DIY”。

| 字段 | 合法值与作用 | 缺省行为 |
|---|---|---|
| `enabled` | `0` 关闭；`1` 启用 V 键连续发射 | GUI 与客户端均关闭 |
| `resource` | `flying/pon/` 下的 PON 文件名；GUI 要求匹配资源目录项，保存时将七个兼容原名换为别名 | `nanaimo_basketball.pon` |
| `reverse_direction` | `0` 使用原发射侧；`1` 切换发射侧及出生位置计算方向，并对匹配资源启用额外反射 | GUI 新配置为 `1`；客户端直接读取缺失字段时为 `0` |

- GUI 只保存配置，不在保存按钮中安装资源；启动准备流程在 `enabled=1` 时调用安装器。
- 配置保存要求退出该目录客户端；角色数据库、其他客户端目录和适配器进程具有各自生命周期。
- GUI 文件名校验为 `^[A-Za-z0-9_][A-Za-z0-9_.]{0,57}\.pon$`，不接受目录路径；客户端桥接还检查同目录资源存在且不是目录。
- 首次预载加载配置，随后预载可重置发射状态但不重新读取配置。更改配置后应重启客户端。
- `ProfileIniOverride` 属于启动器测试／配置覆盖入口；常规启动将配置放在客户端根目录。自定义覆盖目录不能视为客户端读取目录自动重定向。

## 实现证据

| 实现 | 负责内容 |
|---|---|
| `gui_launcher/projectile_browser.ps1` 的 `Read-ProjectileSettings`／`Write-ProjectileSettings` | GUI 缺省值、字段校验、ASCII 配置与原子保存 |
| `gui_launcher/nanaimo_launcher.ps1` 的启动准备流程 | 根目录配置读取与可选安装器调用 |
| `scripts/projectile_diy_asm.py` 的 `load_config`／`preload_bridge`／`fire_bridge` | 首次读取、文件存在检查、90 ms 节流和对象重建后的松键门槛 |
