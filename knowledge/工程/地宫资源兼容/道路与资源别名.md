### P03 村庄道路资源包

原始第五村 pack 只有前六个入口的连通道路，page17 没有通往 page18 的出口。地宫7需要 P03 道路 pack：

```text
Village_map_image/Village_map_image.pack
```

派生器读取 pack 目录与第五村 50×36 单元网格，按字段语义生成道路；不要求原始 pack 或输出 pack 命中固定哈希。

当前P03道路连接17↔18↔19，并在page19封闭后续规划道路。基础CN兼容布局采用以下入口格点，韩服原生L7/L8布局采用下文对应格点：

- page18 单元格 `x22..27/y3..4` 的地宫7入口 action `166`；
- page18 `(25,6)` 的返回 marker `169`，返回像素坐标 `(400,96)`；
- 入口恢复到补制美术引入前的区域，不再迁往左侧实验室图像；
- 已有 `160..166` action；
- 未增加虚构的 `167..182` 地宫入口。

韩服原生L7/L8布局的page18入口action166为`x8..11/y5..9`，marker169返回格点为`(10,15)`；基础CN布局对应`x22..27/y3..4`和`(25,6)`。原生布局使用各自入口与返回坐标，L8后续道路统一封闭；父子收据关系见[范围与前置进度](范围与前置进度.md#df-03-002)，完整文件与操作归[五村地图与顺序解锁安装](../../指南/客户端二进制补丁/五村地图与顺序解锁安装.md)。

P03 提供道路连通性；战斗资源覆盖范围由 SSTG、SMMO 与 PON 清单独立确认。

### 地宫7关卡 SSTG 别名

客户端请求的兼容路径为：

```text
flying/hd0_ep22_dg00_st01.sstg
```

使用者应从已有的：

```text
flying/hd0_ep22_dg01_st01.sstg
```

制作**逐字节相同**的别名文件。该复制关系由派生器执行；不对源文件或别名文件设置固定大小／哈希门禁。

只复制 SSTG 文件名；文件内部已经存在的 dg01 SMMO 引用保持不变。

### 适配器资源查找映射

地宫7在村庄／房间身份中保留 `hd0/ep100/dg6/st1`，但资源目录使用 `ep22/dg1/st1`。完整适配器对**普通目标和BOSS**使用限定映射：

```text
hd0 / ep100 / dg6 / st1
    ->
hd0 / ep22 / dg1 / st1
```

该映射只用于资源查找，不改写房间身份、客户端显示 tuple、奖励归属或持久进度。

### PON 同家族兼容别名

关卡嵌套依赖使用以下别名：

```text
源  flying/pon/mis_ep22_dg01_m_196.pon
目标 flying/pon/mis_ep22_dg01_m_196_02.pon
操作 逐字节复制，不设置固定大小／哈希门禁
```

该文件是同家族兼容别名，其外观、轨迹与参数沿用源文件。`gui_launcher/resource_patches/superboss_projectile_alias.json` 记录派生关系和适用范围；GUI 以路径与生成结果为准。
