# 工程／客户端兼容／陈旧组件启动兼容

## 当前结论

陈旧组件兼容由启动器在进入游戏前自动准备，覆盖原版布局转换、原生启动链、接口调用约定和频道登录。原版转换恢复文件节、导入表和重定位，将PE入口接入原生CRT启动链，执行游戏主函数及浮点初始化。十三处精确兼容位点共同维护对象创建／销毁、接口设置、频道登录和两个组件回调入口。

频道登录兼容已通过原客户端实机验证：首次选择频道后进入村庄并显示已有角色。运行包身份与分层验证结果见[当前验证归属](../验证状态/层级与版本归属.md#陈旧组件启动兼容验证)。

## 输入资格

| 输入 | 校验与处理 |
|---|---|
| 原版布局 | 文件长度`11,310,408`、SHA-256 `D56C80CA893990761BBB7FAF412F54D8CB56763AD2D2D74AEFC3F9FE63187515`；通过整文件身份校验后按配方转换。 |
| 已有原生布局 | 校验PE32基址、文件节映射、原生入口、导入目录和十三处精确位点；兼容既有业务补丁。 |
| 已登记旧布局 | 登录位点支持原生指令和既有兼容跳转，按当前目标统一迁移。 |
| 位点冲突 | 预检识别具体冲突并保留输入文件，支持恢复备份后重新准备。 |

原版入口RVA为`0x009BC17B`，目标入口RVA为`0x00750C03`，图像基址为`0x00400000`。原生入口的初始化链进入`0x00B50A23`，主函数调用位于`0x00B50B95`、目标为`0x00439FE0`，浮点初始化位于`0x00B4ED97`。完整转换内容、精确字节、配套文件及安装恢复步骤统一见[二进制安装与恢复](../../指南/客户端二进制补丁/陈旧组件兼容安装与恢复.md)。

## 启动器契约

本地进入和社交参与共用兼容准备。启动器调用同版工具的`--legacy-startup`选项，依次执行布局转换、十三处兼容处理及所选业务项，再校验`verification.all_pass=true`和完整操作集合。

操作集合包含`legacy_startup_channel_login`、`legacy_startup_object_receive_a`、`legacy_startup_object_receive_b`。GUI以客户端、运行程序集、运行清单和兼容报告的身份管理会话缓存；任一输入更新后重新准备。安装事务提供内容寻址备份、并发修改校验、逐文件替换和异常恢复。

## 频道登录空接口崩溃

频道登录兼容将执行流从`0x004DFB1A`引至`0x004DFB8D`，完成禁用组件调用与原生登录流程的衔接。会话值安装、教程标志、频道显示及`this+0x30=5`的状态推进继续执行，登录失败分支沿用原生处理。

两个组件回调入口分别返回1并清理4字节参数，四个外层回调继续执行对象释放和返回路径。换线控制器沿用原生会话安装及场景恢复。完整位点、前置字节、迁移输入和目标字节集中维护于[二进制转换清单](../../指南/客户端二进制补丁/陈旧组件兼容安装与恢复.md#二进制转换清单)。
