# 工程／术语约定

## 用途与适用范围

本页维护知识库的说明性术语，以及源码标识、命令开关、字段名与资源名保留原拼写的条件。事实页、指南与索引的正文用词统一以本表为准；术语的维护归属、知识路由与迁移审计约定见[知识维护](知识维护.md)。

## 术语约定

| 说明性术语 | 原标识保留条件 |
|---|---|
| DIY、NPC、L7／L8 | DIY指自定义内容接入，NPC指非玩家角色，L7／L8指第七／第八地宫；示例中的“修道士／僧侣”检索统一路由到项目名称“修道僧” |
| 配方、清单、约定、收据 | 配方定义转换或补丁规则，清单登记文件身份，约定描述接口和状态约束，收据记录某次实际安装；技术正文不用法律语义的“合同”指代这些对象 |
| 适配器、工作进程、补丁 | 代码标识、命令开关、文件／资源名保持原拼写 |
| BOSS、超级BOSS | 使用社区惯用的大写 `BOSS`；`首领`、`Boss`、`boss` 只在原文引用、既有标题锚点或标明用途的历史别名中保留。源码标识、命令开关及原始资源名保持原拼写 |
| 载荷、完整帧 | 字段名仍保留 `payload` 等原标识；偏移必须说明基准与字节单位。当前正文统一写“完整帧”，不使用“完整报文” |
| HP／MP、SP | HP 指生命值，MP 指魔力值；正文首次出现写作“HP（生命值）”“MP（魔力值）”。不用“生命／魔法”“魔法值”“生命与魔法”等省写。SP 保留原拼写 |
| 评级、评价、评分 | “评级”指结算等级 F／D／C／B／A／S；“评价”指持久化的最佳成绩记录；“评分”只保留在既有标题锚点、客户端页面名与原文引用中，当前正文按实际情况写“结果页”或“计分” |
| 加载、读取、载入 | 资源装入内存统一写“加载”，不使用“载入”；数据查询与解析写“读取”。资源名、源码标识与既有标题锚点保留原拼写 |
| 小地图 | 中文正文统一写“小地图”；`minimap` 作为资源名、路径与源码标识保留原拼写，不使用“迷你图” |
| 账号、登录 | 中文正文统一写“账号”“登录”，不使用“帐号”“登陆” |
| 推荐点数 | 公寓推荐系统的计分单位统一写“推荐点数”，不使用“推荐积分” |
| 场景物品、场景道具 | 场景拾取对象统一写“场景物品”；“场景道具”只保留在既有标题锚点与原文引用中 |
| 分派分支 | 客户端 dispatch 的 case 统一写“分派分支 NNNNN”；`case53210`、`status10` 等原始标识保留原拼写，不使用“案例”“情况” |
| 约定、契约 | 表示接口一致性与状态约束统一写“约定”；“契约”只保留在既有标题锚点与原文引用中 |
| 状态布局版本、经验曲线版本、战斗代次 | 分别说明含义，版本数相同不视为同一版本体系。F100／F102 状态容器的版本统一写作“状态布局版本”，不用“库存版本”“库存格式版本” |
| 拉米诺斯、Lumineos | 中文正文统一写作“拉米诺斯”；`lumineos`／`Lumineos` 作为资源名、路径与源码标识保留原拼写。不用“拉明奥斯”“拉米涅奥斯” |
| 修道僧 | 项目统一名称；`Monk`／`MONK` 作为源码标识与资源名保留原拼写。“僧侣”“修道士”只作检索别名，不作为正文用词 |
| 汉斯、Hans | 中文正文统一写作“汉斯”；`Hans`／`hans` 作为源码标识、字段名与资源名保留原拼写 |
| 库存、背包 | “库存”指适配器维护的库存对象、容量与持久化载体；“背包”指客户端背包界面或标签页 |
| 城镇、村庄 | 模块与目录名用“城镇”；具体场景用“村庄”；“一村”“四村”等客户端既有简称保留 |
| 卡片、卡册 | 正文统一用“卡片”，“卡牌”只在既有锚点与原文引用中保留；“卡册”指卡片册页载体 |
| 复活礼包、复活糖果 | “复活礼包”指类别48的礼包实例及其购买与次数载体；“复活糖果”是该礼包的显示名；不用“复活糖” |
| 地宫、关卡 | “地宫”为项目统一称谓，指 L1～L8 地宫；“关卡”指地宫内的一层。“副本”保留其“资源拷贝”与引用原文的用法，不用作“地宫”的同义词 |
| 终结状态（terminal） | 表示对象或战斗已进入终结状态，不是对象类别；`terminal` 等源码标识保留原拼写。协议中的终结标志、组件序号与本地状态字段须按各自载体解释，不能统称为同一个“终端字节” |

知识页中的“待维护者决定”表示适用范围尚未确定；保留具体问题及证据边界，不能作为已经消除的冲突。
