## 当前运行结构

| 组件 | 仓库相对路径 |
|---|---|
| 一键入口 | `start_nanaimo_launcher.bat` |
| GUI | `gui_launcher/nanaimo_launcher.ps1` |
| 社交模式最近地址 | `adapter_ip.txt` |
| 家具客户端图标生成器 | `gui_launcher/generate_furniture_previews.py` |
| 家具客户端图标图集 | `gui_launcher/data/previews/furniture_icons.png`、`furniture_icons.json` |
| 客户端连接器 | `gui_launcher/client_connect.ps1` |
| 完整适配器 | `adapter_runtime/Nanaimo.Adapter.exe` |
| 地宫桥接 | `adapter_runtime/nanaimo_gameplay_bridge.exe` |
| runtime 清单 | `adapter_runtime/adapter_manifest.json` |
| 活动发布清单 | `manifest/open_release_manifest.json` |
| 源码闭包 | `manifest/source_closure.json` |
| 导出候选清单 | `manifest/patch_allowlist.json` |

## 地宫与战斗资源约定

标准GUI（`gui_launcher/nanaimo_launcher.ps1`）自身只启动上表登记的运行目录组件，运行包身份以活动发布清单与适配器清单为准；地宫资源与战斗资源的规则分别由[地宫资源兼容](../地宫资源兼容/README.md)和[地宫／战斗资源](../../业务/地宫/战斗资源/README.md)维护，本页不重复登记。
