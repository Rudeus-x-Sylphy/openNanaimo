### PET库存、选中身份与场景刷新

- C44C 是宠物及材料库存列表，头部携带选中宠物身份。有库存或扩容权益时，托管构造的完整帧为2032字节；空库存且无扩容权益时可返回12字节空列表（`BuildPetInventoryPayload`）。

- C473/C474 是商城待领取物品的分页边界，包含宠物及受支持的其他商品；分页规则见[商城待领取分页](../../经济/商城/待领取分页与纪念礼物.md#kb-03-035-3)。

- C44B是独立宠物箱请求入口；C378打开装备栏时，适配器按请求返回C379后再返回C44C，两条入口均按请求驱动。

- 类别15持久库存先经当前PET定义查找，再进行期限、排序、56行容量及选中实例投影；C44C、C452、C379选中摘要／外观D7和会话handle共用有效定义筛选。历史数据库行、数量、成长与保存的选择按原值保留，材料使用独立目录及身份校验。
- World装备栏控制器`0x8005F0`的C44C分支`0x80382E`读取完整帧`+10 BYTE`计数、`+12`起每行36字节宠物数据，经`0x8039A2 -> 0x40949E -> 0x7C6B40 -> 0x412783 -> 0x7C8430`构造对象；`0x7CC623 -> 0x41CE2C -> 0x9EBFA0`查询PET目录，缺失返回0，随后`0x7CC6EE -> 0x404624 -> 0x9F4540`进入`0x9F454A`的`WORD [eax+0x40E]`读取。因此完整2032字节响应仍以有效PET定义为必需前提。
- 当前990条PET表以定义存在性作为客户端投影前提；历史代码`15009901`按无定义项目隔离。库存遍历会构造全部有效行，因此这一校验覆盖已装备及未装备项目。已确认故障位置为模块RVA`0x005F454A`、指令VA`0x009F454A`；当前筛选在构造客户端库存前生效，验证范围见[无定义宠物隔离验证](../../../工程/验证状态/层级与版本归属.md#无定义宠物隔离验证)。

- 起始紫色／蓝色／柠檬宠物的目录初始模型／年龄阶段值为 `1/2`（即两个取值 1 与 2，字段口径见[宠物资源阶段边界](../成长/阶段与奖励策略.md#kb-04-019)与[宠物成长表与结算经验来源](../成长/阶段与奖励策略.md#kb-07-005)）；当前适配器把当前阶段（年龄）钳制到至少 1，数据库原值保留。

- PET代码、实例标识、库存所有权、选中记录尾部和可见角色跟随效果分别维护。
- `C44C`每只宠物独立下发一行，记录`+8`的WORD为handle，完整帧`+11`为选中handle；`C379`完整帧`+172`和`C452`记录`+8`引用同一会话身份。`PetIdentityMap`将0..55的handle映射到持久`(ItemCode,PetInstanceId)`，移除一只不重排其余handle；材料身份沿用独立区间。重连重建会话映射，持久实例与选中实例保持。
- 换宠`C47D/144`由`sub_819C90 -> sub_41B293 -> sub_82D070`构造，经`sub_ADA3E0`发送；完整帧`+93 BYTE`为选中handle、`+94 WORD`为卸下handle，`+96/+100 DWORD`为对应代码，`+104..139`为36字节外观。只在对应代码非零时读取handle，并同时校验所有权、代码和当前卸下实例；同代码互换也必须按两个handle分别处理。
- `C44D`丢弃、`C44F`镶嵌／黄金粉／特殊宝石、`C453`充能均先将handle解析为确切实例；成长经验、有效HP／MP与原生战斗导入读取选中实例。句柄错配、已删除句柄、外来实例及会话失效均不允许修改另一只同代码宠物。

- 本仓库托管适配器的关闭背包策略由成功的 C47D 请求触发。
- 村庄状态使用 `C47E -> C47F -> C379 -> C3CC -> C44C -> C430`；房间、准备状态和公寓内部使用 `C47E -> C379 -> C3CC -> C44C -> C430`。
- 多人 `room_active` 与连接本地 C38D/C38E 周期分别维护副本和公寓状态，并由 C367/C365/CF09/CF6C 过渡更新。

### 选中宠物资源与关闭背包刷新

- 角色资料整合保留性别D8，并通过C368/CF71/CF72发布一致的选中宠物有效HP/MP。
- 关闭背包后按[PET库存、选中身份与场景刷新](#kb-03-024-1)的村庄／房间两条响应序列刷新，并保持关卡预加载与场景状态连续。

### 宠物目录编辑与效果元数据

- 宠物目录整合当前PET定义（规模见[韩服新增宠物与移植边界](资源身份与移植.md#kb-04-004-1)）、18931个PA宝石定义及适配器效果映射，包含基础／有效攻击、HP/MP增益、槽位数量、年龄元数据和准确宝石槽位。
- 同一宠物允许多个独立槽位使用相同宝石代码。
- 直接编辑持久化数据可以分配初始状态，但不证明原始适配器的购买、消耗或宝石镶嵌交易。
