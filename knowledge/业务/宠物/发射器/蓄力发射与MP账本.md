# 业务／宠物／发射器／蓄力发射与MP账本

## 范围与适用条件

蓄力发射的源角色选择、扣后 MP 载体、发射器字段与 MP 消费资格；适用于 subtype20 发射边界。

主题入口：[主题索引](索引.md)。

### 蓄力与远程发射器

- 主动蓄力subtype20由0x6E7590/0x6D86F0检查当前MP≥成本；被动owner75、追踪及subtype30使用各自条件。
- PetLevel、MP与动作子类型分别参与状态管理。
- 适配器在活跃地宫的`0x044C/40` subtype20发射边界记入MP消耗：以客户端已扣费后的绝对MP下调当前有效MP，每次发射记账一次，覆盖打空及同次发射的多个弹丸／命中。
- D00D／D011负责命中结算；随后的type9吸收继续使用同一`g_profile_mp_current`与原有小数余量。
- 成本门槛由原客户端按PET发射器资源计算。

- 消费按当前连接角色隔离，要求开场转发屏障已释放、受伤账本的房间／战斗周期匹配、存活且处于结算前；长度40、subtype20及有效MP上限共同限定消费资格。
- 按客户端时钟保持单次消费幂等、过滤旧发射并支持32位回绕，换房／换战斗周期重新建账。
- 射击报告只承担MP下调，恢复由拾取和吸收路径维护；工作进程的F102快照返回已更新MP，吸收通过既有定向CF72同步。
- 成本校验范围为客户端绝对MP与有效上限；客户端恢复通知与在途发射交错已有独立用户确认，范围与受测版本待补录状态见[蓄力与回蓝交错](../../../工程/验证状态/地宫与成长验收.md#kb-09-026-10)。

字段及单次发送链归[房间角色、加载、地图和继续条件门控](#kb-08-023-8)，当前构造验证与运行包归[验证入口](#kb-09-026-6)。原客户端蓄力打空、连续命中回蓝、恢复与发射交错及多人可见效果已有[蓄力与回蓝交错](../../../工程/验证状态/地宫与成长验收.md#kb-09-026-10)的独立用户确认，受测版本待补录，不扩展为多人地宫所有双向发射场景通过。

- 蓄力发射通过MP账本更新并保留适配器7秒护盾，正MP吸收使用CF72/116同步。
- 该刷新在客户端apply0下仍重建快捷栏并清除两组type1保护数组，独立保护链表保持，存在资源同步中断数组保护的静态／隔离指令风险。
- GI21000001的视觉type9与这两组type1保护不能直接等同；其实际效果写入链及“护盾→蓄力／吸蓝→受击”仍需原客户端运行闭合。
- 精确数组与调用点归[房间角色、加载、地图和继续条件门控](#kb-08-023-8)，验证层级归[验证入口](#kb-09-026-6)。
- Power0 的owner资源标识75 出现在 subtype20 与首次 Power 收集之前。
- 自动／寻迹行为的归因需要库存状态、发射路径与操作标记共同闭合。
- 现行构造依次发送CF71和角色定向CF72，后者携带+0x64=1、完整角色资料／PET及+0x66当前成长阶段、+0x67最大成长阶段。
- CFDA保持请求驱动。
- 0x044C+8选择源角色；转发字节等价不代表渲染或射击已经验收。
- 双向主体、自动与追踪发射的两客户端可见效果尚未完整验证，相关同步机制见[业务／地宫／索引](../../地宫/索引.md)。

### 0x044C蓄力发射的源角色、扣后MP与时钟

- 0x044C 共有源角色选择：`0x006FCE26..0x006FCEBC` 使用数据包 DWORD `+0x08`；子类型分派保持 `0x006FCF30 -> 0x006FD207`。

- **0x044C蓄力MP载体（原客户端发射／远端消费，完整帧40字节）：** `sub_6D86F0`先检查当前MP及成本，再经`0x6D873E..0x6D8744 -> 0x405AB5 -> 0x6E3050`扣MP；`0x6D875B -> 0x416A54 -> 0x6E73E0`把扣后值写入PET发射器`+0x44`。
- `0x40944E -> sub_6AB290`在`0x6AB3D7 -> 0x4134E4 -> sub_6ACBF0`发送一次subtype20，然后安排追加弹丸循环。
- 构造`0x6AE840`固定长度40；完整帧`BYTE+0x10`为子类型、`BYTE+0x11`为发射器行，`WORD+0x16`复制`launcher+0x44`，采用扣后绝对MP语义；`DWORD+0x1C`来自`0x40395E -> 0x6A6000`客户端单例的`+0x24`时钟，经`0x417544 -> 0x6AE8F0`读取。
- 远端`0x6FD34F..0x6FD3C5`在subtype20经`0x41DBCE -> 0x6D88F0`发射后，读取`WORD+0x16`并调用MP setter覆盖绝对值；普通发射的同偏移沿用发射器既有值，MP消费资格限定为subtype20。
- 完整帧40字节门控覆盖本路径最高读取到`+0x1F`；本段偏移统一相对完整帧，载荷偏移由完整帧偏移减8得到。

- 成本计算链为`0x414CA9 -> 0x6E6F50 -> 0x417BA2 -> 0x6E6F80`，按`launcher+0x50`选行，读取`[launcher+0xD0]+row*0x118+0x1558`并右移1。
- 适配器在[蓄力与远程发射器](#kb-04-010)规定的发射边界记录扣后MP。
- 当前PE对应594条指令、2004字节与该静态约定一致，验证范围为指令与字段约定。

### 蓄力MP账本的构造样例与消费资格

- 蓄力MP消费与吸收采用[蓄力与远程发射器](#kb-04-010)规定的发射边界策略，字段及地址归[房间角色、加载、地图和继续条件门控](#kb-08-023-8)。
- F102返回按发射更新后的绝对MP：初值2760时，两次成本44的蓄力发射分别返回2716、2672，打空同样计入消费。
- 单次幂等、时钟顺序、subtype20、有效MP上限和房间／战斗周期共同限定记账资格，恢复通知由既有吸收路径维护。
