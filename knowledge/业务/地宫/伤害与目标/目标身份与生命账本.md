# 伤害与目标／目标身份与生命账本

## 范围与阅读约定

普通、运行时、分体目标的身份、HP 初始化、终结及回收范围。

术语：HP／MP 为生命／魔法；“原始HP（raw HP）”与“名义HP（nominal HP，即客户端按所选槽位百分比缩放后的 HP）”是同一资源行的两个独立口径。`raw/nominal HP` 表示原始值／名义值这一对数值，不是名义HP的别名。保留源码字段名、协议名和资源文件名，具体对象归属由对应证据说明。

以下偏移未另注明时相对完整报文；`record`、`actor`、`manager`、payload、资源逻辑行和文件偏移均是独立基准。统计数字限定于正文登记的样本、资源目录和验证层级。

## 普通、分体与运行时目标账本

- 普通、资源已知的 D00D 目标在当前 `DungeonBattleInstance` 内以 **runtime UID** 为稳定身份；`targetIndex` 只是客户端目标向量的遍历／表现索引，同一运行时实例的连续报告可以变化，不能参与 HP 键。
- 相同资源 owner 对应的不同 runtime UID 各自拥有独立 HP、首次终结、得分和掉落，一个实例死亡不得修改同 owner 的其他实例。

只有 `HP > 0 -> HP == 0` 的首次跃迁产生终结状态、得分和掉落。已终结实例的后续报告返回非终结 status0，不再次发送 D00E/status200，也不消费另一条当前或预载表现行。未编目动态实体使用 battle-scoped runtime UID 终结集合。

- runtime/deform 目标使用独立的 `selector + generation token` 账本；同 owner、不同 selector 的实例互不影响，generation 改变只重置对应实例。
- 地图、房间或战斗切换创建新 epoch，原生资源域重选也会递增 epoch 并清空 static/runtime 状态。

- 普通 D00D、runtime/deform、视觉 crate 和BOSS D011/D012/D013 始终使用不同账本。
- D00E 的客户端警告表示终结 selector 在当前与预载目标池中均未找到；因此重复终结必须在 适配器 端抑制，不能以再次发送 status200 作为补偿。
- 以上键模型与重复终结行为已由资源目录检查、C harness 和 适配器 回归覆盖；原客户端低级地宫分体的可见效果已获用户确认，范围与受测版本待补录状态见[地宫分体与接触伤害验收](../../../工程/验证状态/地宫与成长验收.md#地宫分体与接触伤害验收)。

## 情侣特殊怪物属性

- 情侣特殊遭遇覆盖46份资源、20,683个放置记录及62个阶段组合。
- 资源类型、原始HP（raw HP）、碰撞攻击、得分、防御和奖励分类按独立字段映射；情侣开关决定遭遇资格，参战成员共享相同地图状态。
- 运行实例生命统一采用既定的正向原始HP值与正向名义HP值的较小值，4,298条托管运行实例记录已与原生策略对齐。
- 资源基础目录保留原始属性，运行时UID负责具体实例状态；普通、分体、箱子和BOSS继续使用独立终结账本。

属性映射、资源身份、普通与超级阶段覆盖及数据归一化幂等检查通过。

组队、稀有、神秘特殊怪同样使用上述正向原始HP与名义HP较小值策略。`scripts/normalize_couple_monster_catalog.py --all-special`按资源摘要和放置选择器扩展归一化，补齐1,120条托管运行记录；只更新DCC7运行记录的HP，基础属性、选择器、计分及掉落字段不变。生成器同步`combat_score_resource_data.inc`的DCC7摘要。生成资格与概率唯一归属[特殊遭遇与闲置资源](../关卡与房间/特殊遭遇与闲置资源.md)，此处不将构造一致性扩大为客户端战斗验收。

## 普通HP和攻击来源

- 行保留原始HP／名义HP值、基础/类型/奖励、资源哈希、放置和关联。
- 运行时绑定／重新武装依赖分配／生成事件，而不是定时器/重复选择器。

- 客户端HP初始化公式与地址区间0x6CA898..0x6CA8D4（含 PE double `0x00C59EB8`=0.01 与 `sub_6CA6C0`）统一见[普通目标、源攻击和选定资源](#kb-08-038-1)。
- 适配器端采用min(正原始HP,正名义HP)作为兼容性策略；历史适配器曾仅采用正原始HP，客户端初始化仍按所选百分比缩放。

- 有界基础9999异常仅适用于分类的无奖励低生命值目标，不适用于类型4/无生命值行或其他未确认的适用范围（原文“无界楼层”未定义）。

## 普通终结和碰撞信道

- 游戏分派器0x6EBAC0 / D00E: 字节+0x1A=200 是终端；WORD+0x18 是选择器。
- 字节+0x1B 是单独掉落子类型，不是状态。
- 状态0在没有目标回收的情况下更新分数。

- Terminal200仅用于合理的普通终结决策；无有效攻击／无HP结算资格/类型4报告仅保持非终结状态。
- 未改变HP的未解决攻击不得判定为终结。

- 终结路径0x6EBEE9..0x6EBEF0 ->0x6C9B20选择命中目标及其+0x198关联值等于该选择器的目标，并调用0x6CD770执行资源定义的终结效果；相同位置或相同资源名本身不构成关联。
- 加载器0x6C8D9A..0x6C8DA0将源+0x334复制到目标+0x198；状态2与终结效果按各自调用处理。

## D00E按关联选择器回收

- D00E回收0x6C9B20将目标的关联字段+0x198与指定选择器比较；相同坐标或相同MMO资源名不能替代该关联条件。加载器将源+0x334复制到目标+0x198的完整链、状态2与终结效果调用见[普通终结和碰撞信道](#kb-06-011)；0x6CD770执行终端/状态2效果。共享MMO不是链接证明。

## 普通目标、源攻击和选定资源

| 边界 | 地址/调用链 | 验证用途 |
|---|---|---|
| D00D普通攻击 | 构造函数 `sub_708640`；构造函数 `sub_6E9D40/sub_6E9E20`；调用点 `0x006713FC/0x0067148E/0x00671856` | 指令 `0xD00D`，长度20；拥有者 WORD `+0x0C`，目标向量索引 BYTE `+0x0E`（原生兼容解析将其命名为 `source_index`，不表示协议已证明它是PON来源行），效果 BYTE `+0x0F`，选择器 DWORD `+0x10`；无伤害/致命伤害 |
| D00E 分派 | `0x006EBC50..0x006EBC66 -> 0x006EBE05` | Opcode53262 接收边界 |
| 终结选择器 D00E | `0x006EBEB1..0x006EBEC8`；`0x006EBEE9..0x006EBEF0 -> sub_40C0C2 -> sub_6C9B20` | 状态 `+0x1A=200`，选择器 WORD `+0x18`，匹配场景行中的终端/呈现 |
| D00E 仅评分 | `0x006EC884..0x006EC8E1` | 状态非200；更新评分 DWORDs `+0x08/+0x0C/+0x10`，无选择器终端调用 |
| D00E 预加载池回退 | `0x006EC5F8..0x006EC61D -> sub_6A0720` (`0x006A0720..0x006A07C8`) | 在当前行缺失后，遍历阶段管理器 `+2924`，通过 `sub_4100E6` 比较相同的选择器，返回匹配的对象 `BYTE+0x1A` 并调用 `sub_40C0C2`；零表示没有回退匹配 |
| D00E 选择器缺失警告 | `0x006EC786..0x006EC850`；值 `0x006EC864..0x006EC87C` | 本地项目类型 outside1/2/3/4/5/10，尤其是0，会打印CP949预加载池/ItemUID警告；`NpcUid=WORD+0x18`，`iItemType` 是本地查找输出，不是D035字段 |

```text

sub_69FB10 读取当前 SMMO 槽位索引，位置为 stage+0xB49

sub_69F830(stage, slot) 返回百分比字节 stage+0xB40+slot

sub_419961 -> sub_6C27A0 接收该百分比

资源目标记录 +0x10C -> 运行时目标 +0x08 原始本地 HP

sub_41E5D3 -> sub_6CA6C0

0x006CA898..0x006CA8D4: target+0x08 = trunc(target+0x08 * percentage * 0.01)

PE double 0x00C59EB8 = 0.01

sub_6CA6C0 还初始化目标运行时状态；选择器写入位置为 target+0x2B0

sub_670E10 网络 D00D 调用点 0x6713FC/0x67148E/0x671856

sub_67A320 本地／教程控制器具有不同的 HP 归零调用链

sub_6CD770 处理本地终止／表现状态

```
上述调用链确认了现行SMMO路径的初始化公式：生成的`nominal_hp`是客户端本地初始HP。对于原始HP（`raw`）1459、slot110，客户端初始化为1604。因此，在原始HP边界观察到终结不能证明初始化时采用原始HP；还需分析伤害、状态修改及生命周期。

本地呈现无法证明权威性的移除或波次完成。
