# 业务／DIY／子弹

子弹 DIY 通过客户端 PON 资源选择、独立篮球外观派生和可选 x86 发射桥接接入。现有实现提供选择已有资源与一个已审核的篮球实例；新子弹资源须自行补齐资源目录、依赖、安装身份和验证，界面没有任意资源编辑或通用反向移植能力。

| 子页 | 解决的问题 |
|---|---|
| [接入与资源链](接入与资源链.md) | 选择复用／外观派生策略，区分文件名、owner、行编号与协议身份 |
| [配置与兼容策略](配置与兼容策略.md) | 目录、预览、独立 INI、别名与反向门控如何协同 |
| [验证与伤害边界](验证与伤害边界.md) | 安装、隔离执行与实机验收如何分层，客户端外观如何关联适配器伤害 |

| 工程与操作入口 | 用途 |
|---|---|

| [子弹 DIY 兼容](../../../工程/子弹DIY兼容/README.md) | 安装配方、精确输入身份、迁移和卸载 |
| [子弹资源事务](../../../工程/资源安装/子弹资源事务.md) | 文件事务与冲突保护 |
