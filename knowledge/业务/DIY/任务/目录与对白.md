# DIY／任务／目录与对白

## 范围与边界

本页维护任务DIY的编号、目录派生、本地化及显示投影。章节采用独立73系列，通用任务字段归[任务窗口](../../角色/任务/窗口协议与客户端消费.md)，章节目录与状态归[章节剧情](../../角色/任务/章节剧情移植进展.md)。对白窗口与资源绑定见[对白与立绘](对白与立绘.md)，安装步骤及文件身份见[章节表与对白安装](../../../指南/客户端二进制补丁/章节表与对白安装.md)。

## 编号与格式

任务ID、目标ID、QS文本ID、SCRIPT UID、NPC UID、村庄页面及战斗episode分别维护。DIY定义须显式关联这些身份：任务引用目标，目标关联动作，动作指定说话者与QS，场景绑定村庄与页面，结算绑定章节对应的战斗身份。SCRIPT10000表示脚本，QS10000表示文本。

| 对象 | 当前约束 |
|---|---|
| 普通卷轴与勋章 | 基础目录含204个可购买卷轴、217项任务、357个目标；71系列使用固定type1槽。 |
| 章节任务 | `73000000..73000015`连续16章，使用固定type2槽；第16章后继为0。 |
| 章节目标 | 每章入口、战斗、出口三项目标；第四／八／十二／十六章增加本村修道僧目标，共52项。 |
| 目标类型 | 章节入口／出口从目录类型39投影为CN类型1，战斗保留40，修道僧保留1；类型与参数由对应执行策略共同解释。 |
| 正文脚本 | SCRIPT10000..10031承载32组入口／出口动作；另4组修道僧动作引用既有定义。 |
| 章节文本 | 139条QS包含107条正文、16条章节说明和16条奖励说明；另维护16个标题、52个目标名和18名说话人。 |
| 完整安装表 | QT含409目标／233任务；QS含772条记录，其中633条为基础文本，含12条修道僧文本。 |

目录按结构解析可变目标数组、平行值数组、奖励三元组、后继、附加字段与尾部NPC绑定。附加三元组保留纹理路径和名字等实际类型；目标原始字段、动作属性、空的`dungeon/level`属性与`CONDITION goto`均随定义保存。跨版本编译按目标客户端布局投影，字段宽度见[CN章节接入边界](../../角色/任务/窗口协议与客户端消费.md#cn章节接入边界)。

目录校验覆盖输入摘要、唯一ID、完整尾部、目标顺序、章节后继、脚本／QS引用与覆盖计数。离线目录包含`catalog.json`、`localization-review.json`和`manifest.json`，同一输入可重派生并逐字节核对。安装表支持从第一章开始的连续前缀，一章为360目标／218任务／637条QS，四章为370／221／660，十六章为409／233／772；前缀目标增量为`3c + floor(c/4)`。

## 本地化与显示投影

`manifest/story_localization.json`维护完整译文、原文、说话人名字及逐项审核字段；`manifest/story_terms.json`维护术语与任务面板短文案。审核模板以`approved=false`起始，文本审核、奖励授权及章节启用各自维护。

中文使用严格GBK编码，格式允许集合、NUL终止空间与编码后字节数共同构成输入约束。保留`%s`等占位符的种类／数量、`%%`字面百分号和`^&`显式断行；目录分隔符`#`及内嵌NUL属于保留字符。当前客户端正文将16处`%s`显示为“收集者”。动态名字属于扩展接口，其输入须有界读取，并按替换结果重新计算GBK行宽和页数。

| 显示位置 | 字节与行数约束 | DIY用途 |
|---|---|---|
| 任务说明／奖励面板 | 每行最多30个GBK正文字节，另留NUL；奖励总行数至多为QT奖励项数 | 按显示槽编写精简而完整的说明。 |
| 章节客户端对白 | 每页4行、每行51字节存储，最多50个GBK正文字节并以NUL终止 | 逐段保留完整正文，按字节分页。 |
| 宿主对白分页 | 每行最多48个GBK正文字节、每页4行 | 保留动作内页索引、动作末页标记与说话者。 |
| 章节名字 | 24字节槽含NUL，写入40字节原生名字字段 | 当前最长名字22个GBK字节，完整显示状态修饰与复合名称。 |

任务面板消费规则归[任务面板文本容量](../../角色/任务/窗口协议与客户端消费.md#任务面板文本容量)。六条短文案投影为QS3026／3032／3036／3113／3119／3127，完整译文继续保留在本地化所有者中。第五章五项奖励分别占一行；奖励ID、数量、期限与性别映射由奖励定义决定。面板文案和正文分页分别生成。

## 术语与资源身份

术语覆盖角色、村庄、卡片、宠物、装备及道具，按实际ID维护。QS1000“尼莫”、QS506“恰恰”、QS552“伊露卡”、QS1012“小云云”、QS1013“卡片册／魔法钥匙／特殊卡片”和GS8030“黄金粉末”沿用对应目录称谓。卡片20／37／59／73／111的合成说明分别为“蓄能药水40／紫色兔子／小斑点狗／耍宝小猕猴／帅帅的哈士奇”。

章节NPC18／28／30分别为李小成／蒂米／秃鹫。NPC33的章节名字及正文统一为“阿雅塔”，QS533基础条目称谓“阿郁塔”按原字段保留。普通第八章首领使用“不老的始皇帝”，秘密关卡使用“青龙大帝里斯”；剧情状态修饰、咒语动作和黑色剪影按叙事语义维护。当前术语与奖励映射归[术语与奖励本地化](../../角色/任务/章节剧情移植进展.md#术语与奖励本地化)。

`manifest/story_portrait_resources.json`统一登记18名正文角色与37项EFF／IM3依赖，包含NPC53..56。动作中的NPC／expression集合、EFF依赖、图片头、文件大小与摘要联合校验，同名同字节资源可复用，同名异字节资源按冲突处理。完整文件清单与资源安装归[章节资源](../../../指南/客户端二进制补丁/章节候选资源.md#完整立绘文件清单)。

## 发布资格

当前目录与程序集包含十六章数据、状态机、奖励事务和客户端对白载荷。章节默认开启，逐章奖励审核单独控制发放资格；离线准备产物的`activation_allowed=false`不代表服务默认关闭，完整流程仍为`runtime_acceptance=false`。默认起始归[章节规则](../../角色/任务/章节剧情移植进展.md#适配器闸与章节前缀)，已确认的第一至四章对白展示与其他功能分别按[版本归属](../../../工程/验证状态/章节剧情与跨村门槛.md)登记。
