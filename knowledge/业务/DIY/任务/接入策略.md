# DIY／任务／接入策略

## 当前能力

任务DIY同时定义目录身份、显示内容、满足条件、奖励事务和安装身份。现行实现分别维护普通任务、勋章主线与章节链，各类任务按自己的目标语义和槽位运行。

| 层 | 可复用能力 | 适用范围 |
|---|---|---|
| 普通任务 | QH／QT、十个type0槽位、动态条件评估与持久目标进度 | 通关、组队、限制条件、家具、收徒、技能及持有条件。 |
| 勋章主线 | 71系列、固定type1槽、领取账本及终章礼包 | 13项主线、12枚勋章与独立终章兑奖。 |
| 章节目录 | 73系列、固定type2槽、连续前缀、逐动作与逐段映射 | 16章、52目标、107段正文及18名说话人。 |
| 章节推进 | 房间事件、可信结算、目标修订号、任务槽投影 | 入口、超级BOSS、出口及四章一次的修道僧步骤。 |
| 章节奖励 | 显式审核、性别映射、期限、整包事务与领取账本 | 玩家主动领取，成功后推进下一章；第16章提交完成标记。 |
| 对白窗口 | 分段正文、完整名字、逐段立绘、原生窗口注册及回收 | 章节持有独立状态与正文区域，复用既有窗口框体。 |
| 独立挑战与跨村 | 四村挑战、胜败分支、排名、永久通关位及可选交通授权 | 挑战成绩、章节完成凭据、跨村开关各自归属。 |

跨村策略归[修道僧跨村授权](../../角色/新手引导/跨村前置.md#修道僧跨村授权)。章节与教程后的自动起始默认开启，既有章节按持久进度恢复；配置优先级、诊断禁用和新记录资格归[章节默认启动](../../角色/任务/章节剧情移植进展.md#适配器闸与章节前缀)。

## 第一章闭环

当前链路为「活动type2任务 → 本章所属村庄和入口房间 → 本章超级BOSS成功结算 → 返回对应房间 → 出口阶段 → 玩家领取 → 下一章」。第四／八／十二／十六章在出口之后增加修道僧步骤，接受该步骤激活后的本村成功结算。

适配器以房间事件确认剧情阶段，客户端以任务记录选择正文、说话人和立绘。逐页阅读状态属于显示生命周期；奖励资格由持久目标与审核决定。宿主逐页票据接口另绑定任务、修订号、场景代次和在线会话，其构造检查范围由[章节验证](../../../工程/验证状态/章节剧情与跨村门槛.md)维护。

## 内容定义契约

新增或调整任务时，以下内容组成一份完整定义：

| 定义项 | 必须明确的内容 | 主入口 |
|---|---|---|
| 身份 | 任务／目标／QS／SCRIPT／NPC身份、槽类型、前后继及目录布局 | [目录与对白](目录与对白.md) |
| 场景 | 村庄、页面、本章episode、入口与出口阶段 | [目标与奖励](目标与奖励.md#场景与战斗条件) |
| 动作 | 说话人、表情、正文、动作顺序、段索引、页索引与末页语义 | [对白与立绘](对白与立绘.md) |
| 目标 | 满足事件、实时条件或持久条件、计数、步骤修订号与结算身份 | [目标与奖励](目标与奖励.md) |
| 奖励 | 逐项种类／ID／数量／期限、性别映射、审核绑定、容量及单次发放 | [奖励事务](目标与奖励.md#奖励事务) |
| 兼容 | 当前目标投影、已有任务进度、历史领取和永久权益的保留规则 | [存档与重复操作](目标与奖励.md#存档与重复操作) |
| 交付 | 两端QT／QS、程序位点、立绘、父资源身份、安装收据及恢复范围 | [章节表与对白安装](../../../指南/客户端二进制补丁/章节表与对白安装.md) |

各类持久状态按用途分开：目标账本保存实际满足条件，任务槽服务客户端显示，显示游标管理段落，领取账本保证单次发奖，安装收据维护文件所有权。它们通过任务身份和修订号关联。

## 进度与事务设计约束

当前目标索引始终落在QT目标数组内，全部完成时保留末项；普通多目标的累计数、章节剧情阶段和当前目标索引各自维护。任务类型决定`Progress3`的解释，槽位投影统一由该任务所有者负责。

确认资格由账号、角色、在线会话、当前任务、场景及修订号共同约束；战斗事件再绑定本轮结算身份。已提交结算提供持久目标结果，重复事件保持幂等。宿主会话票据以场景／战斗代次区分有效期，取消、重新进入场景或消费后按当前状态重新取得票据。

奖励、领取记录和下一章状态使用同一数据库事务。普通卷轴、勋章、师徒计数、终章礼包及章节分别沿用所属事务；共享库存与成长能力按完整奖励计划调用。旧表迁移按已登记结构匹配，精确匹配的旧Episode5起点结构可扩展到Episode1；额外字段、触发器或索引按未知结构拒绝迁移。

## 发布与验收范围

当前发布包含章节目录、程序集、对白载荷及配套资源，章节默认开启。奖励授权仍依赖当前包对应的独立审核；审核模板按16章列出原始三元组、映射、期限与审核字段。只读奖励目录审计保留`grant_allowed=false`，默认启动不自动批准奖励。

已确认的客户端范围包含既有第一至四章分段对白与完整名字、第一章入口对白和立绘，以及用户确认的十六章连续推进、多目标进度、逐页交互和异常窗口生命周期；具体证据与受测版本待补录状态归[章节验证](../../../工程/验证状态/章节剧情与跨村门槛.md)。离线包`activation_allowed=false`不决定服务启动默认值；逐章奖励实际领取／穿戴与跨村授权仍待确认，整包`runtime_acceptance=false`不自动改写。

验证清单按层划分：目录覆盖与引用、GBK及名字容量、窗口状态、任务条件与事务、安装资源身份、客户端可见效果。交互范围包含取消重播、重登、结算返城、四村场景与立绘、背包满、重复领奖和链尾；性别与期限覆盖男女逐章奖励及同款限时装升级永久。程序和资源操作集中在[二进制补丁指南](../../../指南/客户端二进制补丁/章节表与对白安装.md)。
