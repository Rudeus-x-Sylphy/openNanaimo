# DIY／地宫／计分板接入方案

## 范围与状态

本页定义现有地宫生命周期内的计分板扩展契约。布局和字段容量归客户端，成绩来源、排序和更新资格归适配器。通用规则见[评价持久化与排行榜](../../地宫/计分与结算/评价持久化与排行榜.md)，具体表、缓存分配和程序位点见[修道僧实例](修道僧结算与进度.md#四关排名与成绩展示)。

修道僧实例采用四关单槽评级和十名成绩榜；指令、资源与事务分别校验。客户端排行榜已获用户验收确认，范围与受测版本待补录状态见[四关排名验证](../../../工程/验证状态/修道僧挑战验收.md#四关排名验证)；原清单`runtime_acceptance=false`不自动改写。

## 成绩与持久化

查询维度由玩法定义，不能向单关玩法强加普通地宫的难度矩阵。修道僧以角色和挑战编号唯一定位，兼容字段Difficulty固定0；普通、秘密和第五村保留原有多难度模型。个人最佳、队伍最佳及成功收据各有唯一归属；D/C成功状态和B/A/S可见徽标分别定义。分数与评级保持各自的最大值，可靠耗时缺省用NULL表示。

成功提交绑定在线账号、角色、会话、战斗代次和结算轮次，在同一事务保存收据、进度和成绩。重复提交幂等、陈旧与越权提交拒绝、失败全事务回滚；旧档通关位与新成绩分别维护，删除角色时处理所属引用。

十名榜单排序沿用通用规则，包含同分次序、空榜和空行零填充，字符串按编码容量截断并保留终止符。显示选择器用于合法视图选择，真实查询键来自授权会话。异步返回时再次核对角色、worker、战斗代次与当前选择。

## 缓存与更新

- 初始恢复使用C354→C355，在已登记容量内写入评级缓存，保留普通、秘密、第五村与挑战的各自区间以及相邻姓名、戒指字段。
- CF71采用当前关卡和逻辑难度的最佳评级；D/C成功记录对应空白徽标。
- CF88在当前本人结算资格内更新所属评级槽，按角色、房间、地图与战斗周期管理状态生命周期。单槽字节与多难度两位字段不能混用。
- CF15驱动CF16查询结果，托管与保留原生出口使用同一账本，并覆盖建房、加入、重试、返城、重登及worker复用。
- 全开放开关维护进入资格，成绩始终取自真实结算；重登恢复属于只读投影。

## 窗口与布局

| 项目 | 实现约束 |
|---|---|
| 适用范围 | 精确玩法元组进入扩展分支，其他元组返回原路径 |
| 行列 | 行列只反映真实玩法；修道僧使用原生数字贴图在Epi框内显示01／02／03／04，每行一个评级格 |
| 生命周期 | 复用窗口类型、虚表、关闭按钮、更新和释放，处理分配失败 |
| 绘制 | 保持原文本ABI、栈、寄存器、标志和绘制顺序 |
| 评级位宽 | 多难度缓存每难度两位；挑战每行一个0～3字节，不向高位填充其他难度 |
| 榜单容量 | 固定十行记录步长、空行初始化与字符串终止符 |
| 扩展指标 | 额外数值列、分页和新图标需独立定义存储、授权、字段容量与消费规则 |

四关单槽复用已定义缓存和现有图标，专用背景须同时去掉普通地宫图像内烘焙的表头和空格，不能仅减少徽章绘制次数。挑战模型按四关单槽定义。通用可视编辑器、任意列配置、跨区域汇总、季／周榜及主动推送属于独立扩展设计。
