# DIY／NPC／身份与场景

定义村庄／页面身份、可见位置、命中中心与脚底排序根。

## 组成与身份

一个NPC由村庄页面记录、场景EFF及IM3、名牌图像、命中区域、对白控制器、本地化文本和对白立绘共同组成。地图中的可见位置与输入命中中心使用同一坐标；场景排序另用脚底坐标。四村修道僧分别绑定本村出口页面与单人挑战。

## 位置与场景渲染

| 项目 | 数据／消费链 | 作用 |
|---|---|---|
| VIL记录 | `(village+1)*10000+page` | 定位本村出口页面。 |
| 可走格点 | 50×36格点、单元步幅36字节，type1／WORD+14 | 普拉塔诺斯村和萨恩村位置的中心及四向12像素采样值均为0；派生保留前四村道路、碰撞、交通及格点数据。 |
| 排序层 | VIL第1层 | 与城镇角色按世界Y排序；第2层前景不提供相同的角色深度关系。 |
| 绘制链插入 | `0x9DBA60 → 0x40FB69 → 0x9DCA40 → 0x417184 → 0x4D7B50` | 按placement层号消费对象，并比较对象Y插入链。 |
| 障碍位置 | 普拉塔诺斯村Y168栏杆、萨恩村住宅碰撞区 | 本例NPC分别位于栏杆前方和住宅碰撞区外。 |
| EFF引用 | 四村独立身体图像、共用阴影、中文名牌 | 名称和图像与各村身份配套。 |
| 排序根与轨道 | 根Y=中心Y+26；阴影／身体／名牌Y常量为0／-43／11 | 重定位后保持三者原世界位置及命中中心关系。 |
| 身体足点 | 局部底边y=93、半高50，`-43-50+93=0` | 身体脚底和阴影中心共同落在排序根。 |
| 更新与角色足点 | 场景`0xAB5FB0 → 0xAC1BC0`；角色`0x4FCCC0` | 场景物与城镇角色按各自足点参与统一排序。 |
| 安装原子性 | 地图与四个EFF | 属于同一事务，避免只换placement或只换轨道造成错位。 |
