# DIY／NPC／输入与对白

定义点击、悬停、GBK分页、窗口创建、绘制与回收。

## 命中与输入

| 职责 | 消费点／字段 | 规则与作用 |
|---|---|---|
| 命中与资格 | 村庄更新`0x527CCD` | 接入点击控制器；命中矩形为中心X±24、Y±48，要求当前村庄／出口页面匹配、光标对象有效且背景输入可用。 |
| 鼠标位置 | `0x52AA50`、村庄`+0x334` | 把鼠标坐标写入光标对象。 |
| 悬停反馈 | `0x52A751`在`0x527C80`之后 | 复核命中，经`0x402770 → 0xAB35E0`设置手形1；门类光标编号为5，窗口按钮沿用原生光标。 |
| 输入快照 | `0x41F861 → 0x52A520 → 0xAD04E0` | 更新本轮与上一轮输入。 |
| 左键按下沿 | `+0x21C=0x80`且`+0x22C!=0x80` | 每次按下产生一次开窗动作。 |
| 左键松开 | `0x415ED3 → 0x4EA7A0(0)` | 为需要松开语义的独立控件提供检测；与NPC按下沿分别定义。 |

## 对白分页与窗口生命周期

| 阶段 | 结构／消费点 | 行为 |
|---|---|---|
| 分配与构造 | 窗口0x400字节，`+0x200`内嵌0x16C字节引导对象；`0x4163BF → 0xA12610` | 构造窗口与引导对象；`0xA12CC0(0,0)`加载底部框及下一页／结束按钮。 |
| 正文分页 | 每页四行，每行51字节 | GBK内容上限48字节，以NUL结尾；多字节字符按编码后长度校验。 |
| 布局 | `0xA13C00` | 框体中心`400,300`、名字`60,474`、正文`61,507`、按钮`479,550`。 |
| 按钮与键盘 | 更新`0x414353 → 0x7B2470`，命中`0x4169A0 → 0x7B2630` | 按钮返回5推进，Enter使用相同分页逻辑，Escape关闭。 |
| 末页动作 | 来源校验 | 入口对白末页进入本村挑战；结果对白末页完成关闭。 |
| 窗口状态 | `WORD+0x34` | 1表示打开／翻页，2表示关闭。 |
| 回收与摘链 | 回收器`0x7EC5C0`、消费点`0x7EC5F2..0x7EC5F7`、虚表`+0x0C` | 当前`0x6E4600`仅对关闭状态返回1；经`0x7EC605 → 0x4123A0 → 0x7ECD70`摘链，`0x7EC644`调用析构。 |
| 析构顺序 | `0x41B6A8 → 0xA12790`，再`0x4D7830` | 先释放引导对象资源，再释放窗口。 |
| 最终UI绘制 | 普通点`0x527852`；修道僧独立点`0x5278F1` | 反向遍历窗口链，对虚表匹配且状态1的窗口绘制正文与立绘一次；经`0x41CB16`绘制光标。 |

绘制顺序为城镇及聊天／HUD → 修道僧对白 → 光标。窗口状态、回收资格和显示顺序共同约束对白生命周期。
