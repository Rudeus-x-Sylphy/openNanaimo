# DIY／NPC／接入策略

本页从四村修道僧的场景派生和CN对白控制器提取接入顺序。现有实现是明确的四村特例；新增NPC需要修改相关表、代码配方及清单，没有只填一份JSON就能注册任意NPC的通用接口。

<a id="接入契约"></a>

## 接入约定

| 层次 | 必须明确的输入 | 实现入口与消费目的 |
|---|---|---|
| 场景身份 | 村庄0～3、页面27／26／12／6、独占的场景纹理UID | `scripts/monk_dialogue_compat.py::ENTRIES`与`prepare_monk_dialogue.py::derive_pack`共同定位VIL记录`(village+1)*10000+page`。 |
| 世界位置 | 显示／点击中心、可走格点、排序根 | `prepare_monk_entry.py::MONK_LAYER=1`；`prepare_monk_dialogue.py::MONK_FOOT_Y_OFFSET=26`同步第1层placement与三条EFF Y轨道。 |
| 场景图像 | 身体、阴影、名牌及其EFF引用 | `prepare_monk_entry.py`生成名牌；`prepare_monk_dialogue.py::foot_origin_effect`只接受原始或已重定位布局，防止重复转换漂移。 |
| 输入 | 页面资格、背景输入可用、鼠标对象、按下沿、手形光标 | `monk_dialogue_compat.py`生成命中、更新和悬停代码；命中中心与场景中心使用同一表。 |
| 文本与分页 | 名称、入口及结果文本ID、GBK编码、每页四行 | `manifest/monk_localization.json`是文案来源；分页正文每行51字节，GBK正文上限48字节，须在编码后检查字节长度。 |
| 窗口与立绘 | 本村立绘、分配失败处理、对象所有权、关闭／释放 | 原生引导框、立绘更新和析构复用；独立最终UI绘制点保证对白位于HUD之上、光标之下。 |
| 动作 | 对白末页要触发的业务动作及来源验证 | 修道僧样例调用地宫入口8～11；对白文本不会自动创建适配器资格规则。 |
| 返城反馈 | 本人UID、来源村庄／页面／坐标、挑战代次与一次显示资格 | `monk_dialogue_compat.py::followup_payload`与[来源与返城](来源与返城.md)绑定本次结果。 |

## 修改与验证顺序

1. 确定NPC唯一身份、业务动作和允许出现的场景；同步修改场景表、点击表、动作资格与立绘映射，记录所有保留的其他NPC、格点及道路。
2. 检查中心与四向12像素位置的可走性。调整脚底排序根时，同时重定位阴影／身体／名牌轨道；排序层号和位置属于一项视觉约定。
3. 在本地化清单维护显示名称与文案。场景名牌是IM3图像，对白名字是文字绘制；更名需分别更新两个入口。
4. 用匹配输入在独立目录生成地图、EFF、IM3、立绘与UI；审查引用闭包及输出摘要后更新场景清单、客户端兼容配方和启动器内嵌版本。
5. 生成并验证CN二进制补丁。核对PE虚拟地址、目标位点原字节及代码区容量；不能把本例VA直接套到另一语言或另一大小的客户端。
6. 验证点击一次只开一个窗口、Enter／按钮分页、Escape关闭、分配失败不丢结果、立绘只更新一次、关闭后资源释放，以及回到原页面原位置后仅显示本人本次结果。
7. 完成[源码与验证](../地宫/源码与验证.md)中的静态／事务检查，再按[修道僧挑战验收](../../../工程/验证状态/修道僧挑战验收.md)登记客户端画面和交互结果。

## 历史入口与现行入口

| 状态 | 文件 | 适用含义 |
|---|---|---|
| 场景预览 | `prepare_monk_entry.py` | 只派生场景图像，无交互入口安装；看到NPC不能证明点击和挑战已接入。 |
| 第五村旧入口 | `prepare_monk_village_entries.py`、`manifest/monk_village_entries.json` | 记录旧action168～171与前景标记；供已发布包识别及迁移。 |
| 当前四村对白 | `prepare_monk_dialogue.py`、`manifest/monk_dialogue_resources.json` | 安装四村NPC与37项场景／立绘／UI，清理旧第五村挑战动作；原生地宫7／8道路及返回身份继续由其自身规则维护。 |

代码依据：场景派生器（`scripts/prepare_monk_dialogue.py`）、场景与名牌生成器（`scripts/prepare_monk_entry.py`）、CN对白代码生成器（`scripts/monk_dialogue_compat.py`）。返回[NPC索引](README.md)。
