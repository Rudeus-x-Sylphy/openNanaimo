# DIY／NPC／立绘与动画

定义四村立绘资源、原生对象所有权、更新与绘制。

## 立绘与动画

| 资源 | 数量／格式 | 引用关系 |
|---|---|---|
| `effs/interface/NPC_62_0.eff`至`NPC_65_0.eff` | 4项，EFF2各三行 | 每村依赖对应的`NPC_N.im3`与`NPC_N_b.im3`。 |
| `NPC_62.im3`至`NPC_65.im3` | 4项，230×300、IM3 v2／format10 | 立绘主体。 |
| `NPC_62_b.im3`至`NPC_65_b.im3` | 4项，230×300、IM3 v2／format8 | 配套立绘图像。 |

12项文件共同登记于`manifest/monk_dialogue_resources.json`（该清单共37项）。

| 生命周期 | 消费点／字段 | 行为 |
|---|---|---|
| 初始化输入 | `INIT_PORTRAIT=0x739080`，ECX引导对象、EDX村庄0～3 | 村庄与分配结果通过校验后才提交肖像槽。 |
| 分配／所有权 | 分配0x144字节；`0x41BE00 → 0xAB6910`构造`CPtcGrp` | 由`guide+0xF4`持有。 |
| 加载／位置 | `0x404232 → 0xAB6B60`，五参数`(path,0,400,300,0)` | 加载本村EFF，位置沿用`guide+0x12C/+0x130`。 |
| 原生名字查找 | `0xA12EC0`使用`guide+0x118`与数量，生成`interface\NPC_%d_%d.eff` | 本例用独立加载接口保持中文名字与村庄立绘的确定对应。 |
| 每帧更新 | 肖像虚表`+0x10`一次，再更新框体 | 推进透明度与滑入轨道，避免重复动画步进。 |
| 绘制 | `0xA13630`经`guide+0xF4+4*guide[0x14C/4]`调用虚表`+0x14` | 当前肖像索引0。 |
| 释放 | 原生析构释放`guide+0xF4/+0xF8` | 沿用引导对象的资源所有权，避免重复释放或泄漏。 |
