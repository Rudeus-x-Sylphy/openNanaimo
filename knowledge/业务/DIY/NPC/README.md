# DIY／NPC

以四村修道僧为已实现样例，维护自定义NPC的位置、场景、输入、对白、立绘和返回位置。完整接入步骤见[接入策略](接入策略.md)，战斗与进度见[DIY／地宫](../地宫/README.md)，安装和恢复见[四村对白安装](../../../指南/客户端二进制补丁/修道僧四村对白安装/README.md)。

本例代码位点是已登记CN布局的PE虚拟地址（VA），不能直接当文件偏移；`对象+偏移`相对该对象基址。地图／角色坐标、EFF局部轨道和排序根各有独立基准，安装前核对精确原字节及资源清单。

| 子主题 | 作用 |
|---|---|
| [身份与场景](身份与场景.md) | 定义村庄／页面身份、可见位置、命中中心与脚底排序根。 |
| [名字与本地化](名字与本地化.md) | 定义场景名牌与对白名字的不同渲染入口及统一文本来源。 |
| [输入与对白](输入与对白.md) | 定义点击、悬停、GBK分页、窗口创建、绘制与回收。 |
| [立绘与动画](立绘与动画.md) | 定义四村立绘资源、原生对象所有权、更新与绘制。 |
| [来源与返城](来源与返城.md) | 定义来源坐标冻结、返城恢复、结果对白资格与安装约定。 |
| [接入策略](接入策略.md) | 从修道僧代码提取新增或替换NPC所需的同步修改与验收顺序。 |

章节对白和任务进度连接见[任务DIY](../任务/README.md)；既有修道僧的窗口、立绘、中文文本和挑战身份优先复用，不为章节移植创建另一套NPC。
