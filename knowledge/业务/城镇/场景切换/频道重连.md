## 规则与证据

<a id="kb-01-005"></a>

<!-- BEGIN 01-005 -->

### 游戏内切换频道

- 切换频道使用新建的 **类型 10 登录连接**执行 `271B/12 -> 271C/176`。
- 选择频道后关闭当前 **GS 连接 0** 和登录连接 10，再重建 GS0 并发送 `C351/24`。
- `C352 BYTE+0x08==100` 是重新进入完成条件；`WORD+0x0A` 安装新的场景／会话本地值。
- `0x271D` 虽注册于协议元数据，但已核实的 `CChangeChannelWindow` 操作链不会发出它。

频道重新进入只在旧代理连接与旧后端连接均完成释放后复用原逻辑槽位。重入凭据绑定账号、角色、来源端点和连接代次，并携带村庄选择器、页面及最后合法坐标；房间、战斗和过渡状态开启新的连接周期。

旧槽位在期限内未完成释放时，本次重入直接失败，不改用其他槽位。延迟角色附着同时绑定目标连接和角色连接的代次，任意一侧发生重入后，旧任务立即失效。

### 频道重新进入的状态恢复

频道切换保留账号、角色、逻辑槽位、村庄选择器、页面和最后合法坐标。旧连接的代理与后端两侧均完成释放后才允许复用；未完成释放的重叠进入不会占用其他槽位。同一来源存在多个会话时，身份和连接代次保持独立。

新连接重建村庄角色，并重新初始化房间成员关系、战斗状态、过渡状态和一次性标记。延迟角色附件只对创建它的连接代次有效，频道切换后不会落入新场景。

频道重入后的 `C354/C355` 按当前角色持久资料重新装载普通地宫通关位、普通／秘密／第五村评价和道路进度。默认采用逐关开放规则；显式启用 `UnlockAllDungeons` 时，普通角色采用全开权限投影，纯新手仍采用持久进度。三类评价缓存始终按实际成绩恢复，权限投影与数据库通关记录分别保持独立。

普通地宫的三档难度按[普通地宫进入资格](../../地宫/关卡与房间/房间身份.md#普通地宫进入资格)恢复；第五村前置、L1至L8的道路开放与末端边界归[五村顺序解锁](村庄拓扑与兼容资源.md#五村顺序解锁)。重入专项与完整启动集成的当前结果见[频道重入与启动自检](../../../工程/验证状态/地宫与成长验收.md#频道重入与启动自检)。

### 频道选择器登录和GS重新进入

频道选择器使用新的登录连接10完成 `271B/12 -> 271C/176`，随后关闭当前 GS0/login10，按选定 IPv4 与已保存 GS 端口重连 GS0，并发送 `C351/24 -> C352`。原连接和适配器会话释放后，在来源 IP 唯一匹配时保留逻辑槽位；角色重建保持请求驱动。

- 每次新登录均初始化帧头：S2C 序列从0开始；第一个完整请求为该套接字固定 `checksum_seed=low5|(low5<<8)`；每个响应复制触发请求的低5位。
- 适配器构造验证覆盖首次低09/16/0E、`0,1..100,1` 序列环、后续响应低位复制、UID21复用及C355资料状态一致性；这些结果不构成客户端运行验收。
- 调用地址见[频道切换调用链](#kb-08-015-1)。

### 频道切换调用链

下列地址按对应客户端映射解析；不同映射的地址不可互换。`CChangeChannelWindow`的RTTI及完整消费链是此处字段归属的依据。

| 边界 | 精确地址 | 已证行为 |
|---|---|---|
| 窗口循环／更新 | `0x00A6A150 -> 0x00A69620` | 应用 state23；以登录 type10 连接适配器 IP:11005；具有显式 Connect Fail 分支 |
| 通道列表请求 | 构造函数 `0x004E0810`；发送者 `0x00A6A000` | `271B/12` 在 connection10 上 |
| 通道列表分派/处理函数 | `0x00A699C0 -> 0x00A69A70` | `271C`；行数从0x0A开始计算，行位置从0x0C开始（`population WORD+0`，`index BYTE+2`，`IPv4 DWORD+4`），容量从0xAC开始；单行响应至少完整初始化176字节 |
| 点击/销毁/连接 | `0x004DE530` | 销毁连接的GS0，关闭登录10，使用保存的GS端口连接选定的IPv4作为连接0 |
| GS 重新接受请求 | 构造函数 `0x004DEA50` | `C351/24`，连接后立即发送 |
| 重新验收完成 | `0x00A699C0 -> 0x00A69C70` | `C352 BYTE+0x08==100`；安装 `WORD+0x0A`，离开选择器状态；失败返回选择界面 |

- `0x271D` 在协议元数据注册中仅出现一次，位置为 `0x0091A904`；从关闭的通道窗口链中没有到达它的构造函数/发送边。
- 该静态链确认客户端在销毁原GS后执行重连；适配器复用相同逻辑槽位的条件见[游戏内切换频道](#kb-01-005)。
- 静态链不证明销毁期间可创建角色，也不构成客户端运行验收。
