### 玩家经验载体和HUD静态调用链闭合

- 战斗分数、临时经验与结算入账分层处理：D00E/48的 `6EC8B7..6EC8D3` 和D012/60或64的 `6ED9B5..6ED9DA` 读取DWORD+8/+0xC/+0x10三槽分数，经 `403323 → 748990` 按row+0x288槽写row+0x28C（stride0x2C）并刷新数字；D010/36在 `6EF06B..6EF094` 读DWORD+0xC，经 `41CCD8 → 66E740` 的actor+0x7A4C槽进入相同写入链。
- 适配器保持这些实时分数字段原值。

- `40876F → 748C90` 排序显示后在 `748ED0` 选择本地槽；等级<80时 `748EF9..748F28` 乘double 0.25（C79948），经 `401005 → 74C190` 写global+FD0，等级≥80在748F37写零。
- 74C190仅由thunk401005引用，该thunk的调用点为748F28和748F37；`409133 → A76240` 按selector0/1/2返回原值／一半／零，`8E1620` 在8E1AF4/8E1B19把临时值加到 `4061CC → 834000` 的global+FCC已提交经验后钳到下级阈值。
- 兼容项在74C19A将setter输入清零，完整25字节门禁及精确三字节修改见[完整适配器与客户端兼容说明](../../../../指南/完整适配器与客户端兼容说明.md)；分数、CF88奖励和已提交经验保持原值。

- EXP字段闭合依据307条解析器／HUD指令。
- 0x6EBAC0完整分派器没有可用的反编译结果，相关case由IDA反汇编闭合，不能将其描述为完整反编译。
- 协议策略与数值来源见[200级经验状态与内部版本边界](权威状态与对外字段.md#kb-03-001)、[玩家累计经验范围与原生曲线边界](../曲线与经验奖励.md#kb-07-004)。

- C354 构造函数0x54DCD0（thunk0x41F9A6），状态1发送者0x52ACB0/0x52ACCD ->0xADA3E0（socket0）；C355 角色分派器0x531DA3 ->0x41646E ->0x530C90，全长728（最后WORD+0x2D6）。
- 从+0x28/+0x2C/+0x30读取当前/较低/下一个状态，并读取等级+0x23。
- C355+0x80/+0x84副本前提部分单独保留，不包含EXP。

- CF70/12构造函数0x708400通过thunk0x404165实现；控制器 `0x6E94C0` 在 `0x6E9506` 处构建，将控制器 `+0x7C` 复制到请求 `+8`，发送操作在 `0x6E951B` 处，指向 `0x40A821/0x6E90C0 ->0xADA3E0`（控制器套接字索引 `+0x78`）。
- 控制器有自己的0x40A96B门控条件；未引入未经请求的CF71。

- CF71 是0x6EBAC0中的 case53105。
- 本地 UID 分支0x6F4FD0..0x6F4FF5使用与 C355/CF88 相同的设置函数，将 DWORD+0x40写入 next、DWORD+0x44写入 当前值，不写 lower。
- level+0x48紧接在 grade+0x49之前应用。
- 保留的完整184字节响应覆盖既有角色／技能／复活尾部；没有依据改用更短的经验值专用数据包。

- CF87/12 构造函数0x7087F0 至0x40FDC1，发送者0x6EAA00 ->0x40A821；CF88 记录起始位置+0x0C，步长0x34，最小值12+52*count。
- 本地结果记录+0x14 低位 ->0x6FA399/0x41A7B7；+0x10 当前 ->0x6FA3B8/0x41587A；+0x18 下一个 ->0x6FA3D7/0x415ACD。
- 记录+4为升级标志，+0x0A为当前人物等级（u8，当前上限200）；该客户端结果处理链不重新计算HP/MP。
- CF88在`6F9D37..6F9D4B`按52字节步长读取UID，`6FA2CF → 407ACC → 761C90`按UID替换既有结果行（控制器`+0x448`、步长`0xAC`），总分落到`+0x4BC`，评级到`+0x4EC`，就绪标志到`+0x4E8`。
- 尾部`6FADE9 → 411FD1 → 762180`执行结果排序；当前兼容配方等长修改`762230/6`及`7622D7/154`，以unsigned最终总分降序、同分UID升序选择既有`762371`交换或`76240D`保持分支，保留`+0x4E8`就绪门控、原生交换／绘制路径以及行内评级／经验。
- 完整补丁应用、校验与恢复步骤见[客户端二进制补丁](../../../../指南/客户端二进制补丁/README.md)；隔离x86检查和适配器构造验证归[200级成套发布与数据版本](../持久化与离线迁移.md#kb-09-007-2)。

- 战斗分派器`6EBAC0`在`6EBDBA..6EBDCE`处理C57C：`[controller]`为完整帧，压栈后`404336 → 6EB6F0`。
- 后者依次读DWORD+0x10/+0x14/+0x0C，经41A7B7/415ACD/41587A写lower/next/current并清临时EXP；WORD+0x18经41714D→4D7C30写global+FDA当前HP，WORD+0x1A经4026DA→A757E0写global+FE2当前MP（逐字节异或0x46；A75850读取后恢复编码），BYTE+0x1C经40FEE8→A72570设置等级。
- 模式为2以外的值时还按本地UID更新三行房间名单等级与现有页面文字（409E80→8877D0）。
- BYTE+0x1D控制社交通知分支：0/5/10/15/20使用+0x20文本，0/20另读WORD+0x1E及BYTE+0x30；全覆盖最少49字节，适配器完整初始化52字节并选255走静默default。
- 尾部ADA730释放非空等待对象。
- 该接口负责全局／房间资料，战斗actor+0x7BAC由角色定向等级接口维护；结算由CF88独立处理。

- C60D/12在战斗分派器`6EBBD5`比较、`6EBBDF → 6F5935 → 40EF57 → 701B40`处理完整帧：WORD+8角色UID、BYTE+0x0A等级、BYTE+0x0B地宫称号，最高消费+11，最小12字节。
- handler遍历manager的队员链表（manager+0x18容器，head位于manager+0x1C），匹配UID后由`701B9F → 41EEE8 → 4D8CD0`写actor DWORD+0x7BAC；非模式2还更新匹配的三行房间资料+23等级／+22称号及现有页面文字，尾部释放等待对象。
- manager本地人物独立保存在+0x14（`66EA90`创建，`4179BD → 4D8CF0`读取），与队员链表分别管理。
- 本地分支`701BB4..701BE6`通过兼容项完成指针缓存、身份校验及等级setter调用。

- 战斗人物脚边绘制`6DBD60..6DBD83`经`415D57 → 6E7570`读取actor+0x7BAC，再按文本资源0x1F87格式化。
- 兼容项`battle_local_level`精确替换`701BB4`起51字节，先缓存本地指针、检查非空和UID，再跳`701B94`复用已有setter，随后保留房间更新及返回路径；使用原有代码区并保持actor／PET身份、HP/MP和Power连续。
- 完整字节及应用、校验、回退步骤集中于[完整适配器与客户端兼容说明](../../../../指南/完整适配器与客户端兼容说明.md)。
- 当前确认范围为静态接口约定及隔离指令分支。

- 共享设置器：0x41A7B7 -> 0x4D7BC0 写入 Character+0xFC8 下；0x41587A -> 0x4D7BE0 写入+0xFCC 当前并清除临时收益+0xFD0；0x415ACD -> 0x4D7C10 写入+0xFD4 下一个。
- 等级 0x40FEE8 -> 0xA72570 仅设置等级字段，不设置阈值。

- HUD0x8E1620 从地址0x41BDC9/0x833FE0、0x4061CC/0x834000、0x40AD8A/0x834020 读取 lower、当前值、next 信息，并将这些信息分别存入 HUD+0x448、HUD+0x44C、HUD+0x450。
- 模式0x40A3E4/0xA74410 选择当前值是否包含临时增益（通过地址0x409133/0xA76240，分别表示单独奖励模式0、1、2）。
- 它在进行无符号减法/除法之前将当前值限制为下一个值；百分比格式化器是0x8E1D24 ->0xB47637。
- 接近100%的结果在发生下溢时不是有效的进度状态。
- 归一化快照设置器通过现有的本地路径清除临时增益。
