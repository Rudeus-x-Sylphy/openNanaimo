## 原版机制与数值边界

- 原版 `QS._D31` 文本10028要求携带12枚勇者勋章找地宫门口的哈希奥；10026明确以12枚勋章交换礼包；10027为“哈希奥的大礼包1个”。`GQ._D32` 引导6关联奖励文本10027。
- 客户端 `0x527A90` 在入口值49且本地勋章字节等于12时进入终章；`0xA59A20` 展示10026并经 `0x402E00 → 0x4D5460 → 0xADA3E0(0,frame)` 提交 `C599/88`，载荷 `WORD +0=7`、`WORD +2=0`、`DWORD +4=6`，72字节尾区不解释为奖品。
- `0x4D7A00` 构造opcode和长度；`0x4D34D0 → 0x4D56A0 → 0xA14900` 在引导状态22消费 `C59A/36`。成功要求完整帧 `BYTE +8=0`、`WORD +16=7`，奖励窗口经 `0x41AAA5 → 0xA5AB70` 读取引导6的奖励文本；确认后 `0xA59A20 → 0x41DF98 → 0x4D7C60` 将manager `+0xCC` 写100。100是已兑换状态，不是勋章数量。
- 完整帧 `BYTE +9/+10` 分别触发物品／金币与卡片状态刷新；最大HP／MP及经验读取至DWORD+32，保持36字节安全长度及既有有效资源上限约定。终章拒绝使用结果3的恢复性提示，不使用会进入退出状态25的结果1；失败尾区清零。
- 上述链路已与现用客户端对应函数逐字节核对，原始输出见静态调用链（本地调查产物，未随仓库提交，公开仓库无法直接打开）与勋章入口（本地调查产物，未随仓库提交，公开仓库无法直接打开）。静态证据证明兑换流程和文本，不证明礼包原版内容，也不证明必须存在独立可开箱物品。原始调查产物仅在本地保留，不随公开源码包交付。

## 当前项目奖励与事务

- `HasioRewardPolicy` 明确采用项目策略，默认一次性增加10000 Hans、10份 `14002486` 伊露卡灵丹妙药、5张 `12000002` SP+2卡片；这不是已证实的官方奖品配方。直接发入钱包、游戏道具背包和卡册，不新造礼包物品或改写原版资源。
- 兑奖要求活动角色／世界会话授权、教程及尼莫引导完成、`71000000..71000011` 的12条持久领取记录。链尾 `71000012` 的奖励事务独立，不用客户端自报进度或请求尾区绕过资格。
- `CompleteStoryGuideAsync(type7,id6)` 在单一SQLite写事务内整包发奖、保留并重映射已有快捷栏索引、将终章 `RewardPending` 写0。游戏道具84行容量、每种SP卡255张容量、整数钱包溢出及每次库存写入均检查；不能整包发放时全部回滚，不返回领取成功，也不截断数量。
- 发奖成功后，同一请求返回 `C59A`；新增游戏道具时随后返回 `C430/C379`。卡片有增量时C59A完整帧+10置1，后续卡册仍经正常 `C3E7/C3E8` 请求刷新，不额外推送其他页的卡册。
- 已提交且 `RewardPending=0` 的记录重复应答成功，不重新发奖；之后的配置修改不改变已领取结果。旧版 `guideId6/RewardPending=1` 在C354恢复时不投影终章完成位，保留12枚勋章；玩家再次找哈希奥才补发并原子清除欠发标记，不在登录时自动送包。
- 实现入口为 `HasioRewardPolicy.cs`、`DatabaseService.HasioReward.cs`、`DatabaseService.cs` 及C599路由。构造检查使用 `--hasio-reward-self-test`，同时纳入 `--quest-system-self-test`；原客户端对话、兑换、领取提示、礼包使用及重登状态已获用户确认，范围与受测版本待补录状态见[终章奖励验证](../../../工程/验证状态/地宫与成长验收.md#哈希奥终章奖励验证)。

## 配置

可选UTF-8文件 `hasio-reward.json` 放在实际 `game.db` 旁；缺省使用上述项目默认值，每次未完成兑奖读取一次。严格接受以下字段，拒绝重复／未知字段、重复代码、空奖励、越界数量、超过64 KiB的文件及非支持目录项。`Items`仅支持现有永久、可快捷使用的游戏消耗品，`Cards`仅支持现有SP卡；配置存在但无效时拒绝兑奖并保留资格，不静默回退默认值。

```json
{
  "Version": 1,
  "Hans": 10000,
  "Items": [{ "Code": 14002486, "Quantity": 10 }],
  "Cards": [{ "Code": 12000002, "Quantity": 5 }]
}
```
