- `sub_6E2890` 设置了 `actor+0x80F8=1`，在 `+0x80F0` 处创建了主根节点，并可以在 `+0x80F4` 处创建第二级根节点。

- `sub_6D9510` 在状态2时推进根节点；主要完成会清空 `+0x80F0` 并设置 `+0x80FC`，但该块并未清除完整的角色技能状态组。

- `sub_6E2D90` 立即销毁两个根节点，将 `+0x80F0/+0x80F4` 置为 0，设置 `+0x80F8/+0x80FC/+0x8104/+0x8108=0`、`+0x8100=-1` 和 `+0x810C/+0x8110=1`；更新器的安全性依赖于 active=0。

- 后续CF9B成功不能单独证明CF9D不安全；仅state2也不足以证明角色状态已清理。完成／状态周期边界上的CF9D用于清除残留锁，其触发范围需独立限定。

自然完成调用链：

```text

0x006DAA6B..0x006DAAC7  更新 root0；state2 -> 销毁，root0=0，gate2=1
0x006DAAD0..0x006DABEB  gate2 成立时更新 root1；state2 调用不重置完整角色状态

```

自然完成链样本中，肉身残留状态可保持 `root0=0`、`root1=0`、`active=1`；对象存活与绘制根状态分别维护。该样本的 `root1=0` 与 08-030-6 记录的弹道残留样本 `root1=1` 不同，两处口径待确认（来源分别为 `sub_6D9510` 自然完成链与 `0x41582A -> 0xAB6DD0` 根完成扫描）。

### AbilityType与gaugeType字段

- `sub_9A0A40`将58字段的SK行加载到1284字节定义：field6在`0x9A0DE5`写BYTE `+0x20`（AbilityType），field14在`0x9A0FA9`写BYTE `+0x98`（gaugeType）。
- `sub_6E2890`在`0x6E2930..0x6E293B`将AbilityType复制到actor `+0x8100`，随后在`0x6E297C`读取gaugeType：gaugeType0分配次级根对象并清零8110；gaugeType1保留次级根对象，计时器非零时设置8110。
- 当前目录将肉弹`52000008..15`映射为AbilityType1/gaugeType0，将弹丸`52000000..07`映射为AbilityType0/gaugeType1；旧有颠倒的字段归属已更正。

- CF9D0x6EA7D0 ->0x6E2D90 销毁根节点，active=0，AbilityType latch=-1，810C=1，8110=1，并且0x688C30（全局字节=0）。
- 这些标志不是全零：完整复位后 `+0x810C=1`、`+0x8110=1`、全局字节 `0x688C30=0`，不能概括为“所有标志都归零”。
- 独立的不可穿透获取器0x6E0C10 搜索数组+0x7DD8/+0x7EB8 和列表+0x7F7C。

- AbilityType的UI读取链：`sub_875280 -> 0x87530A -> sub_406181 -> sub_6E7740`；分派覆盖0..9，值6在`0x87576A`进入case6并请求文本ID6065。
- 当前中文`GS._D20`将该标签显示为`?型`，仅凭这份资源不能确认SpecialSkill名称。

- Actor `+0x8100`已核实的写入点为构造函数`0x6D546D=-1`、成功CF9C的`0x6E293B=definition+0x20`及完整复位`0x6E2DFA=-1`；读取经过`0x6E2F2A`。
- 自然完成路径`sub_6D9510`不写该字段，因此其值锁存到显式清理时，仍可复位。
- 当前16行`SK._D35`不含`AbilityType=6/gaugeType=0`，已核实的战斗读取器仅对值1作特殊处理；SpecialSkill触发策略仍待确认。

### 技能根完成副作用与残留样本

- 根完成0x41582A ->0xAB6DD0 会扫描子完成情况，包括虚拟调用的副作用；该扫描带真实调用副作用，因此根指针／标志只从只读记录器读取，不以调用该函数的结果作为状态依据。

- 弹道残留样本中，肉身残留可保持active1／AbilityType1／root1，8110=0、全局字节0；新弹道保留root1并将计时器600更新为300。肉身状态与目标状态分别维护。该样本的 `root1=1` 与 08-030-1 自然完成链样本的 `root1=0` 不同，两处口径待确认。

### 保留技能根的计时与可见性

- 保留根对象可见性：0x6DAB7C..0x6DABC9 计算可见时长 duration8108-(actor_frame7A50-start8104)，以 120 帧为界的跳动计数在 `+0x810C` 处切换；0x6DB43E..0x6DB467 对根1应用 alpha255/0；新的弹道计时可以揭示保留的肉根1；0x6E2D90 后期将其销毁。

### 技能授权与残留碰撞窗口

适配器授权／残留窗口统一以毫秒为口径：激活授权清理 10000ms（10 秒），剩余碰撞窗口 12000ms（12 秒）；前者用于技能激活授权的清理门控，后者用于残留碰撞窗口，精确门控见[业务／宠物／索引](../../宠物/README.md)；生命周期分别绑定授权与残留碰撞。
