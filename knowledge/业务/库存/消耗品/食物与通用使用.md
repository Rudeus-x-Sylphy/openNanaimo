### 完整的食物效果覆盖

- `gi._D6` 总长 413760 字节，先包含121条各有18字段的飞行道具记录，再包含 **2497** 条各有19字段的食物记录。
- 加载器0x9C1D10分别读取两组数量。
- 食物定义大小为516字节，代码位于+0x1D8，HP/MP WORD位于+0x1FC/+0x200。
- 完整映射包含2497对数值；与不完整表对照，其中2001对相同，另有496对仅在完整表中存在。
- CF93和C46D均先验证同一定义再消耗；未知代码一律拒绝。
- 本地检查覆盖全部2497个编译后的查表结果、两种使用路径、单次扣减、准确变化量、耗尽槽位清除、重启，以及既有物品／无效输入对照。

- 完整食物查表覆盖 `14000190`（HP1200/MP110）、`14000224`、`14000001`、`14000233`、`14002221`（汽水G，资源名 Soda G，客户端定义 HP6390/MP150）、`14000909` 与 `14000229`。
- 56个食物行具有团队适用性；多人全队恢复传播、实际数值与双方动画已获用户确认，范围与受测版本待补录状态见[团队食物与复活道具验收](../../../工程/验证状态/地宫与成长验收.md#团队食物与复活道具验收)；结算页吃药／换宠后的挑战与同步另有[结算库存与挑战入口验证](../../../工程/验证状态/地宫与成长验收.md#结算库存与挑战入口验证)的用户确认。

### 食物使用与恢复请求构造

- C43D：`807E60 -> 417116 -> 7F4F00 -> 41F230/82CC30`；WORD+12 为 实例身份，+14 保留调用方值。
- C43E `8005F0 -> 805AED`，成功200调用 `406447 -> 7F7EE0` 移除确切实例；城镇HP恢复由C43F承载，地宫使用下述CF94／CF72，由所属场景完成恢复事务。

- C43F：`4D9C4B -> 4DA07E -> 40F380/4DCC40` 按 scene 分派；town scene1 `41CAB7 -> 5406E0`，两个 WORD+8/+10 分别增加 HP/MP 并封顶。
- scene11 `40A5CE -> 79D090` 在controller+0x4A0非零时读取同两WORD；该函数两轮写MyInfo，非零增量不等同于一次战斗actor恢复，零增量仅保留库存完成。
- `ADA730` 负责归还接收对象，库存占用（busy）状态由独立路径管理。
- 库存完成与战斗资源恢复使用各自消费链。
- 结算页的应答限制见[结算页食物与队列边界](#结算页食物与队列边界)。
- 天空竞技准备房以C43E/20完成C43D库存事务：`0x805AED..0x805B71`处理成功码200、精确物品实例及接收对象归还；资源由CF72同步。
- 该场景的库存分发`0x8005F0`经公共分发`0x4D34D0`处理队首，C43F属于城镇／住宅的独立消费边界；竞技应答采用C43E单帧完成，维持后续库存读取及房间操作推进。
- D8FF在城镇`5408D0`更新MyInfo，不能迁移到地宫：`6EBAC0 -> 6FCC1B`识别0xD8FF后在`6FCC2C -> ADA730`归还对象并跳过资源写入。
- 地宫／结算背包食物使用CF94/24，槽位0xFFFF绕过`6F1F82..6F1FB0`快捷栏扣除，HP／MP经`6F1FC5..6F21BF`按actor UID应用；该完整窗口与当前PE一致。
- 准备房使用CF72/116，资源写入`6F5BF3..6F5C61`字节一致；全处理函数另含已登记兼容改动，不宣称全函数相等。
- apply0仍清快捷栏保护数组的边界见[蓄力MP与护盾数组保护](../../宠物/发射器/蓄力发射与MP账本.md#kb-08-023-8)；战斗恢复不可用普通CF72替代CF94。

## 结算页食物与队列边界

本节只记录地宫结算页的库存事务与队列衔接（库存响应分发、C43D/C43E/CF94 消费链与 C47D 换宠响应顺序）；地宫结算的计分、冻结与续关规则归[业务／地宫／计分与结算](../../地宫/计分与结算/索引.md)。

库存响应按场景分发。城镇`0x531BD0`的C43F分支在`0x5321E9 → 0x41CAB7 → 0x5406E0`应用两个增量后归还接收对象。地宫`0x6EBAC0`对C43F使用`0x6FCDB9..0x6FCE21`默认分支，队首对象继续保留；因此地宫恢复使用所属CF94消费链，完成接收对象归还和后续动作推进。

| 场景 | C43D 响应链 |
|---|---|
| 城镇 | `C43E/20 → C43F/12` |
| 地宫准备房 | `C43E/20`，并由请求绑定 F108 产生 `CF72/116` |
| 地宫战斗／结算 | `C43E/20 → CF94/24` |

- 结算 CF94 携带字段：actor UID、slot=0xFFFF、实际 HP／MP 增量，尾部初始化为零。
- 事务职责：单次扣药、重复身份校验及死亡／过渡门控。
- F100 同步与解冻边界：F100 同步恢复后的绝对资源，保留 SettlementFrozen 和待确认结算动作，直至有效续关加载边界解冻。

结算C47D换宠完成库存提交和F100资源导入，响应顺序为`C47E → C379 → C3CC → C44C → C430`，保留当前场景actor与续关动作；宠物／宝石有效上限按绝对HP／MP继承规则计算。验证归属见[结算库存与挑战入口验证](../../../工程/验证状态/地宫与成长验收.md#结算库存与挑战入口验证)。
