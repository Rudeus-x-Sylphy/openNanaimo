### SP卡片的技能类型与点数规则

- SP卡片 `12000001..12000010` 为炮弹型，`12000011..12000020` 为肉弹型。
- 合成控制器的三个卡槽每槽承载一张被选中的卡片：`sub_85B030` 按实际放入的张数填写 C3ED 的 frame +0x10／+0x14／+0x18，未用槽位为 0，单张提交时 token 为卡号减 13000000，多张提交时 token 为 0。
- 满足持有、钥匙及点数容量条件的 type30 合成按确定性事务逐槽扣卡，并把各槽面值 `+1..+10` 之和加入对应的 `SkillPoints` 或 `SkillPointsMeat`；一次提交仅受理同一册页（同族）。
- 成功反馈使用 `C3EE DWORD+8=600`、`WORD+0x0C=本次点数增量`，驱动专用完成效果并同步可见 SP；同一传输请求重试使用零增量。
- 普通道具合成继续使用结果400及产物代码。
- 构造与事务检查覆盖两种族型的+1／+10、单张至三张槽位求和、余额上限、钥匙、重复提交和原子扣卡。

合成食谱中的 `210000xx` 不是 SP 卡或技能点；它们属于 `gi._D6` 的飞行道具／效果物品，应作为普通合成产物写入 `CharacterItems`，不能改变任一技能族的 SP 槽。

```text

sub_85A270
  case50154/C3EA -> sub_40F15A -> sub_859840
    -> sub_4167B1 -> sub_85A8D0       引导步骤 取自 +8
    -> sub_4032B5 -> sub_85AAA0       +9/+0A/+0B 及日期元组


  case50158/C3EE -> sub_41E6AA -> sub_8599D0

```

- `sub_83CA40` 对应的C3EE路径仅消耗`DWORD +8`，发送C3E7/C3E9，并使用卡对象`+0x528`作为结果待定。
- 该元组不是通用的。
- 在第二个控制器中，`sub_8599D0` answer400读取`DWORD +0x0C`，存储在`this+992`，设置完成`this+964=1`，并清除忙碌字节`this+961`。
- 在材料/结果动画完成后，`sub_8564A0`创建结果对话框，并调用`sub_40ED13 -> sub_851910`带有该代码。
- `sub_851910`构建显示的奖励对象，并包括一个针对域15的PET特定分支。
- 因此成功C3EE需要长度16和精确的输出在`+0x0C`。

“C3EE不携带输出／奖励ID”仅适用于 `sub_83CA40` 元组，不能作为通用协议结论。

`sub_86E2E0`渲染四种选择模式：模式0使用C3EA `+9`，模式1渲染自由钥匙期限，模式2使用`+0A`，模式3使用`+0B`。日期顺序保持`+0x0C=expiry`、`+0x10=current`；最小安全C3EA长度为20。

### 引导步骤锁闭合

`sub_845E20`构建C3FB/12。`sub_844D10`发送当前/更新WORD对，并设置指导控制器字节`this+0x23=1`。`sub_845180`接收C3FC，检查`WORD +8`，并总是清除`this+0x23`；C3FC/10足够。

收到 C3FB 时返回 C3FC，并保持合成控制器的 current/update 状态一致。C3FB/C3FC 交换与完整合成结果生命周期分别验证。

适配器持久化 `card_guide_state_<account>.dat`，响应请求驱动的C3FC，并为新 `skip_tutorial=1` 账户引导步骤3。

### C3E8与对应库存载体

每个C3E8类型携带：

```text

+0x40 普通钥匙数量
+0x41 黄金钥匙数量
+0x42 神秘钥匙数量
+0x43 保留的第四种／遗留计数字段
+0x88 WORD 免费钥匙启用标记

```

可见的自由钥匙期限来自C3EA，而不是C3E8日期样式的字段或C474行元数据。

| 第二个 C3EE 处理器 | `sub_41E6AA -> sub_8599D0` | answer400 读取 `DWORD +0x0C`，将结果代码存储在控制器 `+992`，设置完成状态 `+964=1`，清除忙状态 `+961` |

### 历史引导未应答的忙状态样本

历史失败元组 `C3EA +8..+0B=0 -> C3FB current0/update3 -> no C3FC` 对应静态忙状态设置／清除链。当前响应仍按上文C3FB/C3FC请求驱动规则构造。该样本证明客户端忙状态未解除，不证明当前处理已通过运行验收。
