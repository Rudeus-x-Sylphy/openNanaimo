### VIP经验卡的主动使用与持久化

- VIP经验卡（又称翻番卡、VIP卡）经主动使用形成有效权益。
- 卡片账本为`CharacterCards`；C3ED的VIP元组由当前在线账户与角色的会话共同授权。
- 普通10、自由20、黄金30分别表示三种钥匙选择。
- 适配器扣费策略为：普通／黄金钥匙各扣一把，自由钥匙以合法且有效的到期时间授权；扣卡、扣钥匙及建立`CharacterExperienceCards(CharacterId,CardCode,Expires)`在同一SQLite事务提交。

- 同一张仍有效卡的重复请求只确认原权益，不二次扣卡或延时。
- 数据库入口默认不允许更换，客户端6201已有结束旧卡、使用新卡的确认流程，协议入口明确允许新卡替换旧权益，但不叠加；失败恢复原权益和库存。
- 数量归零删除卡片行，角色之间独立，数据库重开保留数量和到期状态；原客户端重新登录后的画面验收仍归[卡片整页组合、主动使用与发布范围](发布与验证.md#kb-09-004-1)。

商城可购买标记保持原目录约定，300%行仍不可购买。随机奖励幸运卡不属于经验权益入口；通用拒绝回0，不能冒充容量不足。C3EE后由客户端自行请求C3E7/50及C3E9，不补发跨控制器库存包。VIP列表分类字节为0，按VIP卡号映射数量及新增提示，不与同为category3的SP／活动卡混槽。

- 到期字段采用原生按小时编码，适配器把“使用时刻＋目录小时数”向上对齐到可表示整点，覆盖完整目录时长；判定与列表公布采用同一边界。
- 倍率及结算规则归[业务／地宫／计分与结算](../../地宫/计分与结算/README.md)，协议字段和钥匙链归[VIP卡主动使用与经验权益字段](#kb-08-003)，发布及验证范围归[卡片整页组合、主动使用与发布范围](发布与验证.md#kb-09-004-1)。

### VIP卡主动使用与经验权益字段

- 范围为World连接卡片页／合成控制器的VIP元组，不覆盖普通type10合成或type30 SP卡。
- 点击链`0x855CA0 → 0x85AF50 → 0x41D4C1 → 0x859710`经`0x413BBF → 0x7BEC40`构造C3ED/28，调用`0xADA3E0`发送：WORD+8=40，DWORD+10=钥匙选择，WORD+14=0，DWORD+16=卡号，DWORD+20/+24=0。
- C3EA经`0x859840 → 0x85AAA0`写key对象+12，之后由`0x85AF50/0x85BA10`取用：10普通、20自由、30黄金、40神秘；不是暂停／续时／停止动作。
- `0x85AAA0`读取C3EA的BYTE+0x09普通钥匙数量、+0x0A黄金钥匙数量、+0x0B神秘钥匙数量及DWORD+0x0C/+0x10自由钥匙到期／当前时间；本文偏移以十六进制书写，早前正文用十进制`+10/+11`与`DWORD+12/+16`表述同一组字节，与[协议和控制器边界](../合成/SP与引导控制器.md#kb-03-030)一致；自由钥匙有效时初始默认key状态1对应请求20。
- 文本6201存在结束旧VIP经验卡并使用新卡的确认，不能一概拒绝换档；事务策略归[VIP经验卡的主动使用与持久化](#kb-03-003)。

- 父分派器`0x85A270`的case50158经`0x41E6AA → 0x8599D0`消费C3EE。
- VIP answer800读取DWORD+8结果、WORD+16额外百分比、DWORD+20按小时编码的到期值，再经`0x416AEA → 0x866360 → 0x4013D4 → 0x8821A0 → 0x41C0E4 → 0x8829C0`更新VIP信息，并请求C3E9；最低安全总长24。
- 普通answer400的DWORD+12产物语义不能套到800。

- 完成后的`0x416171 → 0x866520`请求C3E7/12：WORD+8=50、BYTE+10=0、BYTE+11=页。
- `0x863790`消费C3E8/140并经`0x4110F9 → 0x881BD0`处理VIP页：BYTE+11为页，BYTE+12..21为十格数量，BYTE+32..41为新增标记；DWORD+72为到期、DWORD+76为当前时间，WORD+138为额外百分比。
- 到期不大于当前时间时清掉百分比。
- `0x411694 → 0x882E30`按`(额外百分比+100)`显示倍率，并将DWORD到期拆为年／月／日／小时；最高读取字节139。

- VIP使用链的静态校验覆盖13个函数、2274条指令及9143字节。
- 权益事务归[VIP经验卡的主动使用与持久化](#kb-03-003)，计分与取整归[业务／地宫／计分与结算](../../地宫/计分与结算/README.md)，发布及验证范围归[卡片整页组合、主动使用与发布范围](发布与验证.md#kb-09-004-1)。
