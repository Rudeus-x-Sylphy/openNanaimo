## 地址与调用关系



本主题按函数、分派器和状态记录地址与字段读取关系。地址不单独确定语义；同一操作码在不同连接、控制器或客户端状态下可能由不同处理器消费。



```text

构造函数 -> 发送调用点 -> 连接

响应分派器 -> case -> 处理函数

全部读取偏移 -> 写入／调用

最高读取偏移 -> 最小长度

```



本主题维护字段、指令与调用关系。客户端接口、适配器实现及自定义数值策略分别定义；协议规则见01–07，实现结构见09。

### 城镇称号与角色等级



200级兼容将城镇称号设为6位（bit6..11）、等级设为8位（bit12..19），UID保持bit20..31、低6位保持原义；入口使用imm32比较200。托管初始构造、TownTitleProjection增量／广播、原生构造与客户端读取统一使用称号mask=0x3F<<6、等级mask=0xFF<<12，分别保留等级bit12及UID。边界与保位回归覆盖127／128／199／200／201和称号0～255归一化。精确原／新字节、独立代码区、冲突检查、迁移与恢复步骤统一归`docs/客户端二进制补丁.md`。指令隔离验证覆盖200种城镇组合及入口1..255分支。下文CN原布局说明兼容前的字段编码。



`0x53E0C0` 消费城镇角色控制值：位6..12为地宫称号，位13..19为角色等级，位20..31为场景身份。角色构造经 `0x402432 -> 0x535530` 将称号传入参数 `a16`，经 `0x40B2B2 -> 0x504E40` 写入角色 `+0x31BC` 并选择 `1243 + 称号值` 的资源；`0x40AAF6 -> 0xA72530` 保存称号。独立的等级参数 `a18` 经 `0x40D373 -> 0x505D90` 写入角色 `+0x31BE`，经 `0x40FEE8 -> 0xA72570` 保存等级。适配器共享城镇构造同时写入两个独立字段，并保留构造模式及分配身份。
