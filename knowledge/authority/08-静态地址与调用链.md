# 08 静态地址和作用域字段目录

## 地址与调用关系

本主题按函数、分派器和状态记录地址与字段读取关系。地址不单独确定语义；同一操作码在不同连接、控制器或客户端状态下可能由不同处理器消费。

```text
构造函数 -> 发送调用点 -> 连接
响应分派器 -> case -> 处理函数
全部读取偏移 -> 写入／调用
最高读取偏移 -> 最小长度
```

调试字符串用于定位代码，字段结论以指令和调用关系为依据。静态分析、客户端运行观察与适配器自定义策略分别说明，不能互相替代；协议规则见01–07，实现结构见09。

### C355 情侣资料与原生表情下一页门控

C355消费链为 `0x00531DA3 -> 0x0041646E -> 0x00530C90`；情侣姓名从包`+0xDF`传至原生`0xA76170`，按是否非空写入`manager+0x4F6C`。戒指`WORD+0xF0 -> 0x4DDA30 -> manager+0x1028`独立于该布尔标志。

C355 进度填充止于完整帧 `+0xDE`；`+0xDF..+0xEF` 保持17字节情侣姓名，`WORD+0xF0` 保持戒指后缀。空情侣关系写入空姓名与零戒指，原生 `0xA76170` 将 `manager+0x4F6C` 置为 false，在翻页戒指资源查找前关闭门控。

隔离 original-x86 对照执行原生姓名／戒指 setter 和下一页 gate，CRT bounded-copy、strlen、memset 为模型，缺失记录 lookup 按 NULL 建模。越界姓名构造有一次lookup／predicate调用并在上述地址无效读；空姓名Network及两种Stand_Alone构造均为零次lookup／predicate、`closed-before-page2`。这是有假设的隔离执行，不是全客户端 UI 验收；构造输出也不是实时 wire。

## Boss 终局的玩家 HP/MP 回复

D012 `DWORD+0x28==0` 门控位于 `0x6ED62D`；本地 `BYTE+0x24+slot` 为11或20时消费回复。槽位读取 `0x41CCD8 ->0x66E740` 使用 actor `+0x7A4C`。HP 是 `WORD+0x2C+2*slot`，`0x6ED6CC/0x6ED6F0` 读取，`0x6ED6F5` 加到当前值，`0x6ED6FE ->0x406E74 ->0x6E3000` 按最大 HP 钳制并写入。当前／最大 HP 使用双倍编码 `actor+0x7BC0/+0x7BB8`，getter 为 `0x417B5C ->0x664F60`。远端角色循环同样消费各自槽位，不能把 DWORD 累计伤害塞入两项 WORD 回复。

## 超级 Boss 的 mode 推进门控

D012 `+0x28` 通过 `0x6EC979 ->0x401050 ->0x6BF200` 写入 Boss recording `+0x18`。包值为0才进入 `0x6ED62D ->0x6ED63C ->0x40B5DC ->0x680F30`，设置完成许可 `Boss+8=1`。组件退休／爆炸不替代 mode 推进：`0x6BE8C4..0x6BE8F7` 还要求许可、资源节点 `+0x208` 和 `Boss+0x18==0`；`0x6BE9D2` 要求计时严格超过2000ms，随后 `0x6BEA2B ->0x4093F9 ->0x6BE120` 递增 mode。中间终结的 states0 不进入成功结算。episode≥16 的零 recording 分支还可能在 `0x6EE121/0x6EE1A6` 读取 `+0x3C+slot`，故中间终结响应按64字节覆盖四个显式零排名。
