# 01 协议分帧、连接与状态周期

## 证据层级

| 类别 | 能证明什么 | 单独不能证明什么 |
|---|---|---|
| 原始通信记录 | 原始交互的准确字节和先后顺序 | 缺少静态调用链支持的字段语义 |
| 运行观察 | 与本地适配器交互时可归因的行为 | 原始适配器策略 |
| 静态分析 | 指令、偏移、分支、构造函数和处理函数 | 运行验收 |
| 本地自测 | 适配器字节、顺序、路由、请求门控和重置 | 客户端渲染 |
| 回放／仿真 | 在明确假设下的行为 | 完整程序及受保护路径的行为 |
| 自定义策略 | 适配器选择的实现行为 | 原始适配器算法 |
| 假设 | 可被后续实验否定的解释 | 已确认事实 |

封包结论使用以下记录结构区分适用范围：

```text
连接 | 分派器／控制器 | 状态 | 操作码（十进制／十六进制） | 声明长度／实收长度
触发条件 | 响应 | 请求低位 | S2C 序号 | 原始帧 | 关闭方向
```

## S2C 包头

- 高位序号循环：首个响应为 0，随后为 1..100，再从 1 开始。
- 请求驱动的响应复制对应请求的低 5 位。
- 校验和种子独立取自首个 GS C351 的低 5 位：`low | (low << 8)`。
- 广播、Boss、房间重置与调度路径使用同一套序号循环。
- 响应长度必须覆盖处理函数实际读取的最高偏移，且所有被读取字节都已初始化。

## 协议元组

同一操作码的语义受以下范围限定：

```text
(connection, dispatcher/controller, client state, opcode, length)
```

不同元组之间不能直接迁移结论；构造函数、处理函数和状态门控分别决定其适用范围。尤其注意 C351/C352、C367/C368、CF70/CF71、CFEB/CFEC、CF7F/CF80、CFD3/CFD4、CF9C、CF88 与 D012。

## 连接类型

登录、GS／前端、房间／战斗、资料注册和 UDP／P2P 必须分别记录，即便它们复用操作码或回环传输。实际来源端点与本地后端回环套接字也必须分开。

### 游戏内切换频道

切换频道使用新建的 **类型 10 登录连接**执行 `271B/12 -> 271C/176`。选择频道后关闭当前 **GS 连接 0** 和登录连接 10，再重建 GS0 并发送 `C351/24`。`C352 BYTE+0x08==100` 是重新进入完成条件；`WORD+0x0A` 安装新的场景／会话本地值。`0x271D` 虽注册于协议元数据，但已核实的 `CChangeChannelWindow` 操作链不会发出它。

当前世界连接注销期间，立即重连的 GS 与待释放会话保持同一切换身份。新登录套接字首帧（`stage0`）为 `271B` 时标记切换意图；来源 IP 范围内恰好匹配一个存活连接并完成会话释放后，复用槽位、UID 和角色资料。页面、房间、战斗状态开启新的连接内周期，关闭期间不注入 C368/C47F。同 IP 匹配不唯一时，各身份保持独立。

完整 adapter 还支持 GS 先关闭的兼容顺序：世界连接 teardown 开始时，按已认证账号、角色和来源 IP 缓存30秒 handoff ticket；新 C351 携带同一身份并等待原世界 presence 释放后完成重新进入。fresh-271B 路径保持优先，身份匹配同时依赖账号、角色和来源端点。

## 状态周期（epoch）

| 边界 | 含义 | 重置检查 |
|---|---|---|
| CF09 | 早期传输／房间边界 | 名单、角色快照、一次性标记、过期传输状态 |
| CF6C | 地图／房间身份确定 | 普通目标 HP、静态／运行时选择器、箱子、Boss、结算 |
| CF7F | 战斗／最终加载边界 | 战斗周期、Boss 请求计数、实时通信门控 |
| 频道选择 | 刷新登录连接 10，再关闭并重连 GS0 | 原连接和适配器会话释放后保留逻辑槽位／资料；重置页面、房间和战斗状态 |
| C365 | 世界／页面销毁 | 此处禁止重建本地角色 |
| C367/C368 | 创建页面与本地角色 | 角色身份、资料、装备、HP/MP |

即便 TCP 未断开，第二次进入副本也属于新的房间周期。单个周期的观察不能证明一次性行为在后续周期中正确重置；重置验证至少涉及两个完整周期。

## 操作归因

操作归因使用静默对照、单调时钟操作标记，以及新增帧、载荷和本地状态写入之间的对应关系。心跳、遥测、自动保存和定时器作为背景流量单独分类。

只有找到与操作绑定的调用者或状态写入者，才能认定请求由点击触发。

点击前后都出现的请求，应先视为背景流量，直到受控差分实验证明其因果关系。

## 预期请求未出现

预期请求受状态设置函数、状态写入点、忙碌／抑制状态、完成条件、控制器生命周期与主循环顺序共同约束。主动响应或其他分派器的封包不能代替对原请求门控的解释。

## 断线归因

界面文字不能说明由哪一端关闭套接字。关闭方向的证据包括 FIN/RST、`recv`／`send` 返回值、套接字错误、进程存活状态和帧时间戳。解码文字乱码不能代替原始日志或帧字节。

已保留的超级 Boss 返回观察中，CF73/CF1D 是客户端请求，且先于 CF1E；不能将该顺序推广为通用断线流程。长时间运行时的 CF99 是另一种应用状态边界：即便传输连接健康，它也可能设置本地返回村庄条件。

## 稳定的封包家族

```text
C351/C352  GS 种子／校验和边界
CF09/CF0A  传输周期
CF6C/CF6D  地图／房间周期
CF70/CF71  准备房间资料／名单
CFEB/CFEC  房间资料／关卡载荷
CF7F/CF80  预加载／最终加载
CF87/CF88  结算
CF99/CF9A  长时间运行的投降滥用报告／确认
D00D/D00E  普通目标／来源终止状态
D011/D012  Boss 总体状态
D034/D035  场景物品拾取
```
