## 当前构建身份

The repository and playable parent runtimes were republished on September25,2026 after closing both halves of the ready-room-rank defect. The first attributable client run showed retained-native CF71 fixed `+0xB4=1` while the selected-stage rating was zero; after egress normalization was added, a second run showed successful native CF88 S (`+0x0B=5`) and CF16 output while `DungeonProgress.BestRatings` remained zero, so the next CF71 was blank. The current build tracks CF6C selectors, normalizes native CF71 at actual egress, and persists only non-death CF87->CF88 personal results transactionally into ordinary/secret packed rank ledgers with no-downgrade semantics. Native fallback remains blank; CF15/CF16 team leaderboard behavior remains separate. Focused parser/persistence tests, full adapter self-test and the real CF6C->CF70->CF71 route pass; September25,2026 user acceptance confirmed the deployed original-client reported scenario.

## 启动和连接

GUI 固定使用本机回环：

```text
11005 登录
11999 角色资料注册
12050 世界入口
```

一键启动顺序为：停止当前运行的 adapter 与客户端 -> 保存资料 -> 校验 adapter 文件闭包并确认 `game.exe` 存在 -> 从使用者自备文件派生并验证家具五字节 Index 重定向、第五村道路及 SSTG/PON 兼容资源 -> 启动完整 adapter -> 等待三个入口 -> 注册资料 -> 启动客户端。启动器保持 emotion EXE 代码不变；表情翻页由有界 C355 情侣姓名／戒指协议保障。C393 提供有界场景快照，本地 getter 负责家具点击路径。客户端整体哈希用于诊断；家具站点按 PE 布局和当前五字节精确匹配。桥接端口供完整 adapter 内部使用，GUI 固定使用 Network 模式，Standalone 构造器用于协议研究。

## 状态一致性

- 等级和经验、货币、库存、任务、宠物及关卡进度由完整 adapter 的持久层保存。
- 进入地宫时，managed 状态通过固定5120字节结构导入桥接组件；离开或结算时按差量事务写回。
- 宠物阶段／等级／经验在 C44C、C379、CF72 和 CF88 间保持同源。
- Hans 与 NaNa 商品按目录币种扣款；C3CD头像购买从`ava._D1`字段9取得Cash价格，只扣NaNa/Cash，C3CE在+0x10回写NaNa、+0x18回写Hans；整容券按准确库存 identity 消耗。
- Revival uses are restored through C355/local CF71. The ready-room card separately draws actor `+0x8124`; the deployed client now rewrites that text from manager `+0x5600` before each original HUD draw. 复活次数通过C355／本地CF71恢复。native dungeon CF83/12同时存在mode1复活次数路径和mode0 Hans路径。首轮mode1通过worker内部CF95推进并发送CF84 variant60；首次恢复后的第二次死亡帧为mode0/value950，现由managed扣Hans、内部F104/F105同步worker HP/MP并发送CF84 variant20。两者都以本地UID D010死亡锁为前置、不依赖0x044C；mode1额外要求`uses>0`。CF84 `+0x0C/+0x0E`携带HP/MP，`+0x10/+0x14`为零辅助字段。
- 同一提交ID不重复结算角色经验、宠物经验、货币、卡片或道具。

用户在2026年9月23日提供的原客户端日志重现了发布版进入村庄后 `FirstVillageFlag==TRUE -> CVillageChar(-1,-1)`。静态链证明日志中的 `1081671680` 对应 double 400.0，C368 坐标归一化已经到达客户端；失败来自 C355 提前恢复任意页面后，首次村庄分支改读缺失的页面入口。当前运行包已改为 C355 `map/page=0/0` 安全启动，并取消首个 C367 的存档页面覆盖。以下验证仍是静态／adapter 构造，不是修复候选的原客户端端到端验收。
