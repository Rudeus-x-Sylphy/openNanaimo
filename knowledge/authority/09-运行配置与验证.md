## 启动和连接

GUI 固定使用本机回环：

```text
11005 登录
11999 角色资料注册
12050 世界入口
```

一键启动顺序为：停止旧 adapter -> 保存资料 -> 校验文件 -> 启动完整 adapter -> 等待三个入口 -> 注册资料 -> 启动客户端。桥接端口只供完整 adapter 内部使用，不是 GUI 选项。Standalone 构造器仅用于协议研究，不能与 Network 字段布局混用。

## 状态一致性

- 等级和经验、货币、库存、任务、宠物及关卡进度由完整 adapter 的持久层保存。
- 进入地宫时，managed 状态通过固定5120字节结构导入桥接组件；离开或结算时按差量事务写回。
- 宠物阶段／等级／经验在 C44C、C379、CF72 和 CF88 间保持同源。
- Hans 与 NaNa 商品按目录币种扣款；整容券按准确库存 identity 消耗。
- 复活次数通过 C355／CF71 恢复，只在当前战斗 death latch 接受 CF95 时扣减。
- 同一提交ID不重复结算角色经验、宠物经验、货币、卡片或道具。

## 证据边界

当前可以表述为：**静态／源码链闭合，adapter 构造和持久化验证通过。**

仍不能用 host/self-test 代替原客户端试玩。下列项目保留运行验收：

- 宠物页等级、跨阶段提示与多人隔离；
- 整容后的即时动画、重进和重登显示；
- 复活后的角色位置与操作恢复；
- 家具选择补丁的完整可见流程；
- 拉米诺斯村地宫7的道路、房间界面、三难度战斗、返回和再次进入；
- 好友外部桥、完整竞技／娱乐模式以及全部多人交易边界。

发现运行问题时，应记录客户端哈希、adapter manifest、角色、连接、操作时间、首个异常请求／响应和关闭方向，再回到对应主题修正，不应通过主动推送或固定返回值绕过本地状态门控。
