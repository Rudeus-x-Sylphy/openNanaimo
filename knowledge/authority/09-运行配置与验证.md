## 当前功能

当前运行包整合纯新手档启动、村庄交通、公寓推荐、主线勋章、分体 Boss 生命显示、地宫复活与结算、快速准备房、stage1 称号、精确排行榜和关联场景伤害。纯新手档先进入人物形象创建和角色命名；付费城镇交通在扣款提交后立即确认切换；失败结算支持玩家显式重新挑战，并在准备房重新加载完成后进入新的战斗周期；频道重新进入保留村庄页面与最后合法坐标；普通怪物和 Boss 使用严格专属卡池。

2026年9月28日，纯新手档外观／命名、失败结算重新挑战、首次金币复活提示三项完成用户验收。发布检查覆盖257文件源码闭包、托管构建、原生确定性构建、运行包自检和 package 合同。

当前运行包统一以下功能：

- 背包标签按领域路由，购物券、普通道具、喇叭与钥匙使用各自列表；
- 背包实例身份在会话内保持稳定，快捷栏、丢弃、材料、通用使用与扩充券共享同一映射；
- C43D 城镇食物事务按实际 HP/MP 增量提交，库存与资源账本同步更新；
- C480 扩充券按 action、点击实例 identity、exact code 与 expiry 处理；
- 外观零槽和 `EquippedPetItemCode=0` 作为真实卸装状态贯穿保存、刷新、迁移与原生导入；
- GUI/DB `MaxHp/MaxMp` 保存基础值，选中宠物宝石形成 effective maximum，absolute current 跨库存刷新、结算、连续关卡、回城与持久化保持一致；
- 普通结算使用玩家操作驱动的继续／返回链；失败结算只在玩家明确选择重新挑战后建立新的战斗周期，超级 Boss stage1 评分写入持久槽；
- 复活金币与复活彩蛋严格遵循玩家当次选择，恢复重试保持单次扣款；
- 地图边界交接不污染人物位置，频道重新进入恢复村庄页面和最后合法坐标；
- 普通怪物使用30%严格专属卡池，Boss 仅在首次最终终结时从确认池生成一次卡牌；
- Boss 当前 mode recording、复活快照、分体目标账本与多阶段终结使用统一状态周期；
- 新手引导按阶段投影基础外观，完成后恢复保存的装备、特效与宠物；纯新手档使用隔离账号、空角色投影和合法中性 profile，频道选择在完成建角后解锁；
- 复活次数按角色账本保持一致，PET生命周期按观察者／角色独立管理；
- 客户端兼容组件提供双控制器手动结算、原生状态迁移及factory30购房入口与余额让出分支。
