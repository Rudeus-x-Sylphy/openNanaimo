## 2026年9月26日发布内容

当前候选统一以下功能：

- 背包标签按领域路由，购物券、普通道具、喇叭与钥匙使用各自列表；
- 背包实例身份在会话内保持稳定，快捷栏、丢弃、材料、通用使用与扩充券共享同一映射；
- C43D 城镇食物事务按实际 HP/MP 增量提交，库存与资源账本同步更新；
- C480 扩充券按 action、点击实例 identity、exact code 与 expiry 处理；
- 外观零槽和 `EquippedPetItemCode=0` 作为真实卸装状态贯穿保存、刷新、迁移与原生导入；
- GUI/DB `MaxHp/MaxMp` 保存基础值，选中宠物宝石形成 effective maximum，absolute current 跨库存刷新、结算、连续关卡、回城与持久化保持一致；
- 普通结算使用玩家操作驱动的继续／返回链，超级 Boss stage1 评分写入持久槽；
- D012 玩家回复字段、Boss 当前 mode recording、复活快照、分体目标账本与多阶段终结使用统一状态周期。

## 背包与资源契约

- C379/C430/C46D/C47D 共享稳定的会话实例身份，并映射到 DB 紧凑序号；
- C433/C434 按 code 与 identity 处理确切实例；
- C43D/C43E/C43F 在同一事务提交食物扣减和实际恢复增量；
- C480/C481 按 raw type 到协议 action 的映射处理确切扩充券；
- C3CC、C430、C40A、C44C 使用各自容量与 expiry 尾字段；
- C475/C476 执行库存搬运，快捷栏序号与会话身份在同一事务中保持一致；
- 库存刷新保持 live current，并按当前选中宠物重新计算 effective maximum；
- C47F 的零 D5/D6 字段清理翅膀与 GM 效果，房间和公寓保持既有场景连续。

## 地宫与战斗资源契约

- CF71/CF72、C368/D8FF 使用基础值加选中宠物宝石的 effective 最大 HP/MP；
- F100/F102 以 base maxima 和 absolute effective current 分字段交换；
- CF87、连续关卡与回城共享同一 effective 快照；
- 普通结算关闭本地自动推进，继续与返回由对应玩家操作驱动；
- CF8B/CF8C 推进有效房间 tuple，并持久化超级 Boss stage1 评分；
- D012 `+0x28` 发布当前 mode 账本，聚合 HP 与累计伤害用于评分和结算；
- 普通目标、runtime/deform、crate 与 Boss 组件使用独立账本和周期边界。
