# 五村地图与顺序解锁安装

## 安装结果

五村采用前四村通关前置与L1至L8顺序进度，普通阶段、超级BOSS、区域通行和小地图点亮相互对应。L8为道路终点。完整规则见[五村顺序解锁](../../业务/城镇/场景切换/村庄拓扑与兼容资源.md#五村顺序解锁)，评分规则见[评级门槛](../../业务/地宫/计分与结算/评级门槛与无伤锁存.md#评级分母与协议码)。

### 小地图程序位点

目标函数为`game.exe`的`0x009000D0..0x00900156`。工具按PE节表定位并校验完整登记函数，再写入`0x00900131`的一字节位移。

| 安装状态 | `0x0090012F`完整指令 | 固定关闭位置 |
|---|---|---|
| 原始布局 | `C7 80 7C 0B 00 00 00 00 00 00` | L7 |
| L7兼容布局 | `C7 80 80 0B 00 00 00 00 00 00` | L8 |
| 完整L7/L8布局 | `C7 80 84 0B 00 00 00 00 00 00` | L9 |

完整L7/L8资源安装采用最后一行，L7和L8继续按角色前置进度点亮。各位点的完整登记值随运行包内嵌配方提供。

### 地图包替换

地图包的第五村使用50×36网格、16像素格块。兼容处理保持17↔18↔19双向通行，封闭19↔14及后续规划边界，更新对应碰撞、目的页和来源标记。

基础CN布局的L7入口为page18的`x22..27/y3..4`、返回点`(25,6)`；原生L7/L8布局保留page18的`x8..11/y5..9`和page19的`x7..12/y7..9`入口，两页返回点均为`(10,15)`。入口动作分别为166／167，返回标记分别为169／170。

## 安装步骤

1. 退出使用目标目录的客户端和适配器，保存完整客户端及资源备份。准备匹配的基础客户端、当前项目发布文件和上述资源包，在项目目录打开PowerShell。

```powershell
$Client = '<客户端根目录>'
$Overlay = Join-Path $Client ('build/fifth-village-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
$Tool = Join-Path (Get-Location) 'adapter_runtime/Nanaimo.Adapter.exe'
```

2. 核对资源包并准备完整L7/L8资源。首次安装执行下列命令；已登记完整L7/L8资源的目录直接进入第三步。客户端基础资源及宠物配套准备见[完整资源安装](../韩服L7-L8与宠物资源说明.md#5-随仓库资源包与安装步骤)。

```powershell
$Archive = Join-Path (Get-Location) 'resource-packs/nanaimo-korean-resource-kit.zip'
$Expected = ((Get-Content -LiteralPath ($Archive + '.sha256') -Raw).Trim() -split '\s+')[0]
if ((Get-FileHash -LiteralPath $Archive -Algorithm SHA256).Hash -ne $Expected) { throw '资源包摘要校验失败' }
python -B scripts/package_korean_resource_kit.py verify --archive $Archive
if ($LASTEXITCODE -ne 0) { throw '资源包内容校验失败' }
$Kit = Join-Path $Overlay 'kit'
Expand-Archive -LiteralPath $Archive -DestinationPath $Kit
python -B scripts/port_lumineos_resources.py apply --bundle (Join-Path $Kit 'l7-l8-bundle') --client $Client
if ($LASTEXITCODE -ne 0) { throw 'L7/L8资源安装失败' }
```

3. 成套安装最新运行程序、启动器和清单。项目发布目录与客户端目录分开时执行：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root $Client
if ($LASTEXITCODE -ne 0) { throw '程序部署预检失败' }
python -B scripts/deploy_adapter_runtime.py --client-root $Client --apply
if ($LASTEXITCODE -ne 0) { throw '程序部署失败' }
```

4. 校验完整资源并应用五村兼容。该步骤统一派生上表程序位点、地图包、9项别名和登记图像迁移，保存覆盖目录及内容寻址备份。

```powershell
& $Tool --tools verify-resources --client-root $Client --kind lumineos
if ($LASTEXITCODE -ne 0) { throw 'L7/L8资源校验失败' }
& $Tool --tools compatibility --source-root $Client --output-root $Overlay --dungeon7 --dry-run
if ($LASTEXITCODE -ne 0) { throw '五村兼容预检失败' }
& $Tool --tools compatibility --source-root $Client --output-root $Overlay --dungeon7 --overwrite --apply
if ($LASTEXITCODE -ne 0) { throw '五村兼容安装失败' }
& $Tool --tools verify-resources --client-root $Client --kind lumineos
if ($LASTEXITCODE -ne 0) { throw '安装后资源校验失败' }
```

5. 核对`$Overlay/nanaimo_compatibility_report.json`中的`verification.all_pass=true`、逐文件应用结果及大小／摘要。再次执行第四步只读预检，确认结果一致。启动器“开启全部地宫进入权限”关闭时使用顺序规则，显式开启时使用当前可玩区域的全图权限。

## 恢复

恢复按客户端兼容、资源安装、运行程序的逆序执行。每项恢复前校验当前文件等于该事务登记的应用后摘要，并确认备份摘要匹配原值。

1. 客户端兼容的原文件保存于`$Overlay/backups/<原SHA-256>/<相对路径>`。按报告逐项恢复`game.exe`、地图包、原有别名和已移除图像；对事务中新建的别名，按登记结果移除。随后核对安装前大小及SHA-256。
2. 首次安装L7/L8资源时，按该次资源收据执行恢复：

```powershell
python -B scripts/port_lumineos_resources.py rollback --client $Client --receipt '<L7/L8安装收据相对路径>'
if ($LASTEXITCODE -ne 0) { throw 'L7/L8资源恢复失败' }
```

3. 按成套程序部署收据恢复运行程序、启动器与清单：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root $Client --rollback '<程序部署收据相对路径>'
if ($LASTEXITCODE -ne 0) { throw '运行程序恢复失败' }
```

恢复后按对应版本重新核对程序、资源和安装收据。角色通关记录使用独立持久化。
