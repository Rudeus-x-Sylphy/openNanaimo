# 客户端二进制补丁／挑战单槽计分板升级

## 配套范围

四关身份为`hd0/ep24..27/dg0/st0/difficulty0`；成绩表显示四行，Epi框内为原生数字贴图01／02／03／04，每行一个评级格，提示左侧为当前关卡名。旧成绩按角色与挑战合并为最佳评级和最高分，耗时归属最高分获选行；数据库迁移采用单次事务。

客户端基线、完整入口和原指令要求见[程序位点](修道僧四村对白安装/程序位点.md)。单槽实现更新VA `0x6E5800`的5,632字节窗口，入口沿用`0x8C25A8`、`0x8C30ED`、`0x6FA50D`、`0x6FA591`。精确目标字节及已登记输入由`managed-host/Resources/client-compatibility.json`的`monk-dialogue`位点维护；新运行程序集内嵌同一配方。

## 安装顺序

1. 正常退出目标客户端及适配器，备份运行时、兼容客户端、资源标记与角色数据库。确认基础L7/L8、1,154项挑战战斗资源及原35项场景资源符合各自配方。
2. 在全新目录生成37项场景包；使用者准备匹配源资源、目标客户端与合法字体。逐文件核对包内`recipe.json`与当前配方，保存`before`和`manifest.json`。

```powershell
python -B scripts/prepare_monk_dialogue.py build --source '<source-client>' --client '<client-root>' --output '<fresh-entry-bundle>' --font '<user-owned-simsun.ttc>'
python -B scripts/prepare_monk_dialogue.py apply --bundle '<fresh-entry-bundle>' --client '<client-root>'
python -B scripts/prepare_monk_dialogue.py verify --client '<client-root>'
```

已安装旧版场景包时，build命令增加`--baseline-recipe '<reviewed-previous-recipe.json>'`，仅用于按旧配方校验已安装收据、父资源叠加和完整文件摘要；新包仍必须匹配当前配方。不得用目标目录自行拼凑的摘要替代审核过的旧配方。已有450×336布局的边缘清理升级仅改变上述IM3字节，EFF和客户端程序位点不变；仍按完整37项资源事务安装，并配套更新内嵌资源摘要的适配器，不能单独覆盖图片后保留旧收据或旧校验程序。

3. 成套部署`adapter_manifest.json`登记的运行文件，包括Adapter、Gameplay、原生桥接及资源数据。保留同版源码与发布清单。
4. 使用同版工具先预检再应用兼容客户端。精确位点已知输入与目标摘要共同决定可迁移资格，完整程序备份与兼容收据随输出保存。

```powershell
.\adapter_runtime\Nanaimo.Adapter.exe --tools compatibility --source-root '<client-root>' --output-root '<fresh-overlay>' --dungeon-state --dungeon7 --monk-dialogue --dry-run
.\adapter_runtime\Nanaimo.Adapter.exe --tools compatibility --source-root '<client-root>' --output-root '<fresh-overlay>' --dungeon-state --dungeon7 --monk-dialogue --apply
.\adapter_runtime\Nanaimo.Adapter.exe --tools verify-resources --kind monk-dialogue --client-root '<client-root>'
.\adapter_runtime\Nanaimo.Adapter.exe --tools verify-resources --kind lumineos --client-root '<client-root>'
```

5. 兼容结果要求`verification.all_pass=true`，场景资源计数37，战斗资源计数1,154。启动适配器完成数据库可写初始化，再按角色恢复四个单槽成绩。社交槽位同步方式见[安装与恢复](修道僧四村对白安装/安装与恢复.md#社交槽位资源同步)。

## 恢复与所有权

安装事务保存每项文件的前后SHA-256、原件及上一版标记。恢复时先恢复成套运行时和兼容程序，再按场景收据恢复替换项并清理摘要相符的新增两项资源：

```powershell
python -B scripts/prepare_monk_dialogue.py rollback --client '<client-root>' --receipt '<entry-receipt>'
```

数据库版本恢复须单独核对当前角色进度与结构。场景恢复的作用域为收据列出的资源；角色数据按数据库恢复契约处理。安装和恢复后均重新核对程序、场景、战斗与基础资源身份。
