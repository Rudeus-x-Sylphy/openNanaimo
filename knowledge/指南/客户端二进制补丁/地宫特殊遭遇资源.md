# 客户端二进制补丁／地宫特殊遭遇资源

## 配套范围

当前地宫加载支持组队、情侣、稀有及神秘遭遇资格，房间内共享本关计划。概率与资格见[特殊遭遇](../../业务/地宫/关卡与房间/特殊遭遇与闲置资源.md)，生命规则见[目标身份与生命账本](../../业务/地宫/伤害与目标/目标身份与生命账本.md#kb-06-006)。

本次配套更新的资源为`adapter_runtime/资源/数据/dungeon_combat_catalog.bin`。DCC7大小12,253,130字节，SHA-256为`490B4DAF7BAF994524D3CAFFAAA549B58D9EF5430D264E65A42EAC00B650D6F4`。其中1,120条组队、稀有及神秘运行记录的HP与原生计算规则对齐；基础属性、选择器、计分及掉落字段保持原值。情侣既有4,298条运行记录沿用相同规则。

所需文件完整包含在同版仓库的`adapter_runtime/`中，配套`Nanaimo.Adapter.exe`、`Nanaimo.Adapter.dll`、`Nanaimo.Gameplay.dll`、`nanaimo_gameplay_bridge.exe`及其依赖。`release/components/combat_economy/combat_score_resource_data.inc`登记匹配的DCC7摘要；三份活动清单维护源码、运行文件及发布身份。客户端使用现有SSTG、SMMO、MMO及关联资源；各关按所选编队的实际放置生成对象。

## 安装与核对

1. 正常退出目标客户端、适配器与原生桥接，保留匹配的安装目录和备份。
2. 在同版仓库根目录执行程序与资源预检，再应用成套部署：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root '<client-root>'
python -B scripts/deploy_adapter_runtime.py --client-root '<client-root>' --apply
python -B scripts/verify_package.py --root '<client-root>'
```

3. 保存部署返回的`receipt`。安装事务逐项备份和校验DCC7、程序集、原生桥接、目录及清单，遇到用户修改时按身份约定处理。
4. 从目标目录的`start_nanaimo_launcher.bat`启动。生成资格在每次关卡加载时冻结，重试或续关使用新关卡计划。

## 恢复

正常退出客户端与运行程序后，使用同一部署事务的相对收据恢复完整配套版本：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root '<client-root>' --rollback '<deployment-receipt>'
python -B scripts/verify_package.py --root '<client-root>'
```

恢复时逐项核对目标及备份摘要。当前验证覆盖资源归一化、幂等、原生与托管构造；双端连续游玩范围归[地宫验证状态](../../工程/验证状态/地宫与成长验收.md#特殊遭遇资源调查)。
