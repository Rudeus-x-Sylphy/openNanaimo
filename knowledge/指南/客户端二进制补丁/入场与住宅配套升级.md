# 客户端二进制补丁／入场与住宅配套升级

## 升级内容

秘密关卡四村入场费依次为3,000、30,000、80,000、150,000金币，采用报价、确认、事务支付和单次入场授权。免费券与自由券按有效装备及期限提供权益。住宅入室缓存、温度计和实际恢复共用房主TOTAL对应的HP／MP恢复量。

本次交付对象为托管运行程序、配套依赖、目录和发布清单；客户端程序与资源保持当前兼容配方。业务规则见[秘密关卡入口与费用](../../业务/地宫/关卡与房间/房间身份.md#秘密关卡入口与费用)及[住宅访问恢复](../../业务/住宅/访问恢复.md#入室缓存与温度计重建错配)。

## 完整配套

| 文件或目录 | 安装用途与处理方式 |
|---|---|
| `adapter_runtime/Nanaimo.Adapter.exe`、`Nanaimo.Adapter.dll`、`Nanaimo.Adapter.pdb` | 成套替换启动宿主及配套符号 |
| `adapter_runtime/Nanaimo.Gameplay.dll`、`Nanaimo.Gameplay.pdb` | 成套替换入场支付与住宅恢复实现及配套符号 |
| `adapter_runtime/nanaimo_gameplay_bridge.exe` | 按当前运行清单配套安装原生服务 |
| `adapter_runtime/资源/数据/ava._D1` | 装备与两类入场券目录，使用当前运行清单登记的完整文件 |
| `adapter_runtime/资源/数据/`其余目录与`adapter_runtime/`全部依赖 | 逐项依照`adapter_manifest.json`的`files`清单安装，目录结构与相对路径保持一致 |
| `adapter_runtime/adapter_manifest.json` | 全量运行文件的大小及SHA-256 |
| `manifest/source_closure.json`、`manifest/open_release_manifest.json`、`manifest/patch_allowlist.json` | 源码、发布文件及分发候选身份 |
| 活动发布清单内的启动器、安装工具、源码与知识页 | 与运行程序同批同步 |

当前运行包的全量资源及依赖以运行清单为完整逐文件列表。安装器按相同相对路径逐项写入、保留原文件备份，并登记新增文件和替换文件。客户端二进制派生沿用[统一安装与恢复](统一安装与恢复.md#df-12-011)，既有资源专项使用[教程与商城资源配套](教程与商城资源配套.md)及[补丁指南索引](索引.md)中的对应完整清单。

## 安装步骤

1. 准备完整发布目录，保留目标目录中的个人配置与角色数据，停止目标适配器及原生服务。
2. 在发布目录执行源码校验及目标预检，确认预检列出的新增／替换文件：

```powershell
python -B scripts/verify_package.py --source-only
python -B scripts/deploy_adapter_runtime.py --client-root "<客户端目录>"
```

3. 执行事务安装；安装器按清单核对源文件与目标文件，并生成逐文件备份及恢复回执：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root "<客户端目录>" --apply
python -B scripts/verify_package.py --root "<客户端目录>"
```

4. 使用目标目录的运行程序完成入场与住宅专项检查：

```powershell
& "<客户端目录>/adapter_runtime/Nanaimo.Adapter.exe" --secret-entry-self-test
& "<客户端目录>/adapter_runtime/Nanaimo.Adapter.exe" --health-recovery-self-test
& "<客户端目录>/adapter_runtime/Nanaimo.Adapter.exe" --apartment-gameplay-self-test
```

5. 从目标目录启动器进入游戏，核对四村报价、确认后余额、有效券权益、重新入场报价，以及房主／访客温度计与恢复量的一致性。当前自动验收覆盖适配器事务与启动集成，画面验收单独登记。

## 恢复步骤

1. 停止目标适配器及原生服务，定位本次安装的`deployment_backups/<安装目录>/receipt.json`。
2. 执行回执恢复，安装器核对当前文件、备份摘要及安装归属后逐文件还原：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root "<客户端目录>" --rollback "deployment_backups/<安装目录>/receipt.json"
python -B scripts/verify_package.py --root "<客户端目录>"
```

3. 使用恢复版本的启动器和运行程序重新启动服务。
