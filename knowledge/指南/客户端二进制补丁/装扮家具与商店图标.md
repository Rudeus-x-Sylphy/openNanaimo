# 客户端二进制补丁／装扮家具与商店图标

## 交付范围

配套资源包含900条韩服追加装扮、5件科比纪念装扮、1227条追加家具、中文名称及说明、币种与售价、模型、动作和图标依赖。客户端与适配器均包含4790条装扮和2008条家具。业务规则见[商城定价](../../业务/经济/商城/目录币种与购买.md#韩服增量商品定价)及[科比套装](../../业务/库存/装备/期限效果与资源范围.md#科比纪念套装)，格式与兼容要求见[追加装扮与家具](../../工程/资源安装/追加装扮与家具.md)。

本次客户端修正采用资源文件替换：商店图标键`10127`和`300272`的IM3定位原点统一为左上角`(0,0)`；图像尺寸、像素、记录键和商品关联保持原值。两张图标覆盖墨西哥国旗男女各三款、男款澳洲牛仔下装三款，共9条商品。完整装扮动作、特效与家具交互按[验证状态](../../工程/验证状态/文档与静态调查记录.md#商店图标定位)登记。

## 安装步骤

1. 正常退出目标客户端、适配器与原生桥接，保留当前安装目录及其备份目录。
2. 在同版仓库根目录校验资源包及目标安装计划：

```powershell
python -B scripts/package_wardrobe_resources.py verify
python -B scripts/package_wardrobe_resources.py install --client-root '<client-root>'
```

3. 应用资源事务。首次安装完成546项资源；从既有韩服装扮版本升级时，替换`ava._D1`和三个Avatar包，新增上述15项独立文件，并更新安装标记：

```powershell
python -B scripts/package_wardrobe_resources.py install --client-root '<client-root>' --apply
```

4. 按[程序与清单部署](章节表与对白安装.md#自动部署)配套同版运行程序、启动器、脚本及清单。对于已符合活动发布约定的安装目录，可使用：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root '<client-root>'
python -B scripts/deploy_adapter_runtime.py --client-root '<client-root>' --apply
powershell -NoProfile -ExecutionPolicy Bypass -File '<client-root>/gui_launcher/korean_wardrobe_resource_identity.ps1' -ClientRoot '<client-root>'
powershell -NoProfile -ExecutionPolicy Bypass -File '<client-root>/gui_launcher/nanaimo_launcher.ps1' -ValidateOnly
```

5. 保留两次事务返回的`receipt`。从`start_nanaimo_launcher.bat`进入，男角色在“装扮查表”点击“穿戴科比套装”，保存配置后启动；商品格可同时检查男款澳洲牛仔下装及男女墨西哥国旗图标。

## 资源派生

使用匹配的完整资源输入及CN基础安装，可重新生成相同配方。输入表身份、容量、全部依赖、中文文本、旧记录保留和两项图标定位同时校验：

```powershell
python -B scripts/prepare_korean_wardrobe.py --source-root '<resource-root>' --client-root '<baseline-client>' --output '<fresh-stage>'
python -B scripts/prepare_kobe_wardrobe.py --client-root '<wardrobe-client>' --output '<kobe-stage>' --baseline-recipe '<fresh-stage>/project/manifest/korean_wardrobe_resources.json'
python -B scripts/prepare_kobe_wardrobe.py --verify '<kobe-stage>'
```

`wardrobe-client`使用完整韩服装扮安装；科比生成环境另需Pillow及`%WINDIR%/Fonts/arialbd.ttf`，可用`--font`指定配套字体。两阶段生成目录的`client/`保存资源输出；`project/`保存适配器资源表、原生目录、启动器目录及预览，`ready.json`登记文件身份。将科比阶段`project/`的生成文件同步到构建仓库后，按[构建与验证](../构建与验证/索引.md)构建同版程序，并生成资源包：

```powershell
python -B scripts/package_wardrobe_resources.py build --source '<kobe-stage>/client' --output '<new-archive>.zip'
```

活动清单与资源配方随版本成套发布。资源包构建逐项验证输出，已有输出路径由覆盖保护保留。当前完整安装可直接作为科比阶段输入，逐项身份校验后生成同一组客户端资源。

## 恢复步骤

1. 正常退出客户端与运行程序。
2. 按程序部署返回的相对收据恢复同版程序、脚本、预览与资源配方，再按资源安装返回的绝对收据恢复客户端资源。一次发布包含多次资源事务时，按应用顺序的逆序逐次恢复收据；配方身份更新同样保留独立收据：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root '<client-root>' --rollback '<deployment-receipt>'
python -B scripts/prepare_korean_wardrobe.py --client-root '<client-root>' --rollback '<resource-receipt>'
```

3. 资源备份位于`.openNanaimo-wardrobe-backups/<transaction>/files/`。升级事务恢复升级前图标包和安装标记；首次安装事务恢复6项原文件并清理本事务新增项。恢复过程逐项核对当前身份与备份身份，用户后续修改由冲突保护保留。
4. 核对恢复版本的运行清单、启动器及资源配方后重新启动。
