# 地宫过场中文资源安装

## 安装对象

本安装项交付普通关卡与BOSS的160个战前／战后演出、720张中文台词图、44项共用图像及2项关卡演出引用修正，共926项资源。演出与图片位于`effs/game/shootinggamebasic/Ending_Event`，关卡引用位于下列两项SSTG。ep08～ep15恢复64个完整演出；L1～L8中文化144张台词图，前期译图修订37张。

过场由客户端既有关卡事件和结算播放入口读取。此安装项的程序配套是带过场资源校验功能的适配器与社交启动辅助；客户端程序字节沿用当前兼容版本。资源恢复与程序恢复分别使用各自的事务收据。

## 安装顺序

先安装匹配版本的程序与启动辅助，再完成L7/L8、修道僧及其他现有资源事务，最后安装本过场资源包。L8的18张中文台词作为受校验的覆盖层，由完整过场配方与父资源摘要共同限定。

以下命令从项目根目录执行，`<客户端目录>`填写实际中文客户端根目录。执行安装和回退前退出该目录及其社交槽位的游戏客户端。Python 3.10及以上用于资源安装；预制资源包的安装仅使用标准库。

配套程序部署使用现有程序事务入口，执行前退出目标适配器和工作进程，保留其角色数据：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root '<客户端目录>'
python -B scripts/deploy_adapter_runtime.py --client-root '<客户端目录>' --apply
```

部署结果中的`receipt`记录程序原字节及发布清单；随后执行资源安装：

```powershell
python -B scripts/dungeon_cinematics.py plan --kit resource-packs/nanaimo-dungeon-cinematics-kit.zip --client '<客户端目录>'
python -B scripts/dungeon_cinematics.py apply --kit resource-packs/nanaimo-dungeon-cinematics-kit.zip --client '<客户端目录>'
python -B scripts/dungeon_cinematics.py verify --client '<客户端目录>'
```

`plan`执行完整资源包和目标预检。当前已知基线首次安装改变247项资源：64个演出、181张台词图与2项关卡演出引用。其他679项参与成套校验并保持现有字节。未知目标身份作为冲突处理，原有定制内容由维护者核定后另建明确配方。

`apply`持有独占资源锁，先保存全部待改文件的原字节，再登记`applying`收据，逐文件原子替换并联合验证926项资源。提交后写入`.openNanaimo-dungeon-cinematics.json`。重复安装核对完整资源和收据后返回`already-installed`。

原字节和事务收据位于`.openNanaimo-resource-backups/cinematics-<事务标识>/`，安装结果中的`receipt`为准确相对路径。该目录应与客户端一同保留。

## 校验与社交槽位

适配器使用内置配方核对全部926项资源：

```powershell
adapter_runtime/Nanaimo.Adapter.exe --tools verify-resources --kind cinematics --client-root '<客户端目录>'
adapter_runtime/Nanaimo.Adapter.exe --tools verify-resources --kind lumineos --client-root '<客户端目录>'
```

社交启动按同一配方检查主目录和工作目录，核对资源后同步安装身份。目录链接使用主目录的当前内容；复制式槽位按逐文件摘要识别其版本。需要重建复制式槽位时，先按该槽位的既有准备清理入口处理，再重新准备：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File gui_launcher/start_social_client.ps1 -ClientPath '<客户端目录>/game.exe' -WorkingDirectory '<客户端目录>' -SocialSlot 1 -CleanupPreparedCopy
powershell -NoProfile -ExecutionPolicy Bypass -File gui_launcher/start_social_client.ps1 -ClientPath '<客户端目录>/game.exe' -WorkingDirectory '<客户端目录>' -SocialSlot 1 -PrepareOnly
```

P2／P3分别填写相应槽位。启动器沿用原有角色、账号与资源准备约定。L7/L8父资源校验接受已登记的中文覆盖身份，过场完整性仍由926项配方校验。

## 回退与恢复

```powershell
python -B scripts/dungeon_cinematics.py rollback --client '<客户端目录>' --receipt '.openNanaimo-resource-backups/cinematics-<事务标识>/receipt.json'
```

回退先核验全部现有文件和备份摘要，再按逆序恢复原字节并移除本事务的安装标记。用户后续修改受到摘要保护。中断事务保留`applying`状态，使用其准确收据完成恢复后继续安装。重复回退返回`already-rolled-back`。

资源回退完成后，配套程序按其部署收据恢复：

```powershell
python -B scripts/deploy_adapter_runtime.py --client-root '<客户端目录>' --rollback '<程序部署结果中的receipt>'
```

L7/L8、修道僧等父资源事务按其独立安装顺序逆向恢复。每项事务保留自身资源所有权和原始备份。

## 构建配方

重新制图使用单独的韩服输入、安装前中文客户端基线与全新候选目录。完整源码及字幕译稿随仓库交付，字体单独由构建者提供。

固定字体为`simsun.ttc`，18,070,492字节，SHA-256为`120a51d2b14eb588700a21e15fc301f0ea55d7c1a4e1f3ae61db83b7c8d42cd6`，字体面索引0；栅格化使用Pillow 10.4.0／FreeType 2.13.2，字形覆盖由fontTools检查，关卡结构解析使用PyCryptodome。颜色为白色，透明底，字距0，单行，字号14～20，逐图字号及可见边界见配方。58张短句画布升至24像素高，宽度和演出轨道保持原有值，纵向定位点同步至画布中心。

```powershell
python -B scripts/dungeon_cinematics.py build --source '<韩服目录>' --baseline '<安装前中文客户端基线>' --output '<全新候选目录>' --font '<字体路径>/simsun.ttc'
python -B scripts/dungeon_cinematics.py package --built '<候选目录>' --output '<输出目录>/nanaimo-dungeon-cinematics-kit.zip'
python -B -m unittest discover -s scripts -p test_dungeon_cinematics.py -v
```

构建默认与已登记配方逐项相等。经审核的译稿或排版变更使用`--write-recipe`生成新配方，并重新构建配套适配器、资源包和发布清单。构建过程输出隔离候选，安装由显式`apply`命令执行。

结构覆盖、译稿审校、编码回读、事务验证与运行验收归[地宫过场中文资源](../../工程/验证状态/地宫与成长验收.md#地宫过场中文资源)。业务规则见[地宫过场资源](../../业务/地宫/BOSS/阶段推进与开场.md#地宫过场资源)。
