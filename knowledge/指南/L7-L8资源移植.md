# 韩服 L7/L8 资源与代码部署

`scripts/port_lumineos_resources.py` 从匹配且合法取得的韩服资源生成选择性增量包（仓库资源包已提供登记输入，也可使用自行准备的匹配副本）。转换和安装分开：安装、校验及回滚仅使用 Python 标准库；构建转换还需要 PyCryptodome。基础客户端由使用者合法提供；登记的可选输入与安装输出见[随仓库资源包](韩服L7-L8与宠物资源说明.md#df-17-006)。

<!-- FUSION END df-03-001 -->

## 安装与部署入口

1. 核对[资源范围与安装资格](../工程/地宫资源兼容/范围与前置进度.md#df-03-002)，按[资源包安装步骤](韩服L7-L8与宠物资源说明.md#df-17-006)校验包身份并执行转换／安装。
2. 保存输出备份及事务收据；原位升级、异常恢复和回滚前置条件见[资源事务](../工程/资源安装/事务与恢复.md#df-03-003)。
3. 代码部署与资源安装分别执行，按下文“代码与状态一致性”预检和应用；场景／社交副本启动核查见[启动一致性](../工程/地宫资源兼容/范围与前置进度.md#df-03-004)。
4. 客户端EXE修改的前置条件、精确位点及完整应用／回滚约定见[地宫资源兼容（小地图补丁）](../工程/地宫资源兼容/小地图补丁.md#df-11-004-minimap)。验证通过后，按[验证状态](../工程/验证状态/README.md)登记独立客户端验收。

## 定向验证

真实资源检查按本地资源可用性执行或条件跳过，事务和合成场景检查使用隔离输入。具体入口及当前覆盖范围见[构建与验证](构建与验证/README.md)和[验证状态](../工程/验证状态/README.md)；历史“两个检查”的计数不作为现行测试数量。

## 代码与状态一致性

生成器输出到独立目录，须审核后纳入源码与发布数据；它不会自行覆盖正式目录。DCC7、普通 HP 和BOSS目录同时生成，再以当前脚本生成碰撞／地形目录并更新清单，不能只拷贝其中一个表。完整适配器构建默认从 `adapter_runtime/资源/数据/` 取数据，也可通过 `-ResourceDataRoot` 显式指定匹配输入，避免使用旧的本地构建缓存。

部署命令默认只预检；`--apply`先拒绝活动进程，保存代码原字节及配置／存档快照，调用资源事务，再发布清单内文件及单字节小地图兼容项。正式配置与存档保持原内容，下一次启动执行保留旧称号行的R8数据库约束迁移。失败结果不授予R8；成绩按独立区域、阶段和难度保存。HP采用资源字段与适配器缩放规则；卡池和地形对象采用已确认条目的严格资格规则。

回滚需要所有游戏／适配器退出，且文件匹配应用后摘要。代码收据包含资源事务收据；角色存档保持当前进度。开始新游戏后若需要退回旧数据库版本，应另行审查备份与新增进度，不能把安装前存档直接覆盖回来。
