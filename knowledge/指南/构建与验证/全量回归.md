## 完整 Python 回归

### 独立地宫诊断

`--pet-growth-self-test`使用独立工作进程进程和临时状态目录，接受显式`--native <受测bridge路径>`，默认使用测试程序同目录bridge并严格检查文件存在性。其它使用默认native端口的专项在独占环境执行。

```powershell
python -B scripts/test_dungeon_selftest_isolation.py
dotnet run --project tests/NativeDungeonPoolRegression -c Release -f net8.0 -- '<受测bridge路径>'
```

独立连接隔离回归以`NANAIMO_SOCIAL_BRIDGE`指定受测bridge，自动启动隔离端口及临时进程；覆盖3-1／3-3三种资源难度、诊断CF6C／CF70／CF77／CF7F无成员推送、原BOSS持续扣血及诊断断开无CF74。原客户端连续输入与画面仍须独立验收，候选发布范围见知识库[工程／验证状态](../../工程/验证状态/README.md)。

```powershell
python -B -m unittest discover -s scripts -p 'test_*.py' -v
```

回归及专项结果按受测程序身份、日期、统计单位和通过／失败／跳过状态归属，见知识库[工程／验证状态](../../工程/验证状态/README.md)“验证记录的版本边界”。原生生命周期、频道重入、卡片掉落和结算采用确定性检查，结果与对应受测版本共同维护。

新增状态及迁移检查：

```powershell
python -B scripts/test_native_cf72_lifecycle.py
python -B -m unittest discover -s scripts -p test_client_binary_migrations.py -v
```

`NANAIMO_AUDIT_CLIENT` 指定使用者自备客户端的只读输入路径，默认查找仓库父目录的 `game.exe`。对应检查在隔离执行环境中验证原始指令，工厂分配、资源构造和窗口容器使用明确的模型边界；验证范围为分支、类型映射与兼容迁移。

### 整页卡片组合专项

整页组合专项覆盖二十页映射、材料／产物容量、会话授权、请求幂等、事务回滚及生产分发。卡片更新工具以已安装源码约定生成候选，按源码快照与程序集身份完成逐文件安装事务；运行包、角色数据与客户端分别维护。当前验证范围见知识库[工程／验证状态](../../工程/验证状态/README.md)。

### 卡片分布专项

```powershell
python -B scripts/generate_cn_card_drops.py --check
python -B scripts/test_cn_card_drops.py
```

- 卡池由 `release/components/cards/card_drop_cn.csv` 和 `card_drop_cn_boss_bindings.json` 精确生成；无需外部资源即可核对已登记输入。
- 更新CSV后，使用 `python -B scripts/generate_cn_card_drops.py --client-root "<client-root>"` 重新登记实际SSTG/SMMO的BOSS槽绑定；加 `--check` 只读核对资源与输出。
- 不得只改生成C表，或按MMO名将不同地图的候选合并。
- 导入带权重表使用 `python -B scripts/generate_cn_card_drops.py --xlsx "<xlsx>" --client-root "<client-root>"`（仅导入需要openpyxl）。
- 同一地图／资源中相同rate归为一个概率组，各组rate相加为基础掉卡率，命中后按组内weight选择一张；SP不再单独roll。
- 零权重、收益加成、domain22及箱子资格限制见知识库[地宫掉落](../../业务/地宫/掉落/README.md)；验证范围为目录构造、概率边界与生成一致性，发布状态见[工程／验证状态](../../工程/验证状态/README.md)。
