## 准备房、恢复与娱乐室专项

```powershell
dotnet run --project tests/NativeCoupleConsumablesRegression -c Release
dotnet run --project tests/RevivalBillingRegression -c Release
dotnet run --project tests/MentorshipRegression -c Release
python -B -m unittest discover -s scripts -p test_social_gameplay_compat.py -v
adapter_runtime/Nanaimo.Adapter.exe --health-recovery-self-test
python -B -m unittest discover -s scripts -p test_entertainment_resources.py -v
python -B -m unittest discover -s scripts -p test_social_apartment_resources.py -v
```

原生情侣专项通过 `NANAIMO_SOCIAL_BRIDGE` 指定当前隔离构建。自动恢复验证覆盖各档阈值、温度计完整字段、70／20住宅基础档、50／10城镇恢复、封顶及持久化。复活专项覆盖队员最终开始确认、独立原生房间和大编号角色的当前战斗身份。

- 历史未归属记录包含娱乐室 327 项、原生情侣恢复 149 项、地宫转换 457 项、复活支付 86 项、多人结算 66 项及情侣场景 325 项；原文另称“合计 1410 项通过”。
- 逐项相加为 1410 项，但统计是否去重、单位与受测版本／日期均未登记，因此只保留为历史记录，不作为当前验证结果。
- 娱乐室覆盖共同开场、幸运积分、独立计时、全员机会耗尽和逐角色单次奖励；情侣专项覆盖真实加入流程的关卡身份与恢复绑定；BOSS专项覆盖火焰宝珠本体／冰棱共同血量和独立终结；场景伤害专项覆盖关联发光体的三档资源选择与完整受伤处理。
- 客户端兼容专项覆盖队员回城按钮显示、输入、精确迁移及幂等。
- 验证层级为适配器状态机、工作进程及隔离指令。

### 韩服宠物与英雄龙验证

```powershell
python -B -m unittest discover -s scripts -p test_korean_pets.py -v
python -B -m unittest discover -s scripts -p test_hero_dragon.py -v
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test_korean_pet_resource_identity.ps1
powershell -NoProfile -ExecutionPolicy Bypass -STA -File gui_launcher/nanaimo_launcher.ps1 -SelfTestKoreanPets
powershell -NoProfile -ExecutionPolicy Bypass -STA -File gui_launcher/nanaimo_launcher.ps1 -SelfTestHeroDragon
adapter_runtime/Nanaimo.Adapter.exe --launcher-profile-self-test
```

专项验证121条新增宠物逐项低等级直接指定、三阶资源限制、目录和攻击行、增量安装与回退；验证范围为配置、目录及资源事务。完整启动自检须先退出正在使用固定native端口的游戏／适配器；不要把独立pet-growth检查连接到用户活动bridge。当前目录为990条，发布约定与验证范围见知识库[工程／验证状态](../../工程/验证状态/README.md)。

定向修复构建可用`-PetRecipePath`指定部署所采用的已审核宠物资源配方；编译前按该配方核对实际资源身份。该参数与`-ResourceDataRoot`共同支持资源保持型程序更新。

可选子弹DIY／篮球使用独立PowerShell安装器；功能范围见[子弹DIY与篮球试玩](../子弹DIY与篮球试玩.md)，安装、迁移、回退和专项验证统一见[完整适配器与客户端兼容说明](../完整适配器与客户端兼容说明.md)。
