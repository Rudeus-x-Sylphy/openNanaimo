## 地宫专项

宠物黄金粉末与寿命专项由`--pet-progression-self-test`、`--pet-material-classification-self-test`及`test_pet_lifetime.py`覆盖990种目录、精确经验阈值、强化后镶嵌／结算／数据库重开，以及英雄龙耐久50与永久期限。验证范围为主机构造、资源迁移及数据库事务，原客户端显示采用独立运行验收。

蓄力与MP吸收专项由`test_charge_mp.py`及`test_charge_mp_wire.py`维护发射记账、时钟幂等、房间／战斗周期门控及资源快照；`test_mana_absorption.py`覆盖多次伤害的小数余量、MP从零恢复和有效上限。验证范围为生产状态机与资源构造。

L8目录、十八槽、导航、R8持久化专项：`python -B -m unittest discover -s scripts -p test_lumineos_combat.py -v`；`adapter_runtime/Nanaimo.Adapter.exe --lumineos-self-test`。完整构建自检也包含该专项，资源约定与验证范围见 `L7-L8资源移植.md`。

### 新手引导装备阶段回归

```powershell
dotnet run --project managed-host/Nanaimo.Adapter.csproj -c Release -f net8.0 -- --tutorial-appearance-self-test
```

该专项同时接入完整适配器的 `--self-test`。临时数据库覆盖男女角色各4组特效状态、无角色入口、sidecar优先级、引导中重登、有效／非法／重复 `C353`、`C354` 库存门控、首次 `C368` 全外观恢复、已完成角色重登及配置原文保留。验证范围为协议构造、数据库状态与请求顺序。

### 纯新手档启动回归

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -STA -File gui_launcher/nanaimo_launcher.ps1 -SelfTestPureNewPlayer
dotnet run --project managed-host/Nanaimo.Adapter.csproj -c Release -f net8.0 --no-build -- --pure-new-player-self-test
```

GUI 检查覆盖位于普通用户名之上的新手档控件、隔离 runtime profile、合法且已过期的可选权益日期、强制 `skip_tutorial=0` 与 `unlock_all_dungeons=0`、零宠物／货币／技能种子、核心服务就绪和常规 INI/JSON 保持一致。Host 检查验证无角色账号、客户端建角等价路径、等级1、零货币/SP、零库存、零任务行和未完成引导状态。

### 任务系统定向检查

```powershell
adapter_runtime/Nanaimo.Adapter.exe --quest-system-self-test
```

覆盖任务目录、固定主线、C599 非零尾部、任务交付／奖励、连续地宫目标、限制任务、技能、复活、合成宠物与家具目标。多目标主线另检查C59C记录+3的当前目标索引、最后一项安全索引、旧档地宫1与3已完成时指向地宫2、重复刷新、重开及补完缺项；仅核验Progress3累计数不足以证明客户端条件已展开。启动式自检被在线固定端口占用时保留失败记录，独立任务专项不代替原客户端画面验收。
