# 构建与验证

以下命令均从仓库根目录执行。按具体检查准备 Python、TinyCC、.NET SDK 或匹配客户端；并非每条命令都需要全部依赖，具体条件见各专项。构建脚本支持指定仓库外工具路径。下列`dotnet`命令使用PATH中的SDK；SDK位于其他位置时，将命令替换为实际`dotnet.exe`路径。

|---|---|
| 核对文档迁移、源码闭包、候选及发布清单；区分只读验证与写入刷新。 | [文档与发布检查](文档与发布检查.md) |
| 执行竞技场、娱乐室与准备房专项，说明构造／事务／隔离指令的覆盖边界。 | [竞技与娱乐专项](竞技与娱乐专项.md) |
| 运行完整 Python 回归及隔离地宫、卡片生成检查；外部客户端缺失条件单独登记。 | [全量回归](全量回归.md) |
| 验证地宫资源、复活、加载、引导与任务状态；每组命令保留原有输入前提。 | [地宫专项](地宫专项.md) |

| 执行 GUI 自检和离线库存事务检查，限定实际客户端与服务的操作边界。 | [GUI与离线工具](GUI与离线工具.md) |

## 知识库迁移检查

下列检查核对原 `docs/` 文档的完整字符覆盖、当前片段唯一性、正文信息和本地链接。严格模式用于核对融合时的历史内容；日常维护使用默认模式检查完整覆盖与链接，并报告已编辑片段。维护约定见[知识维护](../../工程/知识维护.md)，含源码闭包与发布清单的完整检查清单见[文档与发布检查](文档与发布检查.md#知识库与文档)。

```powershell
python -B scripts/verify_document_fusion.py
python -B scripts/verify_document_fusion.py --self-test
```

## 修道僧挑战专项

```powershell
python -B scripts/test_monk_resources.py
python -B scripts/test_monk_combat.py
.\.dotnet\dotnet.exe run --project tests/MonkChallengeRegression -c Release
```

专项分别验证资源转换与安装事务、第一关逐槽战斗目录，以及独立四位通关账本和生产选择边界。资源安装步骤见[客户端二进制补丁](../客户端二进制补丁/README.md)。当前实现状态为`four-village-dialogue-entry`、入口绑定（`entry_binding`）为`village-dialogue-bound`。修道僧入口、四关挑战及排行榜已获用户验收确认，受测版本待补录；原清单`runtime_acceptance=false`与该确认分别归属，范围见[修道僧挑战验收](../../工程/验证状态/修道僧挑战验收.md)。
