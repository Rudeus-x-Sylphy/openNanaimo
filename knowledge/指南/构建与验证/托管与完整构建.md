## 托管构建与社交专项

### 社交专项

`tests/SocialRegression` 覆盖好友申请确认、在线会话有效性、定向私聊、组队准备、求婚及关系事务、三种戒指权益、战斗参与者限定、观战与多人续关。原生专项在实际桥接进程中同时验证银、金、钻戒的独立恢复量及库存扣减；启动专项验证工作目录、缓存、配置、参数引用、元数据和清理安全。验证等级按托管构造、原生隔离执行、双客户端启动和客户端场景验收分别登记。

```powershell
dotnet run --project tests/SocialRegression/SocialRegression.csproj -c Release
dotnet run --project tests/SocialRegression/SocialRegression.csproj -c Release -- --couple-food-only
dotnet run --project tests/PureNewPlayerRegression/PureNewPlayerRegression.csproj -c Release
dotnet run --project tests/NativeDungeonPoolRegression/NativeDungeonPoolRegression.csproj -c Release
python -B tests/SocialRegression/test_native_social.py
python -B scripts/test_social_multiclient_helper.py
python -B scripts/test_launcher_contract.py
powershell -NoProfile -ExecutionPolicy Bypass -STA -File scripts/test_launcher_responsiveness.ps1
```

`--couple-food-only`按生产分派验证情侣城镇、准备房、地宫和结算的C43D／C46D双向回血回蓝、单次扣药、并发、重放、事务回滚、工作进程状态导入及死亡／转换门控。使用`NANAIMO_COUPLE_BRIDGE`指定当前隔离构建的bridge；城镇D8FF、准备房CF72、战斗／结算CF94分别断言，不将主机构造或工作进程执行计为原客户端画面验收。

### 托管项目

```powershell
dotnet build managed-host/Nanaimo.Adapter.csproj -c Release -f net8.0 --nologo
dotnet build managed-host/Nanaimo.Adapter.csproj -c Release -f net6.0 --nologo --no-restore
```

构建退出码0表示对应目标框架的Release构建通过；结果还须登记受测源码与工具链版本。

## 完整适配器构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_complete_adapter.ps1 `
  -OutputRoot '<全新候选目录>' `
  -TccPath '<TCC目录>/tcc.exe' `
  -DotnetPath '<.NET 8 SDK目录>/dotnet.exe' `
  -ResourceDataRoot '<adapter数据目录>' `
  -TargetFramework net8.0 `
  -SelfTest
```

固定原生测试端口被占用时，先构建候选，再选择已确认不连接活动工作进程的独立专项；具体开关及隔离条件见本目录专项页。`--<feature>-self-test` 是开关类别的占位描述，不能作为字面命令执行。启动式自检须在对应固定端口空闲时执行。

输出为当前可用目标框架的 `net6.0/win-x64/self-contained` 或 `net8.0/win-x64/self-contained`，包含 `Nanaimo.Adapter.exe`、managed DLL、`nanaimo_gameplay_bridge.exe`、资源数据及 `adapter_manifest.json`。构建使用全新输出目录，清单按当前产物生成。启动式 `--self-test` 使用固定内部端口，执行前要求全部测试端口空闲。
