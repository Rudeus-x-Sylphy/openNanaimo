## 知识库迁移检查

下列检查核对原 `docs/` 文档的完整字符覆盖、当前片段唯一性、正文信息和本地链接。严格模式用于核对融合时的历史内容；日常维护使用默认模式检查完整覆盖与链接，并报告已编辑片段。维护约定见[知识维护](../工程/知识维护.md)，含源码闭包与发布清单的完整检查清单见[文档与发布检查](构建与验证/文档与发布检查.md#知识库与文档)。

```powershell
python -B scripts/verify_document_fusion.py
python -B scripts/verify_document_fusion.py --self-test
```
