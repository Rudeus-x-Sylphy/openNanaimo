## 随仓库资源包与安装步骤

- `resource-packs/nanaimo-korean-resource-kit.zip`及同目录`.zip.sha256`随仓库提供，不是仅有清单、下载占位符或Git LFS指针。
- 资源包包含2350项去重韩服输入、1328项L7/L8安装输出、三份配方、工具与说明；可供英雄龙24项及其余121条宠物526项新增资源的转换／安装。
- 它**不是完整客户端**：原有CN资源、共享BOO／图像等保留项和原客户端程序仍由合法取得的匹配基础客户端提供。
- [兼容及验证范围](../工程/资源安装/验证与未确认依赖.md#df-17-005)所列待确认尾效果引用仍保留原有边界，不因打包而视为已完成实机验收。

### 前置条件与输入身份

先按仓库 README 把工程与基础客户端放在同一根目录，并完成启动器的基础兼容准备。退出全部游戏客户端后，在该根目录打开 PowerShell。写入前保存一份完整的客户端资源副本，供宠物安装被中断或后续退回时核对恢复。下列命令使用仓库脚本；资源包自身也附有同版工具和配方。不要直接把 `source-kr` 覆盖到客户端。

- 已验证的初始868条CN PET表为483152字节，SHA-256为`3efc299b3f30920a0d154d8d3978975995400394d5997521f5e80e48e550638e`。
- **条目数相同不代表基线相同**；其他未经登记的表不能覆盖成此表来绕过检查。
- 869／990升级输入由`manifest/korean_pet_resources.json`的基线及迁移列表限定。
- 下面先检查表身份再开始写入；已有完整990条安装时跳过英雄龙步骤，直接执行追加宠物迁移与L7/L8安装。

### 安装与逐步核验

```powershell
$Client = (Get-Location).Path
$Recipe = Get-Content 'manifest/korean_pet_resources.json' -Raw -Encoding UTF8 | ConvertFrom-Json
$InitialPetHash = (Get-FileHash 'pi._D7' -Algorithm SHA256).Hash
$KnownPetHashes = @('3efc299b3f30920a0d154d8d3978975995400394d5997521f5e80e48e550638e', $Recipe.baseline_catalog.sha256, $Recipe.installed_catalog.sha256)
$KnownPetHashes += @($Recipe.catalog_migrations | ForEach-Object { $_.before.sha256 })
if ($KnownPetHashes -notcontains $InitialPetHash) { throw 'PET基线未登记，停止安装，不覆盖原表' }
$Archive = Join-Path $Client 'resource-packs/nanaimo-korean-resource-kit.zip'
$Expected = ((Get-Content -LiteralPath ($Archive + '.sha256') -Raw).Trim() -split '\s+')[0]
if ((Get-FileHash -LiteralPath $Archive -Algorithm SHA256).Hash -ne $Expected) { throw '资源包摘要不匹配' }
$Work = Join-Path $Client ('build/resource-install-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
$Kit = Join-Path $Work 'kit'
Expand-Archive -LiteralPath $Archive -DestinationPath $Kit

python -m pip install pycryptodome
if ($LASTEXITCODE -ne 0) { throw 'Python依赖安装失败' }
python scripts/package_korean_resource_kit.py verify --archive $Archive
if ($LASTEXITCODE -ne 0) { throw '包内文件校验失败' }

if ($InitialPetHash -eq '3efc299b3f30920a0d154d8d3978975995400394d5997521f5e80e48e550638e') {
    python scripts/prepare_hero_dragon.py --source-root "$Kit/source-kr" --client-root $Client --output-root "$Work/hero" --apply
    if ($LASTEXITCODE -ne 0) { throw '英雄龙安装失败，保留输出并检查基线' }
}
python scripts/prepare_korean_pets.py --source-root "$Kit/source-kr" --client-root $Client --output-root "$Work/pets" --apply
if ($LASTEXITCODE -ne 0) { throw '追加宠物安装失败，保留输出并检查基线' }
python scripts/port_lumineos_resources.py apply --bundle "$Kit/l7-l8-bundle" --client $Client
if ($LASTEXITCODE -ne 0) { throw 'L7/L8安装失败，保留事务收据' }

python scripts/prepare_hero_dragon.py --client-root $Client --verify-installed
if ($LASTEXITCODE -ne 0) { throw '英雄龙安装后校验失败' }
python scripts/prepare_korean_pets.py --client-root $Client --verify-installed
if ($LASTEXITCODE -ne 0) { throw '追加宠物安装后校验失败' }
python scripts/port_lumineos_resources.py verify --client $Client
if ($LASTEXITCODE -ne 0) { throw 'L7/L8安装后校验失败' }
```

通过后使用普通GUI启动器进入游戏；启动器继续核对资源凭据并应用对应兼容项。完整安装首次按868→英雄龙869→追加宠物990合并；已登记的869／990目录按精确迁移规则处理，未知基线拒绝，不绕过摘要。已安装旧L7/L8资源包的客户端按已登记旧标记用本包`apply`升级L7战斗资源及stage1兼容别名；已通过校验的宠物模块继续使用当前安装。

### 回滚与恢复边界

保留 `$Work` 内备份和客户端的 `.openNanaimo-resource-backups` 事务收据。L7/L8 回滚使用 `python scripts/port_lumineos_resources.py rollback --client <客户端目录> --receipt <安装输出的相对收据路径>`；所跟踪的文件已有后续修改时，回滚器会拒绝覆盖。

英雄龙、追加宠物和 L7/L8 是三次独立安装，整组命令没有统一回滚事务。两个宠物安装器会在普通异常时恢复本次已写文件，但没有命令行 `rollback` 入口，也没有 L7/L8 那样的持久化恢复收据。进程中断或成功安装后退回时，须依据安装前资源副本、输出报告及备份逐项核对 PET 表、凭据和新增资源，再恢复匹配的 GUI／适配器版本。资源恢复不得覆盖角色数据库或把旧存档覆盖回来。
