# 200级内部桥接布局（小端序）

托管适配器与原生工作进程使用此版本化状态约定。曲线版本3采用韩服累计经验表T[0..200]；等级上限200，累计经验上限为T[200]。客户端经验条使用独立的投影值，见[等级经验](../业务/角色/等级经验/README.md)。宠物经验仍使用DWORD（32位无符号整数）。

<!-- FUSION END df-04-001 -->

桥接字段的完整布局在此维护；调用方与状态交换见[适配器架构](../工程/适配器架构.md#df-08-010)，操作入口见[启动指南](../指南/启动流程与源码索引.md)。

- 索引 `index >= 420` 的扩展卡册不得使用272+index*4读写，否则会覆盖道具数量／数组。
- 曲线版本仍为**3**，F10B仍为v3/48；库存扩展不再次迁移经验。
- 启动时在单一SQL事务升级已验证、非活动的v3恢复档，将精确旧字节及SHA-256归档到NativeCardProfileArchives，并仅从CharacterCards初始化扩展数量。
- 不得从已污染的旧原生工作进程旁路状态恢复卡片。
- 当前档案重复升级保持幂等；待提交旧奖励日志不隐式升级，切换程序前应使用版本匹配的托管适配器和原生工作进程完成恢复。

所有多字节字段采用小端序；完整帧偏移等于载荷偏移加8。HP/MP上限保持基础值，当前值按本快照所选宠物、宝石及装备计算出的有效上限校验，不能只与基础上限比较。数量字段上限为BYTE（8位无符号整数，0..255），虽然容器使用DWORD（32位无符号整数）。字段依据为`managed/Services/NativeDungeonState.cs`及`release/components/game_session/managed_bridge.inc`的导入／快照实现。

旧原生工作进程拒绝新长度与判别值，不提供仅截取低 DWORD（低 32 位）的兼容方式。构造器先校验版本、长度与曲线，再解释权威状态。
