## 协议结论与适用范围

| 类别 | 维护内容 |
|---|---|
| 协议约定 | 字节布局、方向、先后顺序与状态条件 |
| 运行行为 | 当前适配器的交互与生命周期 |
| 客户端接口 | 指令、偏移、分支、构造函数和处理函数 |
| 自动验证 | 适配器字节、顺序、路由、请求门控和重置 |
| 执行模型 | 明确输入与状态条件下的行为 |
| 自定义策略 | 适配器的数值规则与实现行为 |
| 验收范围 | 按协议、构造、持久化和客户端交互分别登记 |

协议结论按以下结构区分适用范围：

```text
连接 | 分派器／控制器 | 状态 | 操作码（十进制／十六进制） | 声明长度／实收长度
触发条件 | 响应 | 请求低位 | S2C 序号 | 帧布局 | 关闭方向
```

## S2C 包头

- 高位序号循环：首个响应为 0，随后为 1..100，再从 1 开始。
- 请求驱动的响应复制对应请求的低 5 位。
- 登录连接从首个完整请求帧初始化校验和种子：`low | (low << 8)`；主游戏会话（GS）连接从首个 C351 初始化。其他房间连接按各自初始化路径处理，不能将 GS 条件套用于所有连接。
- 广播、BOSS、房间重置与调度路径使用同一套序号循环。
- 响应长度必须覆盖处理函数实际读取的最高偏移，且所有被读取字节都已初始化。

## 协议元组

同一操作码的语义受以下范围限定：

| 元组维度 | 定义 |
|---|---|
| 连接 | 登录、游戏会话、房间／战斗等独立连接 |
| 分派器／控制器 | 实际消费请求或响应的处理路径 |
| 客户端状态 | 页面、控制器阶段及请求门控状态 |
| 操作码 | 保留原十六进制标识，不脱离前三项解释 |
| 长度 | 声明长度、实收长度及完整帧／载荷基准 |

不同元组之间不能直接迁移结论；构造函数、处理函数和状态门控分别决定其适用范围。尤其注意 C351/C352、C367/C368、CF70/CF71、CFEB/CFEC、CF7F/CF80、CFD3/CFD4、CF9C、CF88 与 D012。

## 地址与调用关系

本主题按函数、分派器和状态记录地址与字段读取关系。地址不单独确定语义；同一操作码在不同连接、控制器或客户端状态下可能由不同处理器消费。

```text

构造函数 -> 发送调用点 -> 连接

响应分派器 -> case -> 处理函数

全部读取偏移 -> 写入／调用

最高读取偏移 -> 最小长度

```


本主题维护字段、指令与调用关系。客户端接口、适配器实现及自定义数值策略分别定义；公共协议规则见[基础索引](README.md)，各业务规则见[业务索引](../业务/README.md)，实现结构见[工程／索引](../工程/README.md)。
